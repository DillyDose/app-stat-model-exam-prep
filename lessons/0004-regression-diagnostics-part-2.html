Lecture 4 — Regression Diagnostics (Part II)

Outlier, Leverage, Influence: วินิจฉัยจุดข้อมูลที่ทำลายโมเดล

บทนี้ต่อจาก Lecture 3 (เช็ค assumption ของ error) มาเรื่องเคสข้อมูลรายจุด — จุดไหนในข้อมูลที่ผิดปกติ, ผิดปกติแบบไหน, และผิดปกติมากพอจะ "ทำลาย" ผลการวิเคราะห์หรือไม่ นี่คือทักษะการเช็ค assumption ระดับละเอียดที่สุดของวิชานี้ และเป็นจุดที่ข้อสอบชอบทดสอบ 3 คำที่ฟังดูคล้ายกันแต่ไม่ใช่คำเดียวกัน: outlier, leverage point, และ influential point.

คำเตือนก่อนเริ่ม
สไลด์นี้อ้างอิงจากตำราของ Kutner (สังเกตเลขอ้างอิง "16.2" ที่มุมสไลด์หน้า 2) และใช้ตัวอย่างจาก dataset mtcars (ในตัวอย่าง fit lm(mpg~., data=mtcars), n=32, p=10 ตัวแปรอิสระ จึงมี p+1=11 พารามิเตอร์) กับ dataset co2 จาก package AppRegR (n=177 ประเทศ) — ตัวเลข n, p ที่ปรากฏใน rule of thumb ทุกจุดของบทนี้อ้างอิงจากสองชุดข้อมูลนี้เท่านั้น จำไว้เพื่อเช็คว่าทำไม threshold แต่ละจุดถึงมีค่าตามที่เห็นในสไลด์จริง

1. Outlier vs Leverage Point vs Influential Point — สามคำที่ข้อสอบชอบสับสน

นิยามจากสไลด์ (ตรง ๆ):

  • Outlier — จุดข้อมูลที่เบี่ยงเบนไปจาก pattern โดยรวมของข้อมูล (ไม่ได้ระบุว่าเบี่ยงในมิติไหน)
  • Influential point — outlier ที่ส่งผลกระทบอย่างมากต่อโมเดล (ไม่ใช่ outlier ทุกจุดจะ influential)

สำหรับ simple linear regression สไลด์แบ่งการเบี่ยงเบนออกเป็น 2 มิติที่แยกกันเด็ดขาด: เบี่ยงเบนในค่า Y (ให้ X คงที่) กับเบี่ยงเบนในค่า X — และจุดที่จะกลายเป็น "influential" ต้องเบี่ยงเบนในทั้งสองมิติพร้อมกัน:

อ่านจุดทั้ง 4 ในภาพทีละจุด:

  • จุด 1 อยู่กลาง ๆ ช่วง X (ไม่ outlying ในแกน X เลย) แต่ค่า Y สูงกว่าจุดอื่นที่ X ใกล้เคียงกันมาก — นี่คือ outlying in Y only ไม่มีป้ายกำกับว่า "influential"
  • จุด 2 อยู่ไกลจากกลุ่มข้อมูลในแกน X (X มีค่าสูงผิดปกติ) — นี่คือ leverage point แท้ ๆ (outlying in X) แต่สังเกตว่าสไลด์ไม่ได้ใส่กรอบแดง "influential" ให้จุดนี้ เพราะค่า Y ของมันยังพอจะสอดคล้องกับแนวโน้มที่เส้นถดถอยทำนายไว้ (ไม่ใช่ตัวที่ดึงเส้นออกจากแนวเดิมมากนัก) — นี่คือหลักฐานตรง ๆ จากสไลด์ว่า "high leverage" ไม่ได้แปลว่า "high influence" เสมอไป
  • ส่วนจุด 3 และ 4 ถูกครอบด้วยกรอบสีแดง "Influential points" เพราะทั้งคู่ outlying ทั้งแกน X และ แกน Y พร้อมกัน — จุดแบบนี้มีอำนาจดึงเส้นถดถอยให้เอียงเข้าหาตัวเองได้มาก เพราะอยู่ไกลจากศูนย์กลางข้อมูล (leverage สูง) และยังไม่ตรงกับแนวโน้มที่เหลือ (residual สูง) พร้อมกัน

สรุปเป็นกฎ 3 ข้อที่ต้องจำ:

  1. Outlier วัดจาก Y ที่ผิดปกติ (ทางแนวตั้ง) — ใช้ residual/studentized residual วัด
  2. Leverage point วัดจาก X ที่ผิดปกติ (ทางแนวนอน) — ใช้ hat value วัด
  3. Influential point ไม่ใช่การวัดแบบใหม่ แต่เป็นผลลัพธ์ร่วมของทั้งสองอย่าง — วัดด้วย DFFITS/Cook's D/DFBETAS ซึ่งรวม leverage กับ residual เข้าด้วยกันในสูตรเดียว (จะเห็นชัดในหัวข้อ 5)

2. หา Leverage Point: Hat Matrix Diagonal (hii)

สำหรับ multiple linear regression ที่พล็อต scatter ตรง ๆ ไม่ได้ (มีตัวแปรอิสระหลายตัว) ใช้ hat matrix วัด leverage แทน สมบัติสำคัญ 2 ข้อของ diagonal element hii:

\[ 0 \leq h_{ii} \leq 1 \]   และ   \[ \sum h_{ii} = \#\text{parameters} = p+1 \]

hii คือระยะห่างระหว่างค่า X ของเคสที่ i กับค่าเฉลี่ยของ X ทั้งหมด — ยิ่ง X ของเคสนั้นห่างจากค่าเฉลี่ยของกลุ่มมาก hii ยิ่งเข้าใกล้ 1 (สังเกตว่าผลรวมของ hii ทั้งหมดคงที่เสมอที่ p+1 พารามิเตอร์ ไม่ว่า n จะเท่าไร — นี่คือเหตุผลที่ rule of thumb ด้านล่างหารด้วย n เพื่อปรับตามขนาดตัวอย่าง):

ระบุว่าเป็น outlying X observation เมื่อ \( h_{ii} > \dfrac{2(p+1)}{n} \)

ใช้ mtcars เป็นตัวอย่างตลอดบทนี้: lm(mpg~., data=mtcars) มี n=32, p=10 ตัวแปรอิสระ (cyl, disp, hp, drat, wt, qsec, vs, am, gear, carb) ดังนั้น p+1=11 → cutoff = 2×11/32 = 0.6875. โค้ด R และผลลัพธ์จริง:

อ่านกราฟ: มีแท่งเดียว (ที่ index ประมาณ 9) ที่พุ่งขึ้นไปแตะเส้นตัด (cutoff) สีน้ำเงินที่ 0.6875 พอดี ส่วนแท่งอื่นทั้งหมดอยู่ต่ำกว่าเส้นชัดเจน (สูงสุดรองลงมาราว 0.6) — สรุปได้ทันทีว่ามีเคสเดียวในข้อมูลชุดนี้ที่ถือว่า outlying ในแกน X ตาม rule of thumb (จะยืนยันด้วยตัวเลขแม่นในหัวข้อ 7 ว่าคือ Merc 230, h99=0.742).

3. หา Outlier ใน Y: Internally Studentized Residuals

เมื่อรู้แล้วว่า residual ei = Yi − Ŷi ธรรมดายังเปรียบเทียบข้ามเคสไม่ได้ตรง ๆ (variance ของแต่ละ residual ไม่เท่ากัน ขึ้นกับ hii) สไลด์แนะนำ 2 มาตรวัดตามลำดับ: (1) Internally Studentized Residuals (2) Studentized Deleted Residuals — หัวข้อนี้เริ่มจากตัวแรก:

พิสูจน์ได้ว่า \( s[e_i] = \sqrt{MSE(1-h_{ii})} \)
Internally studentized residual: \( r_i = e_i / s[e_i] = e_i / \sqrt{MSE(1-h_{ii})} \)
ระบุว่าเป็น outlying Y observation เมื่อ \( r_i > 2 \)

สังเกตว่าสูตรนี้หาร ei ด้วย (1−hii) ใต้ราก — เคสที่มี leverage สูง (hii ใกล้ 1) จะมี s[ei] เล็กลง ทำให้ ri ถูก "ขยาย" ขึ้นเทียบกับ residual ดิบ นี่คือเหตุผลที่ hii กับ ri ต้องดูคู่กันเสมอ ไม่ใช่แยกกันคนละเรื่อง.

s[e_i]=√(10.06×(1−0.36))=√(10.06×0.64)=√6.438≈2.538, r_i=8/2.538≈3.15

4. ปัญหา "Masking" และทางแก้: Deleted / Studentized Deleted Residuals

ปัญหาของ internally studentized residual: ถ้าเคสนั้นเป็น outlier ที่รุนแรงมาก มันจะดึง MSE ให้สูงขึ้นเอง (เพราะ MSE คำนวณจาก residual ของทุกเคสรวมถึงตัวมันเอง) ทำให้ ri ของมันเองถูกหารด้วย MSE ที่ถูกบวมขึ้นจากตัวมันเอง — ผลคือ ri อาจดูไม่รุนแรงเท่าที่ควร (เรียกว่า masking effect) ทางแก้คือคำนวณ MSE โดยไม่รวมเคสนั้น:

Deleted residual: \( d_i = Y_i - \hat{Y}_{i(i)} \)  (\( \hat{Y}_{i(i)} \) = ค่าทำนายเมื่อตัดเคส i ออกจากการ fit)
สูตรลัดไม่ต้อง fit ใหม่: \[ d_i = e_i / (1 - h_{ii}) \]
\[ s^2\{d_i\} = MSE_{(i)} / (1 - h_{ii}) \]  โดย \(MSE_{(i)}\) = MSE เมื่อตัดเคส i ออก
Studentized deleted residual: \( t_i = d_i / s\{d_i\} = e_i / \sqrt{MSE_{(i)}(1 - h_{ii})} \)  ~  \( t(n-p-2) \)

ข่าวดี: ไม่ต้อง fit โมเดลใหม่ n รอบเพื่อหา MSE(i) แต่ละตัว เพราะพิสูจน์ได้ว่าคำนวณจากผล fit เพียงครั้งเดียวได้เลย:

\[ t_i = e_i \sqrt{ \dfrac{n-p-2}{SSE(1-h_{ii}) - e_i^2} } \]  ~  \( t(n-p-2) \)
Rule of thumb (เลือกใช้ข้อใดข้อหนึ่ง)
\( t_i > t(1 - \alpha/2n ; n-p-2) \) — Bonferroni critical value (ปรับสำหรับ multiple comparison เพราะทดสอบ n เคสพร้อมกัน)
\( t_i > 3 \) — กฎง่าย ไม่ปรับ multiple comparison

Studentized deleted residual มีอีกชื่อว่า Externally Studentized Residuals (เพราะ MSE(i) มาจาก "ภายนอก" เคส i) ใน R คำนวณด้วยฟังก์ชันสำเร็จรูป:

> e<-resid(model)                              # residuals
> h<-hatvalues(model)                           # leverage
> r<-resid(model)/sqrt(mse*(1-h))               # internally studentized
> int_stures<-rstandard(model)                  # ฟังก์ชันลัดของ r
> d<-resid(model)/(1-h)                         # deleted residuals
> ext_stures<-rstudent(model)                   # studentized deleted residuals (t_i)

บนข้อมูล mtcars ค่า Absolute Studentized Deleted Residuals ของทุกเคสเทียบกับ cutoff แบบ Bonferroni (qt(1-0.05/(2*32), df-1) ≈ 3.6):

อ่านกราฟ:

  • ไม่มีแท่งใดแตะเส้น threshold ±3 เลย — แปลว่าตาม rule \( t_i > 3 \) ไม่มีเคสไหนถูกจัดเป็น outlying Y observation ใน mtcars ชุดนี้ (แม้จะมี 3 เคสแถว index 17, 18, 20 ที่สูงเด่นถึงประมาณ 2 ก็ยังไม่ถึง 3)
  • นี่คือความต่างสำคัญจาก internally studentized residual ในหัวข้อ 3 ที่ใช้ cutoff เพียง 2 (เข้มงวดกว่ามาก และไม่ปรับ multiple comparison) — เห็นได้ชัดว่าการเลือก rule of thumb มีผลต่อข้อสรุปโดยตรง

r_i คำนวณจาก MSE ที่รวม residual ของเคสนั้นเองอยู่ด้วย — ถ้าเคสนั้นเป็น outlier ที่รุนแรงมาก residual ขนาดใหญ่ของมันจะไปดัน MSE โดยรวมให้สูงขึ้น ทำให้ตัวหารของ r_i เองก็ใหญ่ขึ้นตามไปด้วย ผลคือ r_i ถูก "เจือจาง" ลงจนอาจดูไม่ผิดปกติ (ทั้งที่จริง ๆ ผิดปกติมาก) — เรียกว่า masking effect. t_i แก้ปัญหานี้โดยคำนวณ MSE(i) จากข้อมูลไม่รวมเคส i เอง จึงไม่มีทางที่เคสนั้นจะไปเจือจางค่าที่ใช้วัดตัวมันเอง ทำให้ t_i จับ outlier ได้แม่นกว่า r_i เสมอในกรณีที่ residual รุนแรง

5. Influence บนค่าที่ Fit: DFFITS และ Cook's Distance

เมื่อรู้ว่าเคสไหน outlying ใน X (leverage) และเคสไหน outlying ใน Y (residual) แล้ว คำถามต่อไปคือ "เคสไหนที่เมื่อตัดออก จะทำให้ผลการวิเคราะห์เปลี่ยนไปมาก" — สไลด์แบ่ง influence measure เป็น 2 กลุ่มตามสิ่งที่วัด:

  • Influence บนค่าที่ fit (single fitted value): DFFITS, Cook's Distance
  • Influence บนสัมประสิทธิ์ (regression coefficients): DFBETAS, COV RATIO

DFFITS วัดว่า Ŷi เปลี่ยนไปเท่าไรถ้าตัดเคส i ออกแล้ว fit ใหม่:

\[ (DFFITS)_i = (\hat{Y}_i - \hat{Y}_{i(i)}) / \sqrt{MSE_{(i)} h_{ii}} \]
คำนวณจากผล fit ครั้งเดียวได้: \[ (DFFITS)_i = t_i \sqrt{h_{ii} / (1-h_{ii})} \]
\( |DFFITS| > 1 \) สำหรับข้อมูลชุดเล็ก-กลาง  หรือ  \( |DFFITS| > 2\sqrt{(p+1)/n} \) สำหรับข้อมูลชุดใหญ่

สังเกตสูตร \( t_i \sqrt{h_{ii}/(1-h_{ii})} \): DFFITS คือ studentized deleted residual (จับ Y-outlier) คูณ กับพจน์ที่ขึ้นกับ leverage — นี่คือสูตรที่พิสูจน์ตรง ๆ ว่า influence = ฟังก์ชันร่วมของทั้ง residual และ leverage พร้อมกัน (ตรงกับที่อธิบายไว้ในหัวข้อ 1) ถ้า hii ต่ำมาก DFFITS จะเล็กแม้ ti จะใหญ่ และในทางกลับกัน.

Cook's Distance วัดผลรวมของการเปลี่ยนแปลงในค่าทำนายทั้ง n ค่า (ไม่ใช่แค่ค่าที่ i) เมื่อตัดเคส i ออก — เป็น aggregate influence measure:

\[ D_i = \sum_j (\hat{Y}_j - \hat{Y}_{j(i)})^2 / [(p+1)MSE] \]  ≡  \[ D_i = e_i^2 h_{ii} / [(p+1)MSE(1-h_{ii})^2] \]
\( D_i > F(p+1, n-p-1) \) ที่ percentile ~50% ขึ้นไป = influence รุนแรง, ~10-20% หรือต่ำกว่า = influence เล็กน้อย
Threshold ที่นิยมใช้กันทั่วไป (รวมถึงใน olsrr): \( D_i > 4/n \)

สูตร equivalent ของ Di สำคัญมาก: สังเกตพจน์ \( (1-h_{ii})^2 \) อยู่ที่ตัวส่วน — เมื่อ hii เข้าใกล้ 1 (leverage สูงมาก) พจน์นี้เข้าใกล้ 0 ทำให้ Di พุ่งขึ้นได้รุนแรงแม้ residual ei จะไม่ได้ใหญ่มากก็ตาม — นี่คือกลไกทางคณิตศาสตร์ที่อธิบายว่าทำไม leverage point แม้ residual จะดูปกติ ก็ยังมีโอกาส "influential" ได้ (จะเห็นตัวอย่างจริงในหัวข้อ 7).

6. Influence บนสัมประสิทธิ์: DFBETAS และ COV RATIO

DFFITS/Cook's D บอกว่าเคสไหน "มีผลต่อค่าทำนาย" แต่ไม่บอกว่าสัมประสิทธิ์ตัวไหนโดยเฉพาะที่ถูกดึง — DFBETAS ตอบคำถามนี้ตรง ๆ:

\[ (DFBETAS)_{k(i)} = (\hat{\beta}_k - \hat{\beta}_{k(i)}) / \sqrt{MSE_{(i)} c_{kk}} \]  โดย \(c_{kk}\) = diagonal ตัวที่ k ของ \((X'X)^{-1}\)
\( |(DFBETAS)_{k(i)}| > 1 \) สำหรับข้อมูลชุดเล็ก-กลาง  หรือ  \( |(DFBETAS)_{k(i)}| > 2/\sqrt{n} \) สำหรับข้อมูลชุดใหญ่

DFBETAS มีค่าหนึ่งค่าต่อสัมประสิทธิ์ต่อเคส — ถ้าโมเดลมี p+1 พารามิเตอร์และ n เคส จะมี DFBETAS ทั้งหมด (p+1)×n ค่า ต้องพล็อตแยกทีละตัวแปร (จะเห็นในหัวข้อ 7).

COV RATIO วัดคนละมุม: ไม่ได้ดูว่าค่าประมาณ (point estimate) เปลี่ยนไปเท่าไร แต่ดูว่าความแม่นยำ (precision) ของการประมาณสัมประสิทธิ์เปลี่ยนไปเท่าไรเมื่อตัดเคส i ออก — เป็นอัตราส่วนของ determinant ของเมทริกซ์ variance-covariance ของโมเดลที่ตัดเคส i กับโมเดลเต็ม:

\[ COV\ RATIO_i = \left[ \dfrac{1}{1-h_{ii}} \right] \times \left[ \dfrac{MSE_{(i)}}{MSE} \right]^{p+1} \]
\[ |COV\ RATIO_i - 1| \geq \dfrac{3(p+1)}{n} \]

ตีความ:

  • COV RATIO < 1 แปลว่าตัดเคสนี้ออกแล้วช่วงความเชื่อมั่นของสัมประสิทธิ์แคบลง (เคสนี้เคยทำให้ความไม่แน่นอนสูงขึ้น)
  • COV RATIO > 1 แปลว่าตัดออกแล้วช่วงความเชื่อมั่นกว้างขึ้น (เคสนี้เคยช่วยให้ประมาณค่าแม่นยำขึ้น มักเกิดกับ leverage point ที่ไม่ใช่ outlier)
คำถาม 6 (Free response)DFBETAS vs DFFITS
นักวิเคราะห์พบว่าเคส A มี DFFITS สูงเกิน threshold แต่เมื่อดู DFBETAS ของทุกสัมประสิทธิ์กลับพบว่าต่ำกว่า threshold ทุกตัว เป็นไปได้หรือไม่ และถ้าเป็นไปได้ อธิบายว่าเกิดจากอะไร
เป็นไปได้ เพราะ DFFITS วัดผลรวมต่อ "ค่าทำนาย" (ซึ่งเป็นผลรวมเชิงเส้นของสัมประสิทธิ์ทุกตัวคูณ X) ในขณะที่ DFBETAS แยกวัดผลต่อสัมประสิทธิ์แต่ละตัวทีละตัว — เคส A อาจดึงสัมประสิทธิ์หลายตัวให้เปลี่ยนไป "เล็กน้อย" พร้อมกันในทิศทางที่ทำให้ค่าทำนายที่ X ของเคสนั้นเปลี่ยนไปมาก (ผลสะสมจากหลายตัวแปรรวมกัน) แต่แต่ละตัวเปลี่ยนไม่มากพอที่จะเกิน threshold ของ DFBETAS เป็นรายตัว — นี่คือเหตุผลที่ควรดูทั้งสองค่าประกอบกัน ไม่ใช่ดูตัวใดตัวหนึ่งอย่างเดียว

9. Remedies: จะทำอย่างไรกับ Influential Point

สไลด์ให้ทางเลือก 2 แนวทาง:

  1. ตัดทิ้ง (Remove influential points) — ใช้เมื่อมั่นใจว่าเป็นข้อผิดพลาดในการเก็บ/บันทึกข้อมูล หรือเป็นเคสที่ไม่ควรอยู่ใน population ที่สนใจศึกษาจริง ๆ
  2. ใช้ robust regression model — ใช้เมื่อเคสนั้นเป็นข้อมูลจริงที่ถูกต้อง เพียงแต่ทำให้ OLS (ซึ่งไวต่อ outlier มาก เพราะยกกำลังสอง) ให้ผลเบี้ยว: Least Median of Squares (LMS) และ Iterative Reweighted Least Squares (IRLS)

เกณฑ์ตัดสินใจที่สไลด์ implied (จากลำดับการนำเสนอ): ตรวจสอบเคสที่ถูกแฟล็กก่อนเสมอ (ข้อมูลถูกป้อนผิดหรือไม่ อยู่นอกขอบเขตการศึกษาหรือไม่) ถ้าใช่ค่อยตัดทิ้ง ถ้าเป็นข้อมูลจริงที่ถูกต้อง ให้ fit ทั้งโมเดลเต็มและ robust regression คู่กัน แล้วรายงานทั้งสองผล — จะเห็นแนวทางนี้ทำจริงในตัวอย่าง CO2 dataset ต่อไป.

Threshold ที่แสดงคือ 0.023 ตรงกับ 4/177≈0.0226 พอดี — ประเทศ 38 มี Cook's D สูงสุด (~0.21) สอดคล้องกับที่มันเป็นทั้ง outlier และ leverage point พร้อมกันในกราฟก่อนหน้า (ตรงกับกลไก "รุนแรงทั้งสองทางพร้อมกัน = influence สูงสุด" ที่พบใน Ford Pantera L ของ mtcars) ตามมาด้วยประเทศ 146 และ 158 (leverage point ล้วน ๆ จากกราฟก่อนหน้า) ที่ก็ยังมี Cook's D สูงเกิน threshold มาก — ยืนยันอีกครั้งว่า leverage point เพียงอย่างเดียวก็ influential ได้จริงในทางปฏิบัติ ไม่ใช่แค่ทฤษฎี.

DFBETAS ของ CO2 model แยกตามตัวแปร (พล็อตแบ่งเป็น 2 หน้าเพราะมี 8 สัมประสิทธิ์): หน้าแรกครอบคลุม Intercept, log(Population), log(Area), log(GDP) และหน้าที่สองครอบคลุม log(Agri), log(Energy), log(Industry), log(Forest):

Threshold ที่กำกับทุกช่อง (Threshold: 0.15) ตรงกับสูตร 2/√177≈0.150 เป๊ะ — สังเกตประเทศ 146 (ซึ่งมี Cook's D สูงเป็นอันดับ 2 จากกราฟก่อนหน้า) มี DFBETAS ของ log(Agri) และ log(Energy) พุ่งลงไปถึง −0.5 ถึง −0.75 (เกิน threshold หลายเท่า) — แปลว่าประเทศนี้ไม่ได้แค่ influential ต่อค่าทำนายโดยรวม (Cook's D) แต่ influential ต่อสัมประสิทธิ์ของ log(Agri) และ log(Energy) โดยเฉพาะ ในหน้าแรก (ไม่แสดงภาพ) ประเทศเดียวกันก็แสดง DFBETAS สูงเกิน threshold บน log(Population) ด้วย — สรุปได้ว่าประเทศ 146 คือเคสที่ต้องตรวจสอบก่อนสรุปผลใด ๆ จากสัมประสิทธิ์เหล่านี้.

11. Robust Regression วิธีที่ 1: Least Median of Squares (LMS)

แทนที่จะ minimize ผลรวมกำลังสองของ residual (แบบ OLS) LMS minimizeค่ามัธยฐานของ residual กำลังสอง — มัธยฐานทนทานต่อค่าสุดโต่งกว่าผลรวมมาก เพราะไม่ถูกดึงด้วยจุดที่ residual ใหญ่ผิดปกติเพียงไม่กี่จุด:

\[ \text{minimize: } \operatorname{median}_{1 \leq i \leq n} \left\{ (Y_i - \hat{Y}_i)^2 \right\} \] 
> library(MASS)
> co2_lms<-lmsreg(log(CO2)~log(Area)+log(Population)+log(GDP)+log(Agri)
+ +log(Industry)+log(Energy)+log(Forest), data=co2)
> coef(co2_lms)
    (Intercept)       log(Area) log(Population)        log(GDP)
  -17.576396732     0.132096667     1.646917774    -0.073254662
      log(Agri)   log(Industry)     log(Energy)     log(Forest)
   -0.004017242     0.632190437     1.720224742    -0.569381085

สังเกตว่า lmsreg() ให้แค่ ค่าประมาณสัมประสิทธิ์ ไม่มี Std. Error/p-value ให้ในตัว (เพราะ distribution ของตัวประมาณ LMS ซับซ้อนกว่า OLS มาก ไม่มีสูตรปิดง่าย ๆ) — ข้อจำกัดนี้จะเห็นผลชัดในตารางเปรียบเทียบสุดท้าย (หัวข้อ 13) ที่ช่อง p-value ของ LMS ทุกช่องเป็น N/A.

12. Robust Regression วิธีที่ 2: Iterative Reweighted Least Squares (IRLS)

เรียกอีกชื่อว่า M-estimator (Huber, 1964) — แนวคิดคือให้ทุกเคสมี "น้ำหนัก" wi ในการ fit โดยเคสที่ residual ใหญ่ (ดูเหมือน outlier) จะได้น้ำหนักน้อยลงเรื่อย ๆ ผ่านการวนซ้ำ (iterate) จนน้ำหนักลู่เข้าค่าคงที่ สองฟังก์ชันน้ำหนักที่นิยม:

Huber weight
\( w_i = 1 \) ถ้า \( |e_i| \leq 1.345 \)    \( w_i = 1.345/|e_i| \) ถ้า \( |e_i| > 1.345 \)
Bisquare weight
\( w_i = [1 - (e_i/4.685)^2]^2 \) ถ้า \( |e_i| \leq 4.685 \)    \( w_i = 0 \) ถ้า \( |e_i| > 4.685 \)

ความต่างสำคัญ:

  • Huber ลดน้ำหนักลงแบบค่อยเป็นค่อยไป (wi ไม่มีวันเป็น 0 เป๊ะ)
  • Bisquare ตัดน้ำหนักเป็น 0 เต็ม ๆ เมื่อ residual เกิน 4.685 — Bisquare จึงดุกว่า Huber ในการ "ไม่สนใจ" outlier ที่รุนแรงมากไปเลย ในขณะที่ Huber ยังให้น้ำหนักเล็กน้อยอยู่เสมอ

ผลลัพธ์จริงจาก R (สังเกตว่า Residuals ใน output ยังมีค่าติดลบ/บวกมากอยู่ที่ Min/Max เพราะเป็น residual ก่อนถ่วงน้ำหนัก ไม่ใช่หลัง):

13. เทียบผลสุดท้าย: OLS vs LMS vs Huber vs Bisquare

ทดสอบ \( H_0: \beta_j = 0 \) เทียบกัน 4 วิธีบนโมเดล CO2 เดียวกัน:

อ่านแถวที่น่าสนใจที่สุด — log(GDP):

  • ภายใต้ OLS สัมประสิทธิ์ = −0.10, p-value = 0.457 (ไม่มีนัยสำคัญเลยที่ α=0.05)
  • ภายใต้ Huber สัมประสิทธิ์เปลี่ยนเป็น −0.20 (p=0.083, ยังไม่นัยสำคัญที่ α=0.05 แต่ใกล้กว่า)
  • ภายใต้ Bisquare สัมประสิทธิ์ = −0.24, p=0.034 (มีนัยสำคัญที่ α=0.05!)

ข้อสรุปเรื่อง log(GDP) เปลี่ยนไปตามวิธี fit ที่ใช้ ซึ่งบ่งชี้ว่าผล OLS สำหรับตัวแปรนี้ถูกดึงโดย influential point (เช่นประเทศ 146 ที่พบใน DFBETAS หัวข้อ 10) — เมื่อลดอิทธิพลของเคสเหล่านั้นด้วย robust regression สัมประสิทธิ์ log(GDP) แสดงตัวตนที่แท้จริงชัดขึ้น เทียบกับ log(Agri) ที่ไม่มีนัยสำคัญในทุกวิธี (p อยู่ระหว่าง 0.95-0.997 ตลอด) — แปลว่าผลของ log(Agri) ไม่ได้ถูกดึงโดย influential point แต่เป็นเพราะตัวแปรนี้ไม่มีความสัมพันธ์เชิงเส้นกับ log(CO2) จริง ๆ ในข้อมูลชุดนี้ (สอดคล้องกันทุกวิธี)

สังเกตคอลัมน์ LMS: p-value ทุกช่องเป็น N/A ตรงกับที่อธิบายไว้ในหัวข้อ 11 ว่า lmsreg() ไม่ให้ Std. Error/p-value มาให้ในตัว — นี่คือข้อจำกัดจริงของวิธีนี้ ทำให้ในทางปฏิบัติ Huber/Bisquare (ที่ต้องเรียก f.robftest() เพิ่ม) มักถูกใช้มากกว่าเมื่อยังต้องการทำ hypothesis test ประกอบ.

จากตารางเปรียบเทียบ log(GDP) มี p-value = 0.457 ภายใต้ OLS แต่ p-value = 0.034 ภายใต้ Bisquare จงอธิบายว่าทำไมข้อสรุปเรื่องนัยสำคัญของ log(GDP) เปลี่ยนไป และนักวิเคราะห์ควรรายงานผลอย่างไรให้รอบด้าน
OLS ให้น้ำหนักเท่ากันกับทุกเคสรวมถึง influential point (เช่นประเทศ 146 ที่มี DFBETAS สูงเกิน threshold) ทำให้ค่าประมาณและ p-value ของ log(GDP) ถูกดึงจนไม่มีนัยสำคัญ — ในขณะที่ Bisquare ลดน้ำหนักของเคสที่ residual ใหญ่ (ตัดเป็นศูนย์เมื่อเกิน 4.685) ทำให้สัมประสิทธิ์สะท้อนความสัมพันธ์ของ "ประเทศส่วนใหญ่" มากกว่า และพบว่ามีนัยสำคัญจริง (p=0.034). นักวิเคราะห์ควรรายงานทั้งสองผล ไม่ใช่เลือกผลที่ถูกใจ: ระบุว่า OLS ให้ผลไม่มีนัยสำคัญเพราะถูกอิทธิพลของ influential point บางประเทศ แต่เมื่อลดอิทธิพลนั้นด้วย robust regression (Bisquare) พบว่า log(GDP) มีความสัมพันธ์เชิงลบกับ log(CO2) อย่างมีนัยสำคัญ — และควรระบุประเทศที่เป็นต้นเหตุ (influential country) ให้ผู้อ่านตรวจสอบต่อได้ด้วย
