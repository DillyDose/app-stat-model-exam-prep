Lecture 3 — Regression Diagnostics and Remedies

Regression Diagnostics and Remedies: อ่าน Plot จริงให้ออกว่า "ผ่าน" หรือ "พัง" แล้วแก้ยังไง

บทเรียนนี้คือแกนกลางของทักษะที่ 2 ตามที่ระบุไว้ — เช็ค assumption อย่างเป็นระบบ: assumption ไหน คู่กับ diagnostic (plot หรือ test) ตัวไหน, "ผ่าน" หน้าตาเป็นอย่างไรใน output จริง, "พัง" หน้าตาเป็นอย่างไร, และพังแล้วต้องแก้ด้วยวิธีไหน. สไลด์นี้เกือบทั้งหมดเป็น diagnostic plot คู่ pass/fail ที่ครูเตรียมไว้ให้เทียบข้าง ๆ กัน — เราจะอ่านทีละคู่ พร้อมเชื่อมกับ R output จริงทุกจุด.

1. Residual คืออะไร — และทำไมไม่ใช่ตัวเดียวกับ Error

Residual นิยามจากข้อมูลจริง: \(e_i = Y_i - \hat{Y}_i\) (ค่าจริงลบค่าทำนาย) — ต่างจาก error term ทฤษฎี \(\varepsilon_i\) ที่เป็นส่วนเบี่ยงเบนจากเส้นจริง (ไม่มีใครรู้ค่า \(\beta_0, \beta_1\) จริง). \(e_i\) คำนวณได้จากข้อมูล (observable) ส่วน \(\varepsilon_i\) ไม่มีทางรู้ค่าจริง (unobservable) — diagnostic ทั้งบทนี้ใช้ \(e_i\) เป็นตัวแทนเพื่อ "เดา" ว่า \(\varepsilon_i\) น่าจะมีพฤติกรรมตาม assumption หรือไม่.

Residual มีสมบัติที่ต้องจำ 3 ข้อ: (1) ค่าเฉลี่ยของ residual เป็นศูนย์เป๊ะเสมอ \(\bar{e} = \sum e_i/n = 0\) — เป็นผลจากพีชคณิตของ OLS ไม่ใช่สิ่งที่ต้องเช็ค (2) variance ของ residual ประมาณด้วย \(s^2 = MSE\) (3) residual ไม่เป็นอิสระต่อกันเอง เพราะทุกตัวคำนวณมาจากเส้นถดถอยเส้นเดียวกัน — แต่ถ้า n มากกว่าจำนวนพารามิเตอร์มาก ๆ ผลจากการไม่อิสระนี้เล็กจนละเลยได้ในทางปฏิบัติ.

ข้อสังเกตสำคัญ: เพราะ \(\bar{e}\) เป็นศูนย์เสมอโดยพีชคณิต assumption ข้อ "mean zero" จึงไม่มี diagnostic แยกให้เช็ค — สไลด์จัดกลุ่ม diagnostic เหลือ 4 เรื่องเท่านั้น: linearity, normality, constant variance, independence (การพัง mean-zero ที่แท้จริงจะออกอาการเป็น "pattern" ในกราฟ residual-vs-fitted แทน ซึ่งคือสิ่งที่ linearity check ตรวจอยู่แล้ว).

ก่อนลงรายละเอียดทีละข้อ นี่คือแผนที่รวมทั้งบท — จำตารางนี้ให้ได้ก่อน แล้วค่อยไล่ดูตัวอย่างจริงทีละแถว:

สังเกตว่า residuals-vs-fitted ถูกใช้ตรวจทั้ง linearity และ constant variance พร้อมกัน — สองเรื่องนี้อ่านจากกราฟเดียวกันแต่มองคนละมิติ: linearity ดูว่ามี "โค้ง/แนวโน้ม" หรือไม่ (แกน y เอนไปทางบวกหรือลบเป็นช่วง ๆ), constant variance ดูว่า "ความกว้างของแถบ" คงที่ตลอดแกน x หรือไม่ (บานออกเป็นกรวยหรือเปล่า) — สอบมักถามแยกสองแง่มุมจากภาพเดียวกันนี้ ต้องแยกให้ออก.

สำหรับ formal test ทุกตัวในบทนี้ ทิศทางการอ่านผลเหมือนกันหมด: H₀ คือ "assumption เป็นจริง" (residual is normal / has constant variance / is independent) ดังนั้น ต้องการ p-value สูง (ไม่ปฏิเสธ H₀) — กลับด้านกับการทดสอบ \(H_0: \beta=0\) ในบทก่อนที่อยากปฏิเสธ H₀ ต้องระวังจุดนี้เป็นพิเศษ.

3. เช็ค Linearity Assumption

ทำสองอย่าง: (1) plot X vs Y ตรง ๆ ก่อน fit เพื่อดูว่าความสัมพันธ์เป็นเส้นตรงหรือไม่ (2) หลัง fit แล้ว plot residuals vs fitted values เพื่อดู lack of fit — ถ้าโมเดลจับความสัมพันธ์ได้ครบ residual ที่เหลือต้องกระจายแบบสุ่มไม่มีแนวโน้ม:

อ่านสองแผงนี้ให้ละเอียด: แผงซ้าย (✓) เส้นสีแดง (smoother/loess) ที่ลากผ่านกลุ่มจุดแทบจะเป็นเส้นตรงราบอยู่ที่ 0 ตลอดช่วงแกน x — จุดกระจายทั้งเหนือและใต้เส้น 0 ในสัดส่วนใกล้เคียงกันทุกช่วง ไม่มี "รูปทรง" ที่มองเห็นได้ด้วยตา นี่คือสิ่งที่ต้องเห็นเมื่อโมเดลเชิงเส้น fit ข้อมูลได้ดี. แผงขวา (✗) เส้นแดงหักโค้งชัดเจน: เริ่มจากค่าบวก ลดฮวบลงต่ำกว่า 0 ในช่วงกลาง แล้วดีดกลับขึ้นมาที่ปลายขวา — รูปตัว U คว่ำ-หงายนี้คือสัญญาณตรงไปตรงมาที่สุดว่าโมเดลเชิงเส้นพลาดความสัมพันธ์ที่แท้จริงซึ่งเป็นเส้นโค้ง (บางทีเรียก "lack of fit").

ตัวอย่างจริงจาก R — plot(fitted(model1), resid(model1)) เทียบกับ built-in plot(model1, 1) (ซึ่งให้ผลเหมือนกันแต่ R เติม label จุดที่ residual ใหญ่ผิดปกติให้อัตโนมัติ):

สองแผงนี้เป็นข้อมูลชุดเดียวกัน พล็อตสองวิธี — แผงขวาที่ได้จาก plot(model1,1) มีเส้น smoother สีแดงช่วยตาให้เห็นแนวโน้มชัดขึ้น และ R ติด label จุดที่ 46, 36, 55 อัตโนมัติเพราะเป็นจุดที่ residual ห่างจาก 0 มากที่สุดสามอันดับแรก (นี่ยังไม่ใช่ influence diagnostic เต็มรูปแบบ — แค่ช่วยตาดู อธิบายลึกใน Lecture 4). เส้น smoother ที่นี่ค่อนข้างราบใกล้ 0 ตลอดช่วง มีหยักขึ้นลงเล็กน้อยแต่ไม่ได้โค้งเป็นระบบแบบภาพก่อนหน้า — ตีความได้ว่า linearity assumption ผ่านในระดับที่ยอมรับได้ แม้จะมีจุด outlier 3 จุดที่ยังต้องตรวจสอบต่อ (เรื่อง influence point เต็ม ๆ อยู่ใน Lecture 4).

4. เช็ค Normality Assumption

สองวิธี: Normal QQ plot ของ residual (ต้องเกาะเส้น 45 องศา) และ Shapiro-Wilk Test (\(H_0\): residual แจกแจงปกติ — ต้องไม่ปฏิเสธ H₀ ถึงจะ "ผ่าน"):

แผงซ้าย (✓): จุดทุกจุดเรียงตัวเป็นเส้นตรงทแยงมุมสม่ำเสมอตั้งแต่มุมล่างซ้ายถึงบนขวา ไม่มีจุดไหนหลุดออกจากแนว — สรุปว่า empirical quantile กับ theoretical quantile (จากการแจกแจงปกติ) ตรงกันตลอดช่วง = residual แจกแจงแบบปกติ. แผงขวา (✗): ช่วงกลางจุดยังเกาะเส้นได้ดี แต่ที่หางบนขวา จุดหักโค้งชันขึ้นแยกออกจากเส้นตรงอย่างชัดเจน — แปลว่าค่า residual ที่ควรจะมากตามทฤษฎี (theoretical quantile สูง) จริง ๆ แล้วมากกว่านั้นอีก (empirical quantile สูงกว่าที่ทฤษฎีทำนาย) นี่คือลักษณะของการแจกแจงเบ้ขวา (right-skewed) หรือมี outlier ที่หางขวา.

Ramsey & Schafer สรุปรูปแบบที่พบบ่อยไว้ 4 แบบ ให้จำรูปทรงเทียบกัน:

อ่านทีละแบบ: (A) NORMAL — เส้นตรงสม่ำเสมอ ไม่มีอะไรผิดปกติ (มาตรฐานที่ต้องเทียบด้วยทุกครั้ง). (B) LONG-TAILED — จุดโค้งเป็นรูปตัว S: ตรงกลางแบนราบ (จุดกระจุกตัวแน่นกว่าที่ทฤษฎีทำนาย) ส่วนหางทั้งสองข้างชันขึ้น/ลงแรง (หางหนากว่าปกติทั้งสองด้าน) — เป็น distribution ที่มี kurtosis สูง ไม่ใช่แค่เบ้ด้านเดียว. (C) SKEWED (+) — จุดทั้งเส้นโค้งเป็นส่วนโค้งเว้าเดียวตลอด (ไม่ใช่ S-curve) บ่งบอกความเบ้ไปทางบวกอย่างต่อเนื่อง ตรงกับรูปแบบที่เห็นในแผงขวาของภาพก่อนหน้า. (D) OUTLIER — จุดส่วนใหญ่เกาะเส้นตรงได้ดีเกือบทั้งหมด มีเพียงจุดเดียวที่หลุดออกไปไกลจากกลุ่มที่มุมขวาบน — ต่างจาก (B) และ (C) ตรงที่ปัญหาไม่ได้อยู่ที่รูปร่างการแจกแจงโดยรวม แต่อยู่ที่ observation ผิดปกติตัวเดียว (ต้องเช็คว่าเป็น data-entry error หรือ influential point จริงใน Lecture 4).

ผลจริงจาก R บนข้อมูลเดียวกับภาพหน้า 7-8 (model1) — เทียบสองวิธีสร้าง QQ plot ที่ให้ผลเหมือนกัน:

จุดส่วนใหญ่เกาะเส้นประได้ดีตลอดช่วงกลาง (theoretical quantile −1 ถึง 1) — มีจุด 46 ที่ปลายขวาบนกับจุด 36, 55 ที่ปลายซ้ายล่างเบี่ยงออกจากเส้นเล็กน้อย (สังเกตว่าเป็นจุดเดียวกันกับที่ถูก label ไว้ในภาพ residuals-vs-fitted หน้า 8 — จุดที่ residual ใหญ่ผิดปกติในกราฟหนึ่ง มักโผล่มาเป็นจุดเบี่ยงในกราฟ QQ ด้วยเสมอ เพราะเป็นตัวเลขชุดเดียวกัน) รูปแบบนี้ใกล้เคียง (A) NORMAL มากกว่า (B)/(C)/(D) — ยืนยันด้วยผล Shapiro-Wilk ที่ตามมา:

5. เช็ค Constant Variance Assumption

ใช้กราฟเดียวกับ linearity (residuals vs fitted) แต่มองมิติ "ความกว้างของแถบ" แทน "แนวโน้ม" — และมี Breusch-Pagan Test เป็น formal test (\(H_0\): residual มี variance คงที่):

แผงซ้าย (✓): เส้นประบนกับล่างขนานกันตลอดช่วงแกน x — "ความสูง" ของแถบที่จุดกระจายอยู่คงที่ ไม่ว่าจะมองที่ค่า X̂ หรือ X ต่ำหรือสูง นี่คือ homoscedasticity. แผงขวา (✗): เส้นประสองเส้นเริ่มจากจุดแคบ ๆ ทางซ้ายแล้วบานออกเป็นรูปกรวยไปทางขวา — ความกว้างของแถบไม่คงที่ ยิ่งค่า fitted/X มาก residual ยิ่งกระจายกว้าง นี่คือรูปแบบ heteroscedasticity ที่พบบ่อยที่สุด (มักเรียก "megaphone shape" หรือ "fan shape") ซึ่งจะเห็นตัวอย่างจริงในหัวข้อ Weighted Regression ด้านล่าง.

6. เช็ค Independence Assumption

ใช้เมื่อสงสัยว่าข้อมูลมี serial correlation (มักเกิดกับข้อมูลที่เก็บตามลำดับเวลาหรือพื้นที่) — สามวิธี: plot residuals vs time/order (ต้องไม่มี pattern), Run Test (สำหรับ cross-sectional data), Durbin-Watson Test (สำหรับ time-series data โดยเฉพาะ):

อ่านทีละแบบ: (A) Normal Noise — จุดกระจายสุ่มรอบ 0 ไม่มีรูปแบบ ค่าที่ time ใดค่าหนึ่งไม่บอกอะไรเกี่ยวกับค่าที่ time ถัดไป = ผ่าน. (B) Time Trend — residual ค่อย ๆ ไต่ระดับสูงขึ้นเรื่อย ๆ ตามเวลา (เริ่มจากติดลบ จบที่เป็นบวก) สไลด์แนะนำว่ากรณีนี้อาจแก้ได้ง่าย ๆ โดยใส่ time เป็นตัวแปรอิสระเพิ่มเข้าไปในโมเดล (ไม่ต้องใช้เทคนิค time series เต็มรูปแบบ เพราะรูปแบบนี้คือ deterministic trend ที่จับได้ด้วย regression ธรรมดา). (C) Positive Serial Correlation — จุดแกว่งขึ้นลงเป็นช่วงยาว ๆ ราบเรียบ (ถ้าติดลบคราวนี้ คราวถัดไปมักติดลบต่อ) — ค่าที่ time ใกล้กันมี "ความจำ" กัน. (D) Negative Serial Correlation — จุดสลับบวก-ลบแทบทุกจุดติดกันเป็นซิกแซกถี่ ๆ (ถ้าบวกคราวนี้ คราวถัดไปมักติดลบ) — ทั้ง (C) และ (D) สไลด์ระบุว่าต้องใช้ time series techniquesแก้ (ไม่ใช่แค่เติมตัวแปร time เข้าไปเฉย ๆ เหมือน (B)) เพราะโครงสร้างสหสัมพันธ์อยู่ในตัว error เอง.

7. ทำไมต้องเช็คให้ครบ: Robustness of Least Squares Inferences

สไลด์สรุปว่าถ้าไม่เช็คแล้วปล่อยผ่าน แต่ละ assumption ที่พังจะทำให้ตรงไหนของการวิเคราะห์เสียหาย — ต้องจำตารางนี้เพื่อบอกเหตุผลว่าทำไมต้องแก้ ไม่ใช่แค่บอกว่า "พัง":

Assumption ที่พังผลกระทบ
1. Linearityเส้นตรงเป็นโมเดลที่ไม่เหมาะสม — ค่าเฉลี่ยที่ประมาณและค่าทำนาย (estimated means/predictions) เอนเอียง (biased)
2. Constant varianceStandard error ไม่แม่นยำ (inaccurate) — test และ confidence interval ทั้งหมดเชื่อถือไม่ได้ (misleading)
3. NormalityEstimate ของสัมประสิทธิ์และ SE ค่อนข้าง robust ต่อการไม่ปกติ — ผลกระทบมักเล็กน้อย ยกเว้นกรณีมี outlier/หางยาวและ n เล็ก
4. IndependenceStandard error ไม่แม่นยำ — test และ confidence interval เชื่อถือไม่ได้ (เหมือนข้อ 2)

ข้อสังเกตที่ควรจำ: Linearity คือข้อเดียวที่ทำให้ point estimate เอง (ไม่ใช่แค่ SE) เอนเอียง — ส่วน constant variance กับ independence กระทบที่ SE/inference เท่านั้น point estimate ยังไม่ biased (แค่ไม่มีประสิทธิภาพที่สุด/inference ผิด) นี่คือเหตุผลที่สไลด์ให้ความสำคัญกับ linearity เป็นข้อแรกสุดที่ต้องเช็คก่อนเสมอ — ถ้า linearity พังตั้งแต่ต้น ทุกอย่างที่ตามมาก็ผิดหมด ในขณะที่ normality เป็นข้อที่ "robust" ที่สุด (สำคัญน้อยที่สุดเมื่อเทียบกับอีก 3 ข้อ ยกเว้น n เล็กมากหรือมี outlier).

8.2 Box-Cox Transformation — เลือก λ ให้อัตโนมัติแทนการเดา

ปัญหาของการแปลงตัวแปรด้วยมือ (log, sqrt, ...) คือบางครั้งไม่รู้ว่าควรแปลงแบบไหนถึงจะดีที่สุด — Box-Cox procedure หาคำตอบให้อัตโนมัติโดยค้นหาในตระกูล power transformation:

\(Y' = Y^\lambda\), โดย λ ถูกกำหนดจากข้อมูล — กรณีพิเศษที่ต้องจำ: \(\lambda=2 \to Y^2\), \(\lambda=0.5 \to \sqrt{Y}\), \(\lambda=0 \to \log(Y)\) (นิยามพิเศษ), \(\lambda=-0.5 \to 1/\sqrt{Y}\), \(\lambda=-1 \to 1/Y\)

Box-Cox แก้ปัญหาได้พร้อมกันสามเรื่อง: ความเบ้ของ error, variance ไม่เท่ากัน, และ nonlinearity — ทั้งหมดด้วยการแปลง Y ตัวเดียว (ตรงกับแผง (D) ใน decision guide ของหัวข้อ 8).

9. Remedy สำหรับ Non-constant Variance: Weighted Regression

ใช้เมื่อความสัมพันธ์เป็นเส้นตรงอยู่แล้ว (ตรงกับแผง (F) ในหัวข้อ 8) แต่ variance ไม่คงที่ — แนวคิด: observation ที่มี variance เล็ก (แม่นยำกว่า) ควรมีน้ำหนักในการ fit มากกว่า observation ที่มี variance ใหญ่:

\(w_i = 1/\hat{s}_i^2\) (จาก standard deviation function)  หรือ  \(w_i = 1/\hat{v}_i\) (จาก variance function)

ถ้ามี outlier ในข้อมูล สไลด์แนะนำให้ประมาณจาก standard deviation function มากกว่า variance function (เพราะยกกำลังสองใน variance function จะขยายผลกระทบของ outlier ให้แรงขึ้นไปอีก).

10. Remedy สำหรับ Independence: Cochrane-Orcutt Transformation

เมื่อ Durbin-Watson test ยืนยันว่ามี serial correlation ในข้อมูล time-series และไม่สามารถแก้ด้วยการเติม time เป็นตัวแปรอิสระได้ (กรณี (C)/(D) จากหัวข้อ 6 ไม่ใช่กรณี (B)) — สไลด์เสนอ Cochrane-Orcutt Transformation เป็นวิธีแก้:

ภาพนี้คือภาพเดียวกับหัวข้อ 6 (หน้า 16) แต่ครูวงกลมสีแดงเน้นเฉพาะสองแผงล่าง (C) และ (D) — ย้ำว่า Cochrane-Orcutt ใช้แก้เฉพาะกรณีสหสัมพันธ์แบบอนุกรมจริง ไม่ใช่กรณี Time Trend (B) ที่แก้ง่ายกว่าด้วยการเติมตัวแปร time.

โมเดล: \(Y_t = \beta_0+\beta_1 X_{1t}+\cdots+\beta_p X_{pt}+\varepsilon_t\) โดย \(\varepsilon_t = \rho \varepsilon_{t-1}+u_t\), \(u_t \sim \text{iid } N(0,\sigma^2)\)
ขั้นตอน: (1) fit Y on X ธรรมดา ได้ residual e_t (2) ประมาณ \(r = \dfrac{\sum e_t e_{t-1}}{\sum e_t^2}\) (3) แปลงข้อมูล \(Y^*_t = Y_t - rY_{t-1}\), \(X^*_t = X_t - rX_{t-1}\) (4) regress Y* on X* (5) ทำซ้ำ 2-4 จนกว่า Durbin-Watson test จะไม่พบ autocorrelation แล้ว

11. Multicollinearity — ปัญหาที่มีเฉพาะใน Multiple Regression

เมื่อตัวแปรอิสระหลายตัวมีความสัมพันธ์กันเองสูง (correlated กันเอง ไม่ใช่กับ Y) — ผลที่ตามมาคือสัมประสิทธิ์ไม่เสถียร (ค่าประมาณเปลี่ยนแปลงมากถ้าตัดตัวแปรใดตัวหนึ่งออก หรือเพิ่ม observation เข้ามาเล็กน้อย) และค่า standard error ไม่น่าเชื่อถือ. สัญญาณที่บ่งชี้ว่ามี multicollinearity: (1) correlation ระหว่างคู่ตัวแปรอิสระสูง (2) ค่าประมาณสัมประสิทธิ์เปลี่ยนไปมากเมื่อลองโมเดลต่าง ๆ (3) t-test รายตัวไม่มีนัยสำคัญ แต่ F-test ภาพรวมกลับมีนัยสำคัญ — สัญญาณข้อ (3) นี้เป็นตัวที่ตรวจจับได้ง่ายที่สุดจากการอ่าน output.

วัดเชิงปริมาณด้วย Variance Inflation Factor (VIF):

\(\text{VIF}_j = 1/(1-R^2_j)\), โดย R²_j คือ R² จากการ regress ตัวแปรอิสระตัวที่ j กับตัวแปรอิสระที่เหลือทั้งหมด

Rule of thumb ที่ต้องจำ: VIF = 1 ไม่มี correlation กับตัวแปรอื่นเลย, VIF > 4 เริ่มมี multicollinearity ระดับปานกลาง, VIF > 10 multicollinearity รุนแรง.

12. Remedy สำหรับ Multicollinearity: Centering, ตัดตัวแปร, Ridge, PCA

สไลด์เสนอ 4 แนวทาง: (1) Centering ตัวแปรอิสระแต่ละตัว (ลบด้วยค่าเฉลี่ยก่อน fit) (2) ตัดตัวแปรที่สัมพันธ์กันสูงออกบางตัว (3) ใช้ Ridge Regression (4) ใช้ Principal Component Analysis (PCA) — สองข้อหลังนี้สไลด์ลงรายละเอียดและมีตัวอย่าง R จริง จะดูทีละอัน.

12.1 Ridge Regression

Ridge regression อยู่ในกลุ่ม penalized regression — เพิ่มพจน์ลงโทษ (penalty) ที่ขนาดของสัมประสิทธิ์เข้าไปในเป้าหมายที่ต้องการ minimize:

\(\hat{\beta}_{ridge} = \operatorname{argmin}_\beta \left[ \sum_i (Y_i-\beta_0-\sum_j X_{ij}\beta_j)^2 + \lambda\sum_j \beta_j^2 \right]\), โดย \(\lambda > 0\) เป็น tuning parameter
คำตอบเชิงวิเคราะห์: \(\hat{\beta} = (X^\top X+\lambda I)^{-1}(X^\top Y)\)

สังเกตว่าเมื่อ \(\lambda=0\) สูตรนี้กลายเป็น OLS ปกติทันที — ยิ่ง λ มาก สัมประสิทธิ์ยิ่งถูก "หด" เข้าใกล้ 0 มากขึ้น (แลกกับ bias ที่เพิ่มขึ้นเพื่อความเสถียรที่มากขึ้น) การเพิ่ม \(\lambda I\) เข้าไปใน \(X^\top X\) ก่อน invert ยังช่วยแก้ปัญหาทางตัวเลข (numerical) ที่เกิดจาก multicollinearity โดยตรง เพราะ \(X^\top X\) ที่ใกล้ singular (จากตัวแปรที่สัมพันธ์กันสูง) จะ invert ได้อย่างเสถียรขึ้นเมื่อบวก λI เข้าไป.

ทดลองหา λ ที่เหมาะสมด้วย ridge trace plot บนข้อมูล ConsumerIndex เดิม:

12.2 Principal Component Analysis (PCA)

แนวคิด: แทนที่จะใช้ตัวแปรอิสระดิบที่สัมพันธ์กันเอง ให้สร้างตัวแปรใหม่ (Principal Components) ที่เป็นผลรวมเชิงเส้นของตัวแปรเดิม โดยแต่ละ PC ไม่สัมพันธ์กันเอง (orthogonal) และเรียงลำดับตามปริมาณความแปรปรวนที่อธิบายได้จากมากไปน้อย:

อ่านภาพเชิงเรขาคณิต: กลุ่มจุดข้อมูล (สีเทา) เรียงตัวเป็นวงรียาวเฉียง ๆ — ทิศทางที่จุดกระจายตัวมากที่สุดคือแนวเฉียงยาวของวงรี ลูกศร PC1 ชี้ไปตามแนวนั้นพอดี (นี่คือนิยามของ PC1: ทิศทางที่มี variance มากที่สุด) ส่วน PC2 ตั้งฉากกับ PC1 พอดี ชี้ไปตามแนว "แคบ" ของวงรี (ทิศทางที่เหลือหลังตัด PC1 ออกไปแล้ว) — สังเกตว่า PC1 และ PC2 ตั้งฉากกันเสมอ (orthogonal) นี่คือเหตุผลที่ PC ที่ได้ไม่มี multicollinearity ระหว่างกันเองเลย แม้ตัวแปรดิบเดิมจะสัมพันธ์กันสูงแค่ไหนก็ตาม.

Eigenvalue-eigenvector pair จาก covariance matrix S: \((\lambda_1,e_1),(\lambda_2,e_2),\ldots,(\lambda_p,e_p)\) โดย \(\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_p \geq 0\)
\(PC_k = e_{k1}X_1+e_{k2}X_2+\cdots+e_{kp}X_p\) (e_k เรียกว่า "loading" ของ PC_k)
สัดส่วนความแปรปรวนที่ PC_k อธิบายได้: \(\lambda_k / (\lambda_1+\cdots+\lambda_p)\)

คำถามที่ตามมาเสมอ: ควรใช้กี่ PC? ใช้ scree plot (กราฟ eigenvalue λᵢ เทียบกับลำดับ i) แล้วมองหาจุด "elbow" (ข้อศอก) ที่เส้นเริ่มราบ:

Ridge regression ยังคงใช้ตัวแปรอิสระดิบทั้งหมด (food, clothing, fuel, ...) แต่เพิ่มพจน์ penalty λΣβⱼ² เข้าไปเพื่อ "หด" สัมประสิทธิ์ให้เสถียรขึ้น — แลกด้วยการยอมรับ bias เล็กน้อยในสัมประสิทธิ์ (เพราะ β̂_ridge ไม่ใช่ unbiased estimator อีกต่อไป) เพื่อแลกกับ variance ที่ลดลงมาก ข้อดีคือยังตีความสัมประสิทธิ์ของตัวแปรเดิมได้ตรงไปตรงมา ส่วน PCA เปลี่ยนตัวแปรอิสระทั้งหมดให้เป็นชุดตัวแปรใหม่ (PC) ที่ตั้งฉากกันโดยสมบูรณ์ ทำให้ multicollinearity หายไปเลย (ไม่ใช่แค่บรรเทา) และยังช่วยลดมิติของปัญหา (ใช้ 2 PC แทน 5 ตัวแปรเดิม) แต่แลกด้วยการตีความยากขึ้นมาก เพราะ PC1, PC2 เป็นผลรวมเชิงเส้นของตัวแปรทั้งหมด ไม่ใช่ตัวแปรที่มีความหมายทางธุรกิจโดยตรงอีกต่อไป ต้องย้อนไปดู loading (eᵢⱼ) เพื่อตีความว่า PC แต่ละตัว "หมายถึง" อะไร
