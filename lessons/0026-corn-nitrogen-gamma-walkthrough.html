Assignment 9 — Problem 2 (Worked Example)

ฝึกกับโจทย์จริง: Corn Yield vs Nitrogen — Gamma GLM 3 Link Functions

Lesson 13 วางกรอบ Gamma GLM ไว้แล้ว: variance function \(\propto\mu^2\), การเลือก link function (canonical/log/linear) ตามลักษณะของผล X ที่สงสัย, และการแปลผลสัมประสิทธิ์ด้วย \(\exp(\hat\beta)\) เมื่อใช้ log link บทนี้เอากรอบนั้นมาใช้กับโจทย์จริงจาก Assignment 9 ข้อ 2 — ข้อมูล cornnit (faraway package) ที่ศึกษาความสัมพันธ์ระหว่างผลผลิตข้าวโพด (yield, บุชเชล/เอเคอร์) กับปุ๋ยไนโตรเจน (nitrogen, ปอนด์/เอเคอร์) ในวิสคอนซิน โจทย์นี้ให้ fit ทั้ง normal linear model (พร้อมหาการแปลงที่เหมาะสม) และ gamma GLM ด้วย 3 link function ที่ต่างกัน (log, identity, inverse) แล้วเปรียบเทียบว่าแบบไหนดีที่สุด — เป็นตัวอย่างที่ตรงกับหัวข้อ "3 ทางเลือกของ link function" ในหัวข้อ 3 ของ Lesson 13 พอดี

1. ทำไมโจทย์นี้เป็นตัวอย่างของ Gamma GLM

  • yield เป็นผลผลิตต่อเอเคอร์ — เป็นบวกเสมอ (ไม่มีผลผลิตติดลบหรือเป็นศูนย์แบบมีความหมาย)
  • โจทย์ระบุเองว่าต้อง "find appropriate transformations for the data" ก่อน fit normal linear model — เป็นสัญญาณว่าข้อมูลดิบไม่ตรงกับสมมติฐาน normal error ตรง ๆ
  • เมื่อ fit lm(yield~nitrogen) แล้วดู diagnostic plot residual กระจายไม่สม่ำเสมอ และ Box-Cox แนะนำให้แปลงข้อมูล (ไม่ใช่ \(\lambda=1\) ซึ่งคือไม่ต้องแปลงเลย) — บ่งชี้ปัญหา variance ไม่คงที่แบบเดียวกับที่ Lesson 13 หัวข้อ 2 อธิบาย
  • เมื่อโจทย์บอกให้ "develop a GLM ... that does not (explicitly) transform the response" นี่คือคำเชิญตรง ๆ ให้ใช้ Gamma GLM แทนการ log/cube แปลงตัวแปรตอบสนองเอง — yield เข้าเกณฑ์ทั้งหมดของ Lesson 13 หัวข้อ 1: ต่อเนื่อง เป็นบวกเสมอ และเบ้
คำถาม 1ทำไมต้อง Gamma GLM
ข้อใดอธิบายได้ดีที่สุดว่าทำไมข้อมูล cornnit (yield ~ nitrogen) เข้าเกณฑ์ที่ควรพิจารณา Gamma GLM แทน normal linear regression ตรง ๆ?

  • กราฟ log-likelihood เทียบ \(\lambda\) (ทดสอบตั้งแต่ −5 ถึง 5) มียอด (จุดที่ likelihood สูงสุด) อยู่ในช่วงประมาณ \(\lambda \approx 2\) ถึง \(3\) และเส้นประแนวตั้งที่ทำเครื่องหมาย 95% CI ของ \(\lambda\) ก็คร่อมช่วงประมาณ 1.5 ถึง 4 — ไม่รวม \(\lambda = 1\) (คือ "ไม่ต้องแปลงอะไรเลย") อยู่ในช่วงนั้น จึงยืนยันว่าจำเป็นต้องแปลงตัวแปรตอบสนองจริง ๆ

คำถาม 2 (Free response)ปัญหาของการแปลงข้อมูลด้วย Power Transform
อธิบายด้วยคำพูดของตัวเองว่าทำไมโมเดล lm(I(yield^3)~nitrogen) ถึงแม้จะผ่านเกณฑ์ Box-Cox แล้ว แต่ก็ยังมีปัญหาในทางปฏิบัติ — และสิ่งนี้ชี้ไปทางทางออกแบบใด
แม้ \(y^3\) จะอยู่ในช่วง 95% CI ของ Box-Cox และทำให้ \(R^2\) ดีขึ้นเล็กน้อย แต่สัมประสิทธิ์ที่ได้ (7,278) อยู่บนสเกลของ "ยกกำลังสามของผลผลิต" ซึ่งไม่มีความหมายที่ตีความได้ง่ายในหน่วยจริง (บุชเชล/เอเคอร์) — ต้อง back-transform (ถอดรากที่สาม) กลับไปมาซึ่งไม่ตรงไปตรงมาและทำให้ค่าคาดการณ์เพี้ยนจาก Jensen's inequality ทางออกที่ Lesson 13 เสนอไว้คือใช้ Gamma GLM ซึ่งจับ variance function ที่เป็นรูปกำลังสองของค่าเฉลี่ยได้โดยตรง โดยไม่ต้องแปลงตัวแปรตอบสนองเลย แล้วเลือก link function ที่ทำให้แปลผลง่าย (เช่น log หรือ identity) แทน

3. เส้นทางที่สอง (Part b): Gamma GLM ด้วย 3 Link Functions

โจทย์ให้ fit yield~nitrogen ด้วย Gamma family แต่เปลี่ยน link function 3 แบบ — ตรงกับตารางในหัวข้อ 3 ของ Lesson 13 (canonical/inverse, log, linear/identity) พอดี

  • Inverse link คือ canonical link ของ Gamma (\(\eta = 1/\mu\)) ตามที่ Lesson 13 หัวข้อ 3 อธิบายไว้
  • ระวังทิศทางเครื่องหมาย — สัมประสิทธิ์ nitrogen = −1.027e-05 เป็นลบ แต่ไม่ได้แปลว่าไนโตรเจนลดผลผลิต! เพราะโมเดลอยู่บนสเกล \(1/\mu\) ไม่ใช่ \(\mu\): เมื่อ \(1/\mu\) ลดลง แปลว่า \(\mu\) (ผลผลิตเฉลี่ย) เพิ่มขึ้น — ทิศทางเดียวกับอีกสองโมเดล ไม่ใช่ตรงข้าม
  • เช็คความสมเหตุสมผล: ที่ nitrogen = 0, \(1/\mu = 9.134\text{e-}03 \implies \mu \approx 109.5\) บุชเชล/เอเคอร์ — ใกล้เคียงกับอีกสองโมเดล

4. เปรียบเทียบทั้ง 3 Link Function ด้วย AIC และ Deviance

เพราะทั้งสามโมเดลใช้ Gamma family เดียวกัน ต่างกันแค่ link function — เปรียบเทียบ AIC กันได้ตรง ๆ (หลักการเดียวกับที่ Lesson 13 หัวข้อ 8 เปรียบเทียบ 3 link ของ inverse Gaussian GLM ในตัวอย่าง Life Test)

Log \((\eta=\log\mu)\)0.0015178409.081.62721
Identity \((\eta=\mu)\)0.22554406.09 (ต่ำสุด)1.52081

  • ทั้งสามโมเดลผ่าน goodness-of-fit test เท่ากันหมด (\(1-\text{pchisq}=1\) ทุกแบบ) — เกณฑ์นี้แยกไม่ออกว่า link ไหนดีกว่ากัน ต้องใช้ AIC ตัดสินแทน (เหมือนสถานการณ์ในตัวอย่าง Life Test ของ Lesson 13)
  • Identity link ชนะด้วย AIC ต่ำสุด (406.09) รองลงมาคือ log link (409.08) และ inverse link แพ้ที่สุด (411.38)
  • เหตุผลที่โจทย์ให้ไว้ตรง ๆ: "we pick the model 2 with identity link due to the lowest AIC"
สรุปผลลัพธ์สุดท้าย — เทียบกับ Part (a)

โมเดลที่เลือก: Gamma GLM, identity link — \(\mu_i = 102.79382 + 0.22554 \times \text{nitrogen}_i\)

การแปลผล: "ไนโตรเจนเพิ่มขึ้น 1 ปอนด์/เอเคอร์ สัมพันธ์กับผลผลิตข้าวโพดเฉลี่ยเพิ่มขึ้นประมาณ 0.23 บุชเชล/เอเคอร์" — ตรงไปตรงมา ไม่ต้อง back-transform ใด ๆ

เทียบกับโมเดล Part (a) ที่ใช้ \(y^3\) เป็นตัวแปรตอบสนอง (สัมประสิทธิ์ nitrogen = 7,278 บนสเกล "ยกกำลังสามของผลผลิต" ซึ่งตีความยาก) — Gamma GLM ด้วย identity link ให้การแปลผลที่ง่ายกว่ามาก โดยยังคงจับลักษณะ variance ที่ไม่คงที่ของข้อมูลได้ถูกต้อง (variance function \(\propto\mu^2\)) โดยไม่ต้องแปลงตัวแปรตอบสนองเลย — นี่คือข้อได้เปรียบหลักของ GLM เหนือ power-transform ตามที่โจทย์สรุปไว้

คำถาม 8 (Free response)สรุปเปรียบเทียบ Part (a) กับ Part (b)
สรุปว่าทำไม Gamma GLM (identity link) ในส่วน (b) ถึงเป็นทางออกที่ดีกว่าการแปลงตัวแปรตอบสนองด้วย power transform ในส่วน (a) — ให้ยกตัวเลขจริงจากทั้งสองโมเดลมาเปรียบเทียบ
โมเดล Part (a) ใช้ \(y^3\) เป็นตัวแปรตอบสนองเพื่อให้ผ่านเกณฑ์ Box-Cox แต่สัมประสิทธิ์ที่ได้ (nitrogen = 7,278) อยู่บนสเกล "ยกกำลังสามของผลผลิต" ซึ่งไม่มีความหมายที่จับต้องได้ ต้อง back-transform กลับไปกลับมาซึ่งซับซ้อนและเพี้ยนจาก Jensen's inequality ในทางตรงข้าม Gamma GLM ด้วย identity link ในส่วน (b) จับ variance function \(\propto\mu^2\) ของข้อมูลได้โดยตรงจากธรรมชาติของ distribution โดยไม่ต้องแปลงตัวแปรตอบสนองเลย และให้สัมประสิทธิ์ nitrogen = 0.22554 ที่แปลผลได้ตรงตัวทันทีว่า "ไนโตรเจนเพิ่ม 1 ปอนด์/เอเคอร์ ผลผลิตเฉลี่ยเพิ่มขึ้น 0.2255 บุชเชล/เอเคอร์" — ง่ายกว่าและตรงไปตรงมากว่าการอ่านผลบนสเกลยกกำลังสามมาก AIC ของโมเดล identity link (406.09) ยังต่ำที่สุดในบรรดา Gamma GLM ทั้งสาม link ที่ลองด้วย

คำถาม 10 (Free response)เทียบ IG GLM (3b) กับ OLS แปลงตัวแปร (3a)
เทียบข้อดี-ข้อเสียของการฟิต Inverse Gaussian GLM บนสเกลเดิม (ข้อ 3b) กับการแปลงตัวแปรตอบสนองด้วย Box-Cox แล้วฟิต OLS (ข้อ 3a) สำหรับข้อมูล rats ชุดนี้
ข้อ 3a ต้องหา λ≈-1 จาก Box-Cox แล้วฟิต OLS บน 1/time — ตีความสัมประสิทธิ์ยากเพราะอยู่บนสเกล "ส่วนกลับของเวลา" และ interaction บางพจน์เปลี่ยนนัยสำคัญไปหลังแปลง (poisonIII:treatB จาก p=0.0276 เป็น p=0.364) ทำให้ต้องระวังเรื่องการตีความ interaction บนสเกลที่แปลงแล้ว ข้อ 3b (Inverse Gaussian GLM, identity link) ให้สัมประสิทธิ์ตรงบนสเกลเวลาดิบเลย (เหมือน OLS ธรรมดาทุกตัวเลขจุดประมาณ) แต่ SE ถูกต้องกว่าเพราะสมมติ variance function ที่เหมาะกับข้อมูลบวกเบ้ขวาแบบนี้ (\(\propto\mu^3\)) โดยไม่ต้องแปลงตัวแปรตอบสนองเลย ข้อดีของ 3b คือตีความง่ายกว่าไม่ต้อง back-transform แต่ข้อดีของ 3a คือใช้เครื่องมือ OLS มาตรฐานที่คุ้นเคยกว่า
