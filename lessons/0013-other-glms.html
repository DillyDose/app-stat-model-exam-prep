Lecture 13 — Other GLMs

Other GLMs: Gamma และ Inverse Gaussian สำหรับข้อมูลต่อเนื่องเบ้ขวา

Lecture 8 วางกรอบ GLM ทั่วไปไว้แล้ว (exponential family, link function, canonical link, deviance) และ Binomial/Poisson เป็น GLM ที่ใช้บ่อยที่สุดสำหรับข้อมูลนับ/สัดส่วน บทนี้ขยายไปยัง 2 family ที่ใช้น้อยกว่าแต่สำคัญมากสำหรับข้อมูลต่อเนื่อง เป็นบวกเสมอ และเบ้ขวา (เช่น เวลาถึงจุดเสียหาย, ค่าใช้จ่ายเคลมประกัน, ความต้านทานไฟฟ้า) — Gamma GLM และ Inverse Gaussian GLM. ตามลำดับความสำคัญของวิชานี้ บทเรียนนี้เน้น 3 อย่าง: เขียนสมการโมเดลของแต่ละ family ให้ถูก (พร้อม link function ที่เหมาะสม), เช็คได้ว่าโมเดลไหน/link ไหนดีกว่ากัน จาก deviance และ AIC ใน R output จริง, และแปลผลสัมประสิทธิ์ ด้วย \(\exp(\hat\beta)\) เมื่อใช้ log link — เหมือนหลักการเดียวกับ Poisson regression ที่เคยเรียนมา

1. ทำไมต้องมี GLM แบบอื่นนอกจาก Normal/Poisson/Binomial

สไลด์เปิดเรื่องตรง ๆ: Binomial, Gaussian, และ Poisson เป็น GLM ที่ใช้บ่อยที่สุด ส่วน gamma และ inverse Gaussian เป็น GLM ที่ใช้น้อยกว่า และถูกออกแบบมาสำหรับข้อมูลต่อเนื่องที่เบ้ (skewed) โดยเฉพาะ — นี่คือจุดต่างสำคัญจาก normal linear regression ที่สมมติ error แจกแจงแบบสมมาตร (normal) รอบเส้นถดถอย

คำถาม 1Motivation
ข้อมูลชุดหนึ่งเป็นค่าใช้จ่ายในการซ่อมเครื่องจักร (บาท) ซึ่งเป็นบวกเสมอและมีการกระจายเบ้ขวาอย่างชัดเจน (ส่วนใหญ่ค่าซ่อมน้อย มีบางเครื่องซ่อมแพงมาก) เหตุผลใดอธิบายได้ดีที่สุดว่าทำไม normal linear regression ไม่เหมาะกับข้อมูลนี้?

2. ที่มาของ Gamma GLM: ปัญหา Variance ไม่คงที่แบบ Quadratic

Normal linear regression เขียนเป็น \(Y = X\beta + \varepsilon\), \(\varepsilon \sim N(0, \sigma^2 I)\) ซึ่งสมมติ \(\text{Var}(Y_i) = \sigma^2\) คงที่ทุกจุด (variance function \(\text{Var}(\mu_i) = \phi\)) สไลด์ตั้งคำถาม: ถ้าสมมตินี้ผิด และ variance กลับเป็นรูปกำลังสองของค่าเฉลี่ย คือ \(\text{Var}(Y_i) = \sigma^2\mu_i^2\) (variance function \(\text{Var}(\mu_i) = \phi\mu_i^2\)) จะแก้ปัญหานี้อย่างไร?

คำตอบที่สไลด์เสนอ: แปลง log ตัวแปรตอบสนอง (log-normal model) พิสูจน์ด้วย Taylor expansion อันดับ 1 ของ \(Z_i = \log(Y_i)\) รอบ \(\mu_i\):

\(Z_i = \log(Y_i) \approx \log(\mu_i) + \dfrac{1}{\mu_i}(Y_i - \mu_i)\)
\(\implies\) \(E[Z_i] \approx \log(\mu_i)\)
และเมื่อคำนวณ \(E[Z_i^2]\) ต่อด้วยสูตรเดียวกัน จะได้ \(\text{Var}(Z_i) \approx \sigma^2\) (ไม่ขึ้นกับ \(\mu_i\) อีกต่อไป!)

อ่านผลลัพธ์นี้ให้ทะลุ — เทียบก่อน/หลัง แปลง log:

  • ก่อน แปลง log: variance ของ \(Y_i\) คือ \(\sigma^2\mu_i^2\) — โตขึ้นเรื่อย ๆ ตามค่าเฉลี่ย (สังเกตข้อมูล mean สูงจะกระจายกว้างกว่าข้อมูล mean ต่ำ)
  • หลัง แปลง log: variance ของ \(Z_i = \log(Y_i)\) กลายเป็น \(\sigma^2\) คงที่แล้ว ไม่ขึ้นกับ \(\mu_i\) อีกต่อไป — นี่คือความหมายของคำว่า "log transformation stabilizes the variance" พอดี
  • ถ้า variance รูปแบบ quadratic เกิดขึ้นจริง การ log ตัวแปรตอบสนองก่อน fit normal linear regression จะทำให้ constant-variance assumption กลับมาใช้ได้

สไลด์ระบุทางเลือกที่สองด้วย: ถ้าอยากทำงานบนสเกลเดิมของ Y (ไม่อยาก log ก่อน แล้วต้อง back-transform ทีหลัง) gamma regression คือทางแก้อีกทาง — เพราะ gamma distribution มี variance function เป็นรูปกำลังสองของ \(\mu\) โดยธรรมชาติอยู่แล้ว (จะเห็นในหัวข้อถัดไป) จึงจับ pattern \(\text{Var}(Y_i) \propto \mu_i^2\) ได้ตรง ๆ โดยไม่ต้องแปลงตัวแปรก่อน

คำถาม 2 (Free response)Variance Stabilizing Transformation
อธิบายด้วยคำพูดของตัวเองว่าทำไม \(\text{Var}(Y_i) = \sigma^2\mu_i^2\) (variance โตตามค่าเฉลี่ยแบบกำลังสอง) ถึงทำให้การ log-transform ตัวแปรตอบสนองได้ผลลัพธ์ที่มี variance คงที่ (\(\text{Var}(Z_i) \approx \sigma^2\)) และมีทางเลือกอื่นที่ไม่ต้อง log หรือไม่
Taylor expansion ของ \(\log(Y_i)\) รอบ \(\mu_i\) ให้ \(Z_i \approx \log(\mu_i) + \dfrac{Y_i-\mu_i}{\mu_i}\) — สังเกตว่าพจน์ที่มีความสุ่ม \(\dfrac{Y_i-\mu_i}{\mu_i}\) ถูกหารด้วย \(\mu_i\) ก่อน ซึ่งพอดีกับที่ \(Y_i - \mu_i\) มี SD เป็น \(\sigma\mu_i\) (เพราะ \(\text{Var}(Y_i)=\sigma^2\mu_i^2\)) — หารด้วย \(\mu_i\) แล้ว SD ที่เหลือกลายเป็น \(\sigma\) คงที่พอดี ไม่ขึ้นกับ \(\mu_i\) อีกต่อไป นี่คือกลไกที่ log ทำให้ variance เสถียร ทางเลือกอื่นที่ไม่ต้อง log (ทำงานบนสเกลเดิมของ Y โดยตรง) คือใช้ gamma GLM ซึ่งมี variance function เป็น \(\mu^2\) อยู่แล้วในตัว

3. Gamma Distribution และ GLM Setup

Gamma density เขียนทั่วไปเป็น \(f(y) = \dfrac{1}{\Gamma(\nu)} \lambda^\nu y^{\nu-1} e^{-\lambda y}\), \(y > 0\) โดย \(\nu\) คือ shape parameter และ \(\lambda\) คือ scale parameter สไลด์ reparameterize โดยแทน \(\lambda = \dfrac{\nu}{\mu}\) เพื่อให้อยู่ในรูป GLM:

\(f(y) = \dfrac{1}{\Gamma(\nu)} \left(\dfrac{\nu}{\mu}\right)^\nu y^{\nu-1} \exp\!\left(-\dfrac{y\nu}{\mu}\right)\),  \(y > 0\)
\(\implies\) \(E[Y] = \mu\),  \(\text{Var}(Y_i) = \dfrac{\mu^2}{\nu}\)
\(\implies\) canonical parameter \(\theta = -\dfrac{1}{\mu}\), dispersion \(\phi = \nu^{-1}\), \(a(\phi) = \phi\), \(b(\theta) = \log(1/\mu) = -\log(-\theta)\), variance function \(b''(\theta) = \mu^2\)

อ่านความหมาย: \(\text{Var}(Y_i) = \dfrac{\mu_i^2}{\nu}\) คือรูป \(\text{Var}(Y_i) \propto \mu_i^2\) ที่หัวข้อ 2 พูดถึงพอดี — \(\nu\) ทำหน้าที่เหมือน "ตัวหารความแปรปรวน" ตัวเดียวกันทุกจุดข้อมูล (จึงเป็น dispersion parameter \(\phi=\nu^{-1}\) ไม่ขึ้นกับ X) ในขณะที่ตัวแปรผันตามค่าเฉลี่ยจริง ๆ คือ \(\mu^2\)

Canonical parameter \(\theta=-1/\mu\) บอกว่า canonical link คือ \(\eta=-1/\mu\) แต่ในทางปฏิบัติมักตัดเครื่องหมายลบทิ้งแล้วใช้ \(\eta=1/\mu\) (inverse link) แทน

3 ทางเลือกของ Link Function สำหรับ Gamma GLM

สไลด์ให้เหตุผลการเลือก link แต่ละแบบไว้ชัดเจน ไม่ใช่แค่รายชื่อสูตร:

Linkสูตรเมื่อไรควรใช้ (ตามที่สไลด์ระบุ)
Canonical (inverse)\(\eta = \dfrac{1}{\mu}\)ไม่การันตีว่า \(\mu > 0\) (อาจมีปัญหา) — เหมาะเมื่อรู้อยู่แล้วว่า mean response มีขอบเขต (bounded)
Log\(\eta = \log(\mu)\)ควรใช้เมื่อสงสัยว่าผลของตัวแปรอิสระเป็นแบบ คูณ (multiplicative) กับค่าเฉลี่ย — เมื่อ variance เล็ก จะให้ผลใกล้เคียงกับ Gaussian model ที่ log ตัวแปรตอบสนองแล้ว
Linear\(\eta = \mu\)เหมาะกับการโมเดล sum of squares หรือ variance component ที่เป็น \(\chi^2\) (กรณีพิเศษของ gamma ที่ \(\lambda=1/2,\ \nu=df/2\))

ในทางปฏิบัติ log link เป็นตัวที่ใช้บ่อยที่สุด เพราะทำให้แปลผลสัมประสิทธิ์ได้ง่ายแบบเดียวกับ Poisson regression: \(\log(\mu_i) = X_i\beta \implies \mu_i = \exp(\beta_0)\cdot\exp(\beta_1 x_{1i})\cdots\exp(\beta_p x_{pi})\) — ผลของแต่ละ X เป็นตัวคูณเข้ากับค่าเฉลี่ย ไม่ใช่บวก จึงต้องแปลผลด้วย \(\exp(\hat\beta)\) เสมอ ไม่ใช่ \(\hat\beta\) ตรง ๆ

คำถาม 3เลือก Link Function
นักวิเคราะห์สงสัยว่าตัวแปรอิสระแต่ละตัวมีผล "คูณ" (เช่น เพิ่มค่าเฉลี่ยขึ้น 20% ต่อหน่วย ไม่ใช่บวกคงที่) กับค่าเฉลี่ยของ response ที่เป็น gamma ควรเลือก link function แบบใด?

5. ตัวอย่างที่ 2: Payments on Insurance Claims — Offset + การแปลผล

ข้อมูล Hallin & Ingenbleek (1983): ค่าสินไหมประกันรถยนต์ในสวีเดนปี 1977 แบ่งตามระยะทางที่ขับ (Kilometres), ระดับ bonus จากการไม่เคลม (Bonus), และประเภทรถ (Make) เนื่องจากยอดรวมค่าสินไหมของแต่ละกลุ่มควรเป็นสัดส่วนกับจำนวนกรมธรรม์ (Insured, policy-years) ในกลุ่มนั้น สไลด์จึงใส่ offset(log(Insured)) เข้าไปในโมเดล — หลักการเดียวกับที่ Poisson regression ใช้ offset เพื่อโมเดลอัตรา (rate) แทนยอดรวมดิบ ๆ:

เพราะ log link ทำให้ผลของ X เป็นตัวคูณ (multiplicative) จึงต้องยกกำลัง exp() ก่อนแปลผล เสมอ ไม่ใช่อ่าน \(\hat\beta\) ตรง ๆ แบบ linear regression:

  • Bonus: \(\hat\beta = -0.20069 \implies \exp(-0.20069) = 0.8182\) — "เมื่อ Bonus เพิ่มขึ้น 1 ระดับ ค่าสินไหมเฉลี่ยต่อกรมธรรม์คาดว่าจะลดลง 18.18% โดยประมาณ (คูณด้วย 0.8182) เมื่อควบคุม Kilometres และ Make ให้คงที่ — อย่างมีนัยสำคัญทางสถิติ (p<2e-16)"
  • Make8: \(\hat\beta = 0.75038 \implies \exp(0.75038) = 2.1178\) — "รถประเภท Make8 มีค่าสินไหมเฉลี่ยต่อกรมธรรม์สูงกว่ารถประเภทฐาน (Make1) โดยประมาณ 111.78% (หรือคูณด้วย 2.12 เท่า) เมื่อควบคุมตัวแปรอื่นให้คงที่"
  • as.numeric(Kilometres): \(\hat\beta = 0.12007 \implies \exp(0.12007) = 1.1276\) — "เมื่อระดับระยะทางขับเพิ่มขึ้น 1 หน่วย ค่าสินไหมเฉลี่ยคาดว่าจะเพิ่มขึ้นโดยประมาณ 12.76% เมื่อควบคุมตัวแปรอื่น"

สังเกตรูปแบบที่ใช้ซ้ำได้เสมอ: \(\hat\beta > 0 \implies \exp(\hat\beta) > 1 \implies\) ค่าเฉลี่ยเพิ่มขึ้น, \(\hat\beta < 0 \implies \exp(\hat\beta) < 1 \implies\) ค่าเฉลี่ยลดลง — เปอร์เซ็นต์การเปลี่ยนแปลงคือ \((\exp(\hat\beta) - 1) \times 100\%\)

6. Inverse Gaussian GLM

Inverse Gaussian เป็นอีก family สำหรับข้อมูลต่อเนื่องบวกเบ้ขวา แต่มี variance function ที่ "แรง" กว่า gamma:

\(f(y|\mu,\lambda) = \sqrt{\dfrac{\lambda}{2\pi y^3}} \exp\!\left(-\dfrac{\lambda(y-\mu)^2}{2\mu^2 y}\right)\),  \(y, \mu, \lambda > 0\)
\(\implies\) \(E[Y]=\mu\),  \(\text{Var}(Y)=\dfrac{\mu^3}{\lambda}\)
\(\implies\) canonical parameter \(\theta=-1/\mu^2\), dispersion \(\phi=2/\lambda\), \(a(\phi)=\phi=2/\lambda\), \(b(\theta)=-2/\mu=-2\sqrt{-\theta}\), variance function \(V(\mu)=\mu^3\)

Canonical link คือ \(\eta=1/\mu^2\) ส่วน link ทางเลือกอื่นที่ใช้ได้คือ inverse (\(\eta=1/\mu\)), identity (\(\eta=\mu\)), และ log (\(\eta=\log \mu\)) — สังเกตความต่างจาก gamma: variance function ของ inverse Gaussian คือ \(\mu^3\) ในขณะที่ gamma คือ \(\mu^2\) — เลขชี้กำลังสูงกว่าหมายความว่า variance ของ inverse Gaussian โตเร็วกว่าตามค่าเฉลี่ย

กรณีพิเศษ \(\mu=1\) เรียกว่า Wald distribution ภาพต่อไปนี้แสดงรูปทรงของ density เมื่อ \(\lambda\) เปลี่ยนค่า:

อ่านตัวเลขในภาพ: ทั้งสามกราฟใช้ \(\mu=1\) เหมือนกัน แต่ปรับ \(\lambda\) จาก 0.5 → 1 → 5:

  • ยอดของ density (mode) ขยับเข้าใกล้ 1 มากขึ้นเรื่อย ๆ และแคบลง เมื่อ \(\lambda\) เพิ่ม — จากยอดสูงสุดที่ประมาณ 1.4 ใกล้ 0 ตอน \(\lambda=0.5\) ไปเป็นยอดที่ประมาณ 1.1 ใกล้ x=1 ตอน \(\lambda=5\)
  • ตรงกับสูตร \(\text{Var}(Y)=\dfrac{\mu^3}{\lambda}\) พอดี: \(\lambda\) มากขึ้น \(\implies\) variance น้อยลง \(\implies\) การกระจายแคบลงและสมมาตรมากขึ้นรอบ \(\mu\)
  • ทุกกราฟยังคงเบ้ขวาชัดเจน (หางขวายาว) ซึ่งเป็นลักษณะร่วมของทั้ง gamma และ inverse Gaussian ตามที่กล่าวไว้ในหัวข้อถัดไป

รวมทุกอย่างจาก 3 ตัวอย่างเป็นตารางเปรียบเทียบกลาง ๆ ที่ใช้ตอบข้อสอบได้ทันที:

Familyข้อมูลที่เหมาะสมVar(Y)Link ที่นิยมสมการโมเดล (log link)การแปลผล \(\hat\beta\)
Gammaต่อเนื่อง เป็นบวกเสมอ เบ้ขวา (เช่น ค่าใช้จ่ายเคลม, resistivity)\(\propto \mu^2\)log (multiplicative), canonical/inverse \((\eta=1/\mu)\), linear \((\eta=\mu\), สำหรับ \(\chi^2)\)\(\log(\mu_i)=X_i\beta\)\(\exp(\hat\beta)\) = ตัวคูณของค่าเฉลี่ยต่อการเพิ่ม X 1 หน่วย; % เปลี่ยนแปลง = \((\exp(\hat\beta)-1)\times100\%\)
Inverse Gaussianต่อเนื่อง เป็นบวกเสมอ เบ้ขวารุนแรงกว่า มีค่าสุดโต่งมากกว่า Gamma\(\propto \mu^3\)canonical \((\eta=1/\mu^2)\), inverse \((\eta=1/\mu)\), identity \((\eta=\mu)\), logขึ้นกับ link ที่เลือก เช่น \(\dfrac{1}{\mu_i}=X_i\beta\) ถ้าใช้ inverse linkถ้าใช้ log link: แปลผลแบบ \(\exp(\hat\beta)\) เหมือน Gamma; ถ้า link อื่น (identity/inverse) ต้องอ่านทิศทาง (บวก/ลบ) ของผลต่อ \(\eta\) โดยตรง ซึ่งตีความยากกว่า

วิธีเลือกระหว่างสอง family:

  1. ถ้า response บวกเบ้ขวาปกติ ให้เริ่มจาก Gamma เป็นค่าเริ่มต้น
  2. ถ้ามีค่าสุดโต่งมากกว่าปกติ (heavy tail ชัดเจน เช่น histogram มีจุดหลุดไปไกลจากกลุ่มหลัก) ลอง Inverse Gaussian เพิ่ม
  3. เปรียบเทียบ AIC/deviance ระหว่าง link ภายใน family เดียวกันได้ตรง ๆ แต่เทียบข้าม family/distribution ต้องระวัง (ดูหัวข้อ 5–6)

ชัยชนะของบทเรียนนี้

ตอนนี้คุณควรบอกได้ว่าเมื่อ response เป็นข้อมูลต่อเนื่องบวกเบ้ขวา ควรเลือก Gamma GLM (variance \(\propto\mu^2\)) หรือ Inverse Gaussian GLM (variance \(\propto\mu^3\) — เมื่อมี extreme values มากกว่า) และเมื่อเลือกได้แล้ว คุณควรทำสิ่งต่อไปนี้ได้:

  • เขียนสมการโมเดลพร้อม link function ที่เหมาะสม (มักเป็น log link เมื่อสงสัยผลแบบ multiplicative)
  • แปลผลสัมประสิทธิ์ด้วย \(\exp(\hat\beta)\) แบบเดียวกับ Poisson regression ที่เคยเรียนมา
  • อ่าน dispersion parameter และ deviance จาก R output เพื่อทำ goodness-of-fit test (1-pchisq(deviance, df))
  • เลือก link function ที่ดีที่สุดด้วยการเทียบ AIC ภายใน family เดียวกัน — พร้อมรู้ข้อจำกัดว่าเมื่อไรเทียบ AIC/LRT ข้าม distribution ไม่ได้เลย
