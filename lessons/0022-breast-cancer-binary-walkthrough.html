Breast Cancer Diagnosis: เดินตามโจทย์จริงทีละข้อ (Binary Logistic Regression)

บทเรียนนี้ต่อยอดจาก Lesson 9: Binary Data โดยตรง — เอาทุกทักษะที่เรียนไป (เขียนสมการ logistic regression, อ่าน summary(glm(family=binomial)), Hosmer-Lemeshow, AIC-based model selection, interpretation template แบบ log-odds/odds ratio/probability, confusion matrix, และ ROC/AUC) มาใช้กับโจทย์ข้อสอบจริงข้อเดียวแบบครบทุกข้อย่อย (a)–(g) เพื่อฝึกลำดับการคิดที่ข้อสอบจะถามจริง ๆ ไม่ใช่แค่เนื้อหาแยกส่วนแบบใน Lesson 9.

ที่มาของข้อมูล: data(wbca, package="faraway") — การศึกษามะเร็งเต้านมที่วิสคอนซิน มีเนื้องอกที่สงสัยว่าอาจเป็นมะเร็ง 681 ก้อน ซึ่ง 238 ก้อนเป็นมะเร็งจริง (malignant) วิธีมาตรฐานในการวินิจฉัยคือการผ่าตัดตรวจชิ้นเนื้อ (invasive) งานวิจัยนี้ทดสอบว่าวิธีใหม่ที่เรียกว่า fine needle aspiration (เจาะดูดตัวอย่างเนื้อเยื่อปริมาณน้อย ไม่ต้องผ่าตัด) จะใช้ทำนายสถานะเนื้องอกได้แม่นยำแค่ไหน — ตัวแปรตาม Class คือผลวินิจฉัย (1=benign ไม่ใช่มะเร็ง, 0=malignant เป็นมะเร็ง) และตัวแปรอิสระ 9 ตัวเป็นคะแนนลักษณะเซลล์จากการดูด้วยกล้องจุลทรรศน์ (สเกล 1–10 ยิ่งสูงยิ่งผิดปกติ): Adhes (marginal adhesion), BNucl (bare nuclei), Chrom (bland chromatin), Epith (epithelial cell size), Mitos (mitoses), NNucl (normal nucleoli), Thick (clump thickness), UShap (cell shape uniformity), USize (cell size uniformity).

แปลผล Odds Ratio ของตัวแปรที่มีนัยสำคัญ (แสดงเลขจริง)

ใช้ interpretation template จาก Lesson 9: odds ของ [outcome=1] เปลี่ยนเป็น \(\exp(\hat\beta_k)\) เท่า ทุก 1 หน่วยที่ X_k เพิ่มขึ้น โดยตัวแปรอื่นคงที่ — คำนวณ \(\exp(\hat\beta_k)\) จากสัมประสิทธิ์จริงในตารางข้างบน:

  • Adhes (β̂=−0.39681): \(\exp(-0.39681) = 0.6725\) — เมื่อ marginal adhesion เพิ่มขึ้น 1 หน่วย (ตัวแปรอื่นคงที่) odds ของการเป็น benign ลดลงเหลือ 67.25% ของเดิม หรือกลับเศษส่วน \(1/0.6725 \approx 1.487\) — odds ของการเป็นมะเร็งเพิ่มขึ้นประมาณ 1.49 เท่าต่อคะแนน adhesion ที่เพิ่มขึ้น 1 หน่วย
  • BNucl (β̂=−0.41478): \(\exp(-0.41478) = 0.6605\) — odds ของ benign ลดลงเหลือ 66.05% ของเดิมต่อคะแนน bare nuclei ที่เพิ่มขึ้น 1 หน่วย (ตัวแปรอื่นคงที่) — นี่คือตัวแปรที่มีนัยสำคัญที่สุดในตาราง (p=5.02e-05)
  • Chrom (β̂=−0.56456): \(\exp(-0.56456) = 0.5686\) — odds ของ benign ลดลงเหลือ 56.86% ของเดิม (เกือบครึ่งหนึ่ง) ต่อคะแนน bland chromatin ที่เพิ่มขึ้น 1 หน่วย
  • NNucl (β̂=−0.28659): \(\exp(-0.28659) = 0.7508\) — odds ของ benign ลดลงเหลือ 75.08% ของเดิมต่อคะแนน normal nucleoli ที่เพิ่มขึ้น 1 หน่วย
  • Thick (β̂=−0.62675): \(\exp(-0.62675) = 0.5343\) — odds ของ benign ลดลงเหลือ 53.43% ของเดิม (ลดลงเกือบครึ่ง) ต่อคะแนน clump thickness ที่เพิ่มขึ้น 1 หน่วย โดยตัวแปรอื่นคงที่ — effect size ใหญ่เป็นอันดับสองรองจาก Chrom

ตัวแปรทั้งห้าตัวนี้ล้วนมีเครื่องหมายลบและ \(\exp(\hat\beta_k) < 1\) สอดคล้องกัน — ยิ่งคะแนนลักษณะเซลล์เหล่านี้สูง (ยิ่งดูผิดปกติ) โอกาสที่เนื้องอกจะเป็น benign ยิ่งลดลง ตรงตามความคาดหวังทางคลินิก

(d) ทำนายผู้ป่วยใหม่ด้วยตัวแบบลดรูป — Point Estimate และ CI

ผู้ป่วยใหม่มีค่าตัวแปร (ตามลำดับ Adhes, BNucl, Chrom, Epith, Mitos, NNucl, Thick, UShap, USize) = 1, 1, 3, 2, 1, 1, 4, 1, 1 — สังเกตว่า reducedmod ไม่ได้ใช้ Epith กับ USize เลย (ถูกตัดออกในข้อ c) แต่ในโค้ด newdata ยังใส่ครบทุกตัวได้เพราะ R จะเลือกใช้เฉพาะคอลัมน์ที่โมเดลต้องการ:

> eta_CI<-c(eta$fit-1.96*eta$se.fit, eta$fit+1.96*eta$se.fit)
> ilogit(eta_CI)
        1         1
0.9738671 0.9972192
  • ทำไมต้องคำนวณ CI บน scale ของ η ก่อน: \(\hat\beta\) มีการแจกแจงแบบ normal โดยประมาณ (asymptotic MLE property) แต่ \(\hat\pi\) ไม่ได้เป็น normal เพราะผ่าน logistic function ที่ไม่เชิงเส้น — ต้องสร้าง CI บน η ก่อนด้วย \(\hat\eta \mp 1.96 \times SE(\hat\eta)\) แล้วค่อยแปลงกลับด้วย logistic function (การแปลงแบบ monotonic รักษาลำดับ endpoint)
  • คำนวณตรวจสอบ: η̂ = 4.750162, SE = 0.5775932 → η_lower = 4.750162 − 1.96×0.5775932 = 3.6181, η_upper = 4.750162 + 1.96×0.5775932 = 5.8822
  • แปลงกลับด้วย ilogit: π_lower = e^3.6181/(1+e^3.6181) = 0.9739, π_upper = e^5.8822/(1+e^5.8822) = 0.9972 — ตรงกับผลลัพธ์ในสไลด์
  • ประโยคแปลผล: "สำหรับผู้ป่วยที่มีคะแนน Adhes=1, BNucl=1, Chrom=3, Mitos=1, NNucl=1, Thick=4, UShap=1 ตัวแบบลดรูปทำนายความน่าจะเป็นที่เนื้องอกจะเป็น benign อยู่ที่ 0.9921 (มั่นใจ 95% ว่าความน่าจะเป็นที่แท้จริงอยู่ระหว่าง 0.9739 ถึง 0.9972)" — ช่วง CI แคบมาก (ทั้งคู่ใกล้ 1) สะท้อนว่าโมเดลมั่นใจสูงมากว่าผู้ป่วยรายนี้เป็น benign

  • แถว 0 (malignant, 238 ราย): ทำนายผิดเป็น benign ลดลงจาก 10 → 2 ราย เท่านั้น — คุมความผิดพลาดที่อันตรายที่สุดได้ดีขึ้นมาก
  • แถว 1 (benign, 443 ราย): ทำนายผิดเป็นมะเร็งเพิ่มขึ้นจาก 9 → 18 ราย — แลกมาด้วยการส่งคนไข้ที่จริง ๆ ไม่เป็นมะเร็งไปตรวจเพิ่มโดยไม่จำเป็นมากขึ้น
  • อัตราความผิดพลาดรวม: (2+18)/681 = 20/681 ≈ 2.94% — สูงกว่า cutoff=0.5 เล็กน้อย (2.79%) แต่ โครงสร้างของความผิดพลาดเปลี่ยนไปในทางที่ปลอดภัยกว่าทางคลินิก
  • ประเด็นในการเลือก cutoff: การเลือก cutoff ไม่ควรดูแค่ "อัตราความผิดพลาดรวมต่ำสุด" เพราะความผิดพลาดสองแบบมีต้นทุนไม่เท่ากัน — cutoff สูงขึ้น (0.9) ทำให้เกณฑ์ตัดสินว่า "benign" เข้มงวดขึ้น (ต้องมั่นใจมากถึงจะจัดว่าไม่เป็นมะเร็ง) ซึ่งเหมาะกับสถานการณ์ที่การพลาดวินิจฉัยมะเร็ง (false negative ในแง่การเป็นมะเร็ง) มีต้นทุนสูงกว่าการส่งตรวจเพิ่มเติมโดยไม่จำเป็น (false positive) มาก — การเลือก cutoff ที่ "ดีที่สุด" จึงขึ้นกับต้นทุนสัมพัทธ์ของความผิดพลาดแต่ละแบบ ไม่ใช่แค่ค่าเริ่มต้น 0.5 เสมอไป
คำถาม 6 (Free response)ทำไมเปลี่ยน cutoff จาก 0.5 เป็น 0.9
เปรียบเทียบ confusion matrix ที่ cutoff=0.5 (ข้อ e) กับ cutoff=0.9 (ข้อ f) จงอธิบายว่าทำไมแพทย์อาจเลือกใช้ cutoff=0.9 ทั้งที่อัตราความผิดพลาดรวมสูงกว่า

ที่ cutoff=0.5 มีเนื้องอกมะเร็งจริง 10 ก้อนถูกจัดว่า benign (พลาดวินิจฉัยมะเร็ง) เทียบกับที่ cutoff=0.9 เหลือเพียง 2 ก้อน — แม้อัตราความผิดพลาดรวมจะเพิ่มขึ้นเล็กน้อย (จาก 19/681≈2.79% เป็น 20/681≈2.94%) เพราะมีเนื้องอก benign ถูกจัดผิดเป็นมะเร็งเพิ่มขึ้น (9→18 ราย) แต่ต้นทุนของความผิดพลาดสองแบบไม่เท่ากันทางคลินิก: การจัดเนื้องอกมะเร็งว่าเป็น benign อาจทำให้ผู้ป่วยไม่ได้รับการรักษาทันเวลา ซึ่งร้ายแรงกว่าการส่งผู้ป่วยที่จริง ๆ ไม่เป็นมะเร็งไปตรวจชิ้นเนื้อเพิ่มเติม (แค่เสียเวลา/ค่าใช้จ่าย ไม่ถึงชีวิต) ดังนั้นการยกระดับ cutoff เป็น 0.9 (ต้องมั่นใจสูงมากก่อนจะฟันธงว่า benign) จึงเป็นการยอมรับ false positive ที่เพิ่มขึ้นเพื่อแลกกับ false negative ที่ลดลง — สอดคล้องกับหลักการที่ว่าการเลือก cutoff ควรพิจารณาต้นทุนสัมพัทธ์ของความผิดพลาดแต่ละแบบ ไม่ใช่แค่ minimize อัตราความผิดพลาดรวม

(g) Train/Test Split, ROC Curve, และ Best Cutoff จากข้อมูลจริง

ข้อ (e) และ (f) ใช้ข้อมูลชุดเดียวกันทั้ง fit และทดสอบ ซึ่งมักให้ผลดีเกินจริง (overly optimistic) — ข้อ (g) แก้ปัญหานี้ด้วยการแบ่งข้อมูล: ทุกๆ ตัวที่ 3 (observation ที่ 3, 6, 9, …) เป็น test set ที่เหลือ 2 ใน 3 เป็น training set:

ROC Curve บน Test Set

> library(pROC)
> prob<-predict(modelAIC, testdata, type="response")
> roc(testdata$Class, prob, plot=TRUE)

Data: prob in 75 controls (testdata$Class 0) < 152 cases (testdata$Class 1).
Area under the curve: 0.9976
  • Test set มี 227 ราย (75 malignant + 152 benign) — คือ 1 ใน 3 ของ wbca ทั้งหมด ตามที่แบ่งไว้
  • AUC = 0.9976 ใกล้ 1.0 มาก (สมบูรณ์แบบ) — แม้ fit บน training set แล้วเอาไปทดสอบกับ test set ที่ไม่เคยเห็นมาก่อน ตัวแบบยังแยกแยะ malignant/benign ได้แม่นยำสูงมาก ยืนยันว่าตัวแบบนี้ generalize ได้ดี ไม่ใช่แค่ overfit กับข้อมูลที่ใช้ fit

สรุปโจทย์ข้อนี้
เดินตามลำดับข้อสอบจริงข้อเดียวครบ 7 ข้อย่อย (a)–(g): fit ตัวแบบเต็ม+เขียนสมการ → เช็ค goodness-of-fit (Hosmer-Lemeshow) → เลือกตัวแบบด้วย AIC (step()) → ทำนายจุดเดียวพร้อม CI (แปลงผ่าน eta ก่อนเสมอ) → confusion matrix ที่ cutoff มาตรฐาน → เปรียบเทียบ cutoff อื่นพร้อมเหตุผลเชิงต้นทุนของความผิดพลาด → train/test split + ROC/AUC + best threshold จากข้อมูลจริง — นี่คือลำดับการคิดที่ครบเกือบทุกทักษะจาก Lesson 9 ในโจทย์เดียว
