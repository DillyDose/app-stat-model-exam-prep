1. Deterministic vs Probabilistic Model — ทำไมต้องมี error term

โมเดล deterministic คำนวณค่าตัวแปรตามได้เป๊ะจากตัวแปรอิสระ เช่น \(\text{Profit} = (\text{Price} - \text{Variable cost}) \times \text{Units sold} - \text{Fixed costs}\) — ใส่ตัวเลขเข้าไปแล้วได้คำตอบเดียวไม่มีความคลาดเคลื่อน. ปัญหาคือข้อมูลจริงไม่เป็นแบบนั้น: บ้านสองหลังขนาดเท่ากันเป๊ะ (ตารางฟุตเท่ากัน) แทบไม่มีทางขายได้ราคาเท่ากันเป๊ะ — มีปัจจัยอื่นที่โมเดลไม่ได้ใส่ (ทำเล สภาพบ้าน ฤดูกาลที่ขาย) ที่ทำให้ราคาจริงเบี่ยงจากที่โมเดลทำนายไว้เสมอ.

Probabilistic model แก้ปัญหานี้โดยเริ่มจากโมเดล deterministic ที่ประมาณความสัมพันธ์ได้ดีที่สุด แล้วบวกพจน์สุ่ม (error term) เข้าไปเพื่อจับความคลาดเคลื่อนที่เหลือ — นี่คือเหตุผลที่ทุกสมการถดถอยในวิชานี้มี \(\varepsilon\) ต่อท้ายเสมอ ไม่ใช่แค่ธรรมเนียมสัญกรณ์.

2. คำศัพท์, ที่มา, และ Association ≠ Causation

ในสมการถดถอย \(X\) เรียก independent/explanatory variable และ \(Y\) เรียก dependent/response variable. เป้าหมายของ regression มี 2 อย่าง: อธิบายความสัมพันธ์ (association) ระหว่าง X กับ Y และทำนาย Y จาก X ในอนาคต — สังเกตว่าไม่มี "อธิบายเชิงเหตุผล (causal)" อยู่ในรายการนี้ ซึ่งเป็นจุดที่คนตีความสมการถดถอยผิดบ่อยที่สุด.

คำว่า "regression" มาจากงานของ Francis Galton ในศตวรรษที่ 19 ที่ศึกษาความสูงของพ่อแม่กับลูก และพบปรากฏการณ์ที่เรียกว่า "regression toward mediocrity" (ปัจจุบันเรียก regression toward the mean):

อ่านตัวเลขในภาพ: ถ้าพ่อแม่เฉลี่ย (mid-parent) สูงกว่าค่าเฉลี่ยประชากร 3 นิ้ว ลูกจะสูงกว่าค่าเฉลี่ยเพียง 2 นิ้ว เท่านั้น — ไม่ใช่ 3 นิ้วเท่าพ่อแม่ (สังเกตอัตราส่วน "2 to 3" ที่เขียนกำกับไว้ในภาพต้นฉบับ). พ่อแม่ที่สูงผิดปกติ ลูกจะสูง "น้อยลง" กว่าพ่อแม่ (ถอยเข้าใกล้ค่าเฉลี่ยประชากร) และพ่อแม่ที่เตี้ยผิดปกติ ลูกจะเตี้ย "น้อยลง" เช่นกัน — นี่คือที่มาของคำว่า "regression" (การถอยกลับ) ที่ใช้เรียกเทคนิคทั้งตระกูลนี้มาจนถึงทุกวันนี้ ทั้งที่ปัจจุบันเราใช้ regression กับโจทย์ที่ไม่เกี่ยวกับ "การถอยกลับสู่ค่าเฉลี่ย" เลยก็ได้.

Associative vs Causal Inference

สไลด์ยกตัวอย่างคลาสสิกของ confounding variable: ยอดขายไอศกรีมกับจำนวนนักท่องเที่ยวมีความสัมพันธ์เชิงบวกชัดเจนในข้อมูล แต่ทั้งคู่ถูกขับเคลื่อนโดยตัวแปรกวน (confounder) ตัวเดียวกันคืออุณหภูมิ — วันที่ร้อน คนออกไปเที่ยวเยอะขึ้นและไอศกรีมขายดีขึ้นพร้อมกัน โดยที่นักท่องเที่ยวไม่ได้เป็น "สาเหตุ" ที่ทำให้ไอศกรีมขายดีเลย:

ถ้าเก็บข้อมูลแบบสังเกตการณ์ (observational) แล้วรัน lm(ยอดขายไอศกรีม ~ จำนวนนักท่องเที่ยว) จะได้สัมประสิทธิ์เป็นบวกและมีนัยสำคัญทางสถิติแน่นอน — แต่ห้ามสรุปว่านักท่องเที่ยวทำให้ไอศกรีมขายดีขึ้น เพราะกล่องเส้นประสีแดงในภาพ (ตัวแปรที่อยู่ในตัวแบบการถดถอยจริง) ไม่ได้ครอบคลุมอุณหภูมิ ซึ่งเป็นตัวขับเคลื่อนที่แท้จริงของทั้งสองตัว.

ทางแก้ที่ทำให้สรุปเชิงเหตุผล (causal) ได้ คือการทำ experimental study — สุ่มกำหนดค่าตัวแปรอิสระเอง แทนที่จะปล่อยให้มันเกิดขึ้นเองตามธรรมชาติ. ตัวอย่างในสไลด์: สุ่มต้นทานตะวัน 10 ต้น แบ่ง 5 ต้นให้แสง 100,000 ลักซ์ อีก 5 ต้นให้แสง 50,000 ลักซ์ วัดความสูงหลัง 2 สัปดาห์:

เพราะสุ่ม (randomize) ว่าต้นไหนได้แสงระดับใด ตัวแปรกวนที่อาจจะมีอยู่ (เช่น พันธุกรรมของเมล็ด ความสมบูรณ์ของดินเดิม) ถูกกระจายเท่า ๆ กันในสองกลุ่มโดยเฉลี่ย — ถ้าความสูงต่างกันอย่างมีนัยสำคัญระหว่างสองกลุ่ม จึงสรุปเชิงเหตุผลได้ว่าความเข้มแสงเป็นสาเหตุของความสูงที่ต่างกัน ไม่ใช่แค่ "สัมพันธ์กัน" เฉย ๆ — กฎทอง: ข้อมูล observational ให้ได้แค่ข้อสรุปเชิง association; ต้องมี randomized experiment ถึงจะสรุปเชิง causal ได้

3. สมการโมเดล — ทักษะที่ 1: เขียนสมการให้ถูก

Simple Linear Regression คือการถดถอยตัวแปรตาม Y ตัวเดียวบนตัวแปรอิสระ X ตัวเดียว จากคู่ข้อมูล \((X_i, Y_i)\) สำหรับ \(i = 1, 2, \ldots, n\) โมเดลเขียนเป็น:

\[Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i\]
โดย \(\beta_0\) คือ intercept, \(\beta_1\) คือ slope, \(\varepsilon_i\) คือ error term ที่ \(\varepsilon_i \sim \text{iid } N(0,\sigma^2)\)

เมื่อวาดในกราฟสองมิติ \(\hat{\beta}_0\) คือจุดตัดแกน Y (y-intercept) และ \(\hat{\beta}_1\) คือความชัน (slope = rise/run) ของเส้นถดถอยที่ประมาณได้ \(\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X\):

จำไว้เสมอ: \(\beta_0, \beta_1\) (ไม่มีหมวก) คือพารามิเตอร์ทฤษฎีที่ไม่รู้ค่าจริง ส่วน \(\hat{\beta}_0, \hat{\beta}_1\) (มีหมวก) คือค่าประมาณจากข้อมูลตัวอย่าง — ข้อสอบชอบเช็คว่าเขียนหมวกถูกจุดหรือไม่ เพราะสื่อความหมายต่างกันโดยสิ้นเชิง (ค่าจริงที่ไม่มีทางรู้ vs ค่าประมาณที่คำนวณได้จากข้อมูล).

คำถาม 3 (Free response)เขียนสมการโมเดล
บริษัทอยากศึกษาความสัมพันธ์ระหว่างงบโฆษณารายเดือน (ล้านบาท) กับยอดขายรายเดือน (ล้านบาท) จาก 24 เดือนที่ผ่านมา จงเขียนสมการ simple linear regression พร้อมระบุความหมายของแต่ละพจน์ และเขียน assumption ของ ε_i

\(Sales_i = \beta_0 + \beta_1 Ad_i + \varepsilon_i\), สำหรับ i = 1,…,24

โดย \(\beta_0\) = ยอดขายคาดการณ์เมื่องบโฆษณาเท่ากับ 0, \(\beta_1\) = ยอดขายที่เปลี่ยนไปโดยเฉลี่ยเมื่องบโฆษณาเพิ่มขึ้น 1 ล้านบาท, \(\varepsilon_i\) = ความคลาดเคลื่อนของเดือนที่ i ที่โมเดลอธิบายไม่ได้

Assumption: \(\varepsilon_i \sim \text{iid } N(0,\sigma^2)\) — error แต่ละเดือนมีค่าเฉลี่ยเป็นศูนย์ เป็นอิสระต่อกัน มี variance คงที่ทุกระดับของงบโฆษณา และแจกแจงแบบปกติ

4. Assumptions on Error Terms — สิ่งที่ต้องเช็คทุกครั้ง

นี่คือหัวใจของ "assumption checking" ที่ใช้ทั้งวิชา สไลด์ตั้งไว้ 4 ข้อ:

  1. Error terms มีค่าเฉลี่ยเป็นศูนย์ (mean zero)
  2. Error terms เป็นอิสระต่อกัน (independent)
  3. Error terms มี variance คงที่ทุกระดับของ X (constant variance / homoscedasticity)
  4. Error terms แจกแจงแบบปกติ (normally distributed)

ภาพนี้แปล assumption 4 ข้อให้เห็นเป็นรูปธรรม: จุดข้อมูลแต่ละจุด \(y_i\) คือค่าจริงที่สังเกตได้ ส่วนเส้นประสีเขียว \(y = \beta_0 + \beta_1 x\) คือค่าเฉลี่ยทฤษฎีที่โมเดลทำนาย — \(\varepsilon_i\) (ลูกศรสีแดง) คือระยะห่างแนวตั้งระหว่างจุดจริงกับเส้นทฤษฎีที่จุดนั้น. สังเกตว่าจุดข้อมูลกระจายอยู่รอบ ๆ เส้นทั้งด้านบนและด้านล่างในปริมาณใกล้เคียงกันตลอดช่วง X — นี่คือหน้าตาของ assumption ที่ "ผ่าน":

ภาพต่อไปนี้ (จาก Ramsey & Schafer) แปล assumption 4 ข้อให้เป็น "การแจกแจงของ Y ที่แต่ละระดับ X" โดยตรง: ที่ทุกค่าของ X บนเส้นถดถอย มีระฆังคว่ำ (normal distribution) วางอยู่ — ระฆังแต่ละลูกมีศูนย์กลางอยู่บนเส้น \(\beta_0+\beta_1 X\) พอดี (= assumption ข้อ 1 mean เป็นศูนย์ที่ทุกจุด แปลว่า \(E[Y|X]=\beta_0+\beta_1 X\)) และมีความกว้าง (variance) เท่ากันทุกลูก ไม่ว่า X จะมีค่าเท่าไร (= assumption ข้อ 3 constant variance):

ถ้าระฆังลูกไหนกว้างกว่าลูกอื่นอย่างชัดเจน (เช่น กว้างขึ้นเรื่อย ๆ ตาม X) นั่นคือการละเมิด assumption ข้อ 3 หรือที่เรียกว่า heteroscedasticity — และถ้าระฆังไม่สมมาตร (เบ้ซ้าย/ขวา) คือการละเมิดข้อ 4 (normality) — นี่คือสิ่งที่ diagnostic plot ใน R จะให้คุณตรวจสอบจริง (Residuals vs Fitted สำหรับข้อ 1&3, Normal Q-Q สำหรับข้อ 4, Durbin-Watson หรือดูลำดับข้อมูลสำหรับข้อ 2) — รายละเอียดเต็มอยู่ใน Lecture 3 (Regression Diagnostics) แต่ต้องจำ 4 ข้อนี้ให้ขึ้นใจตั้งแต่บทนี้ เพราะทุกโจทย์ที่ให้ fit โมเดลจะถามต่อว่า "assumption เป็นไปตามที่ตั้งไว้หรือไม่"

6. Ordinary Least Squares (OLS) — ที่มาของ \(\hat{\beta}_0, \hat{\beta}_1\)

แนวคิด OLS: หา \(\hat{\beta}_0, \hat{\beta}_1\) ที่ทำให้เส้นถดถอย "ฟิต" ข้อมูลดีที่สุด โดยวัดความ fit จาก residual \(e_i = Y_i - \hat{Y}_i\) (ระยะห่างแนวตั้งจากจุดจริงถึงเส้นทำนาย) ดังภาพ:

OLS เลือก \(\hat{\beta}_0, \hat{\beta}_1\) ที่ทำให้ผลรวมกำลังสองของ residual (SSE) น้อยที่สุด:

\[SSE = \sum e_i^2 = \sum (Y_i-\hat{Y}_i)^2 = \sum (Y_i-\beta_0-\beta_1 X_i)^2\]
แก้สมการ \(\text{argmin}\) ได้:
\(\hat{\beta}_1 = \dfrac{\sum (X_i-\bar{X})(Y_i-\bar{Y})}{\sum (X_i-\bar{X})^2}\)  และ  \(\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}\)

เหตุผลที่ยกกำลังสองแทนที่จะบวก residual ตรง ๆ: ถ้าบวกตรง ๆ residual บวกกับลบจะหักล้างกันจนผลรวมใกล้ศูนย์เสมอ (ทำให้ประเมิน fit ไม่ได้) ยกกำลังสองแก้ปัญหานี้และยังลงโทษ residual ที่มีขนาดใหญ่หนักกว่าสัดส่วน — จุดที่ห่างเส้นมากมีผลต่อ SSE รุนแรงกว่าจุดที่ห่างน้อยแบบไม่เป็นเชิงเส้น.

ความเชื่อมโยงกับ Correlation Coefficient

Correlation coefficient \(r_{xy}\) วัดความสัมพันธ์เชิงเส้นระหว่างสองตัวแปร มีค่าระหว่าง −1 ถึง 1:

\(S_x^2 = \dfrac{1}{n-1}\sum (X_i-\bar{X})^2\),  \(S_y^2 = \dfrac{1}{n-1}\sum (Y_i-\bar{Y})^2\),  \(\text{COV}_{xy} = \dfrac{1}{n-1}\sum (X_i-\bar{X})(Y_i-\bar{Y})\)
\[r_{xy} = \dfrac{\text{COV}_{xy}}{S_x S_y}\]

จัดรูป \(\hat{\beta}_1\) ใหม่โดยหารทั้งเศษส่วนทั้งบนล่างด้วย \((n-1)\) จะเห็นว่า \(\hat{\beta}_1 = \dfrac{\text{COV}_{xy}}{S_x^2}\) — และเพราะ \(r_{xy} = \dfrac{\text{COV}_{xy}}{S_x S_y}\) จึงจัดรูปได้อีกขั้นเป็น:

\[\hat{\beta}_1 = r_{xy} \times \dfrac{S_y}{S_x}\]

สูตรนี้บอกอะไร: ความชันของเส้นถดถอยไม่ใช่แค่ทิศทางของ correlation (บวก/ลบตาม r_xy) แต่ยังถูกปรับสเกลด้วยอัตราส่วนความแปรปรวนของ Y ต่อ X ด้วย — X, Y คู่เดียวกันที่มี \(r_{xy}\) เท่ากันเป๊ะ อาจได้ \(\hat{\beta}_1\) ต่างกันมากถ้าหน่วยวัดของ Y "แกว่งแรง" กว่า X มาก (S_y ใหญ่กว่า S_x มาก) เทียบกับกรณี S_y ใกล้เคียง S_x — และในกรณี Simple Linear Regression (ตัวแปรอิสระเดียว) เท่านั้นที่ \(R^2 = r_{xy}^2\) พอดี (จะเห็นอีกครั้งในหัวข้อ 9).

ค่า correlation coefficient ที่ระดับต่าง ๆ หน้าตาเป็นอย่างไรในทางกราฟ:

สังเกตแผง (c) "Little correlation (r near 0)" — จุดกระจายเป็นวงกลมไม่มีทิศทาง นี่คือรูปแบบเดียวที่ r ใกล้ 0 บอกว่า "ไม่มีความสัมพันธ์เชิงเส้น" — แต่ข้อควรระวัง 3 ข้อจากสไลด์: (1) ถ้าความสัมพันธ์เป็นแบบไม่เชิงเส้น (เช่นรูปโค้งในหัวข้อ 5) r จะประเมินความแรงของความสัมพันธ์ต่ำเกินจริง ทั้งที่ความสัมพันธ์นั้นแน่นมาก แค่ไม่ใช่เส้นตรง (2) เมื่อ n เล็ก ค่า r ไม่เสถียร แกว่งง่ายจากตัวอย่างสุ่ม (3) r ไม่ทนต่อ outlier — จุดผิดปกติจุดเดียวดึง r ให้เปลี่ยนไปมากได้.

8. การทดสอบสมมติฐาน \(\beta_0\) และ \(\beta_1\)

สนใจทดสอบ \(H_0: \beta_1 = 0\) (X ไม่มีความสัมพันธ์เชิงเส้นกับ Y เลย) รูปแบบทั่วไปของ test statistic คือ \(\dfrac{\text{point estimate} - \text{ค่าคาดหวังภายใต้ } H_0}{SE[\text{point estimate}]}\). สำหรับ \(\beta_1\):

\(t = \dfrac{\hat{\beta}_1-\beta_1}{SE[\hat{\beta}_1]} \sim t_{n-2}\),  โดย  \(SE[\hat{\beta}_1] = \sqrt{\dfrac{s^2}{\sum (X_i-\bar{X})^2}}\)

และสำหรับ \(\beta_0\) ใช้สูตรคล้ายกัน แทนที่ตัวส่วนด้วย \(SE[\hat{\beta}_0] = \sqrt{s^2\left(\dfrac{1}{n} + \dfrac{\bar{X}^2}{\sum (X_i-\bar{X})^2}\right)}\). ทั้งสองมี df = n−2 (เสีย 2 df ให้กับการประมาณ \(\beta_0\) และ \(\beta_1\)).

เชื่อมกับ output จริง: แถว x ในตาราง Coefficients คือผลการทดสอบ \(H_0: \beta_1=0\) พอดี — \(t = 3.394/1.108 = 3.064\) ตรงกับคอลัมน์ t value เป๊ะ, df=8 ตรงกับ "8 degrees of freedom" ที่บอกไว้ใต้ตาราง, และ \(\text{Pr}(>|t|) = 0.01548\) คือ p-value สองด้าน (two-tailed) ของการทดสอบนี้.

10. Coefficient of Determination (R²) และการแตกตัว SST

R² วัด "ความแรง" ของความสัมพันธ์ (ต่างจาก hypothesis test ที่บอกแค่ "มี/ไม่มี" ความสัมพันธ์):

\(R^2 = \dfrac{SSR}{SST} = 1-\dfrac{SSE}{SST}\),  ตีความว่าเป็นสัดส่วนความแปรปรวนของ Y ที่ X อธิบายได้,  และในกรณี SLR: \(R^2 = r_{xy}^2\)

ที่มา: ความเบี่ยงเบนรวมของ Y (Total SS) แตกออกเป็นสองส่วนเสมอ — ส่วนที่โมเดลอธิบายได้ (Explained SS, SSR) และส่วนที่อธิบายไม่ได้ (Unexplained SS, SSE):

อ่านภาพ: ระยะห่างรวมจากจุด \(y_i\) ถึงเส้นค่าเฉลี่ย \(\bar{y}\) (SST) แตกเป็นสองท่อนต่อกัน — ท่อนบน (จาก \(y_i\) ถึงเส้นถดถอย \(\hat{y}\)) คือ SSE ที่โมเดลยังทายพลาด, ท่อนล่าง (จากเส้นถดถอยถึง \(\bar{y}\)) คือ SSR ที่โมเดลอธิบายได้จาก X. ถ้า SSE ท่อนบนสั้นมาก (จุดข้อมูลอยู่ใกล้เส้นถดถอยมาก) แปลว่าโมเดลอธิบายได้เกือบหมด R² จะเข้าใกล้ 1.

ยืนยันด้วย output จริง: Multiple R-squared: 0.5399 — X (Time) อธิบายความแปรปรวนของ Sales ได้ 53.99% ส่วนอีก 46.01% เป็นปัจจัยอื่นที่โมเดลนี้ไม่ได้จับไว้.

สไลด์เตือน 3 ความเข้าใจผิดที่พบบ่อยเกี่ยวกับ R²:

  1. R² สูง ≠ ทำนายได้แม่นยำเสมอ (ยังต้องดู residual standard error/prediction interval ประกอบ)
  2. R² สูง ≠ เส้นถดถอยฟิตข้อมูลดีเสมอ (อาจฟิตแนวโน้มหลักได้ แต่ยังพลาดรายละเอียดสำคัญ เช่น non-linearity)
  3. R² ใกล้ 0 ≠ X กับ Y ไม่สัมพันธ์กันเลย (อาจสัมพันธ์กันแบบไม่เชิงเส้นแรงมาก แต่ R² ของโมเดลเชิงเส้นจับไม่ได้ — ย้อนกลับไปหัวข้อ 6 เรื่องข้อจำกัดของ correlation)

11. Mean Response vs Prediction ที่ X = X₀

มีสองคำถามที่ดูคล้ายกันแต่ไม่ใช่เรื่องเดียวกัน: (1) ค่าเฉลี่ยของ Y ที่ X=X₀ คือเท่าไร (mean response) กับ (2) ค่า Y ตัวใหม่ตัวหนึ่งที่ X=X₀ จะเป็นเท่าไร (prediction) — point estimate ของทั้งคู่เท่ากันคือ \(\hat{Y} = \hat{\beta}_0+\hat{\beta}_1 X_0\) แต่ interval estimate ต่างกัน:

Mean response ที่ X₀ คือการถามหาจุดศูนย์กลางของระฆังทฤษฎีที่ X₀ — ความไม่แน่นอนมีแค่แหล่งเดียวคือความไม่แน่นอนในการประมาณ β̂₀, β̂₁ จากข้อมูลตัวอย่าง:

Point estimate: \(\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X_0\)
\((1-\alpha)\%\) CI: \(\hat{Y} \pm t_{(1-\alpha/2,\, n-2)} \times SE[\hat{Y}]\),  \(SE[\hat{Y}] = s\sqrt{\dfrac{1}{n} + \dfrac{(X_0-\bar{X})^2}{\sum (X_i-\bar{X})^2}}\)

ส่วน prediction ที่ X₀ คือการถามหาค่า Y สังเกตใหม่หนึ่งตัว ที่จะสุ่มออกมาจากระฆังทฤษฎีลูกนั้น — ไม่ใช่แค่จุดศูนย์กลางของระฆัง แต่เป็นค่าที่กระจายไปทั่วทั้งระฆังได้:

Point estimate: \(\hat{Y}_{pred} = \hat{\beta}_0 + \hat{\beta}_1 X_0\) (จุดเดียวกับ mean response!)
\((1-\alpha)\%\) PI: \(\hat{Y}_{pred} \pm t_{(1-\alpha/2,\, n-2)} \times SE[\hat{Y}_{pred}]\),  \(SE[\hat{Y}_{pred}] = s\sqrt{1 + \dfrac{1}{n} + \dfrac{(X_0-\bar{X})^2}{\sum (X_i-\bar{X})^2}}\)

เทียบสองสูตร SE ให้ดี: สูตร prediction มี "+1" เพิ่มเข้ามาในรากที่สอง ซึ่งไม่มีในสูตร mean response — พจน์ "+1" นี้คือความแปรปรวนของค่าสังเกตใหม่หนึ่งตัวรอบ ๆ ค่าเฉลี่ยทฤษฎี (ตัว Y เองยังสุ่มได้ตามระฆัง แม้จะรู้ค่าเฉลี่ยทฤษฎีแน่นอนแล้วก็ตาม) ดังนั้น prediction interval กว้างกว่า confidence interval ของ mean response เสมอ ที่ X₀ เดียวกัน — เป็นความจริงทางคณิตศาสตร์ ไม่ใช่แค่บังเอิญจากข้อมูลชุดใดชุดหนึ่ง

ใน R ใช้ predict(object, newdata, interval=c("none","confidence","prediction"), level=0.95) ตัวอย่างทำนาย Sales ที่ Time=5 และ Time=7 แบบ prediction interval:

> newdata<-data.frame(x=c(5,7))
> predict(model, newdata=newdata, interval="prediction")
       fit      lwr      upr
1 40.30303 15.93783 64.66824
2 47.09091 22.45941 71.72241

เช็คตัวเลข: ที่ x=5, \(fit = 23.333 + 3.394\times5 = 40.303\) ตรงกับ \(\hat{Y} = \hat{\beta}_0+\hat{\beta}_1 X\) จากหัวข้อ 7 พอดี — ช่วง 95% prediction interval กว้างถึง 48.7 หน่วย (15.9 ถึง 64.7) ทั้งที่ point estimate อยู่กลาง ๆ พอดีที่ 40.3 — สะท้อนว่าตัวอย่างมีแค่ n=10 จุด ทำให้ยังไม่แน่ใจมากนักในการทำนายค่าสังเกตใหม่แต่ละตัว

12. Confidence Band vs Prediction Interval — เห็นความต่างเป็นภาพ

ขยายจาก "จุดเดียว X₀" ไปเป็น "ทั้งเส้นถดถอย" — confidence band คือกลุ่มของ mean-response CI ที่ทุกค่า X ต่อกันเป็นแถบ, ส่วน prediction interval band คือกลุ่มของ PI ที่ทุกค่า X ต่อกัน:

อ่านภาพ: เส้นประสีน้ำเงิน (95% Confidence Band) แนบชิดเส้นถดถอยสีน้ำเงินตลอดช่วง เพราะเป็นความไม่แน่นอนของ "ค่าเฉลี่ย" เท่านั้น ส่วนเส้นประสีแดง (95% Prediction Interval) ห่างออกไปมากกว่าอย่างชัดเจนตลอดทั้งเส้น ครอบคลุมจุดข้อมูลจริง (วงกลมดำ) เกือบทั้งหมดไว้ข้างใน — ตรงกับส่วน "+1" ในสูตร SE ของหัวข้อ 11 พอดี ที่ทำให้แถบ prediction กว้างกว่าแถบ confidence เสมอทุกจุดบนเส้น ไม่ใช่แค่บางช่วง

ผลลัพธ์จริงจากข้อมูล Automobile Data เมื่อคำนวณทั้งสองแถบด้วย R (predict(..., se.fit=TRUE) ตามสูตร Working–Hotelling \(W=\sqrt{2F_{(1-\alpha,\,2,\,n-2)}}\) สำหรับ band และสูตร PI ปกติสำหรับแถบนอก) แล้วพล็อตทับข้อมูลจริง:

สังเกตแถบในสุด (เขียว/น้ำเงิน ประ) แคบกว่าแถบนอกสุด (แดง ประ) มาก และแถบทั้งคู่บีบแคบที่สุดตรงกลาง (ใกล้ X̄=5.5) แล้วบานออกที่ปลายทั้งสองข้าง (X=1 และ X=10) — ตรงกับพจน์ \((X_0-\bar{X})^2\) ในสูตร SE ทั้งสองแบบ: ยิ่ง X₀ ห่างจากค่าเฉลี่ย X̄ มาก ความไม่แน่นอนยิ่งสูง เพราะข้อมูลตัวอย่างเบาบางกว่าที่ขอบเทียบกับตรงกลาง

อธิบายว่าทำไม 95% prediction interval ที่ X₀ หนึ่งจุด ต้องกว้างกว่า 95% confidence interval ของ mean response ที่ X₀ เดียวกันเสมอ (อ้างอิงสูตร SE ทั้งสองแบบ)
SE ของ prediction (\(s\sqrt{1 + \dfrac{1}{n} + \dfrac{(X_0-\bar{X})^2}{\sum (X_i-\bar{X})^2}}\)) มีพจน์ "+1" เพิ่มเข้ามาเทียบกับ SE ของ mean response (\(s\sqrt{\dfrac{1}{n} + \dfrac{(X_0-\bar{X})^2}{\sum (X_i-\bar{X})^2}}\)) เพราะ prediction ต้องนับความไม่แน่นอน 2 แหล่งรวมกัน: (1) ความไม่แน่นอนในการประมาณเส้นถดถอยจากตัวอย่าง (เหมือน mean response) บวกกับ (2) ความแปรปรวนตามธรรมชาติของค่าสังเกตใหม่หนึ่งตัวรอบเส้นทฤษฎี (σ²) ซึ่ง mean response ไม่ต้องนับเพราะถามแค่ค่าเฉลี่ย ไม่ใช่ค่าสังเกตจริงตัวใดตัวหนึ่ง
