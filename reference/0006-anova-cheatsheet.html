Lecture 6 — Single Factor ANOVA

ANOVA สมการ + ANOVA Table + Post-hoc Cheat Sheet

สรุปสมการ ANOVA ทั้งสองแบบ, โครงสร้างตาราง ANOVA, การอ่าน R output ภายใต้ contrast ต่างกัน, และวิธี post-hoc ทั้ง 4 — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. สมการโมเดล ANOVA (สองแบบ)

Cell Means Model
\(Y_{ij} = \mu_i + \varepsilon_{ij}\),  \(\varepsilon_{ij} \sim \text{iid } N(0, \sigma^2)\) \(\Longleftrightarrow\) \(Y_{ij} \sim \text{independent } N(\mu_i, \sigma^2)\)

พารามิเตอร์: \(\mu_1,\ldots,\mu_r\) และ \(\sigma^2\) (รวม \(r+1\) ตัว)  |  \(H_0: \mu_1=\mu_2=\cdots=\mu_r\)

Factor Effects Model
\(Y_{ij} = \mu + \tau_i + \varepsilon_{ij}\)  พร้อม constraint \(\sum \tau_i = 0\) (นิยมสุด) หรือ \(\tau_r = 0\)

พารามิเตอร์: \(\mu, \tau_1,\ldots,\tau_r\) และ \(\sigma^2\) (\(r+2\) ตัว — overparameterized ถ้าไม่ใส่ constraint)  |  \(H_0: \tau_1=\cdots=\tau_r=0\)

ANOVA ↔ Regression: factor ที่มี \(r\) levels เทียบเท่า regression ที่มีตัวแปร dummy \(r-1\) ตัว (เก็บ intercept ไว้แทนกลุ่มอ้างอิง 1 กลุ่ม) — \(Y_i = \beta_0+\beta_1 X_{i1}+\cdots+\beta_{r-1} X_{i,r-1}+\varepsilon_i\)

สำคัญ: ค่าประมาณของ \(\mu, \tau_i\) เองเปลี่ยนไปตาม constraint ที่เลือก แต่ปริมาณที่สนใจจริง (เช่น \(\hat{\mu}+\hat{\tau}_i\) หรือ \(\hat{\tau}_i-\hat{\tau}_k\)) เท่ากันเสมอไม่ว่าจะเลือก constraint แบบไหน

2. ANOVA Table

SourcedfSum of SquaresMean Square
Model (Treatment)\(r-1\)\(SSTR = \sum n_i(\bar{Y}_{i\cdot}-\bar{Y}_{\cdot\cdot})^2\)\(MSTR = SSTR/(r-1)\)
Error\(n_T-r\)\(SSE = \sum\sum(Y_{ij}-\bar{Y}_{i\cdot})^2\)\(MSE = SSE/(n_T-r)\)
Total\(n_T-1\)\(SST = \sum\sum(Y_{ij}-\bar{Y}_{\cdot\cdot})^2\)\(MST = SST/(n_T-1)\)
\(F = MSTR/MSE\) — วัดอัตราส่วน between-treatment ÷ within-treatment variability  |  F สูง = between มากกว่า within มาก → ปฏิเสธ \(H_0\); F ใกล้ 1 = ไม่ปฏิเสธ \(H_0\)

เปรียบเทียบกับ SLR ANOVA table (Lesson 1): โครงสร้างเหมือนกันทุกประการ เปลี่ยนแค่ SSTR แทน SSR และ \(r-1\) df แทน 1 df (เพราะ ANOVA ใช้ dummy variable \(r-1\) ตัว)

\(s^2 = \sum(n_i-1)s_i^2 / (n_T-r)\)  (pooled variance ถ่วงน้ำหนักด้วย df แต่ละกลุ่ม),  \(s_i^2 = \sum(Y_{ij}-\bar{Y}_{i\cdot})^2/(n_i-1)\)

3. Assumptions — เหมือน Lesson 1 ทุกข้อ

(1) Independent (2) Normal — ทุกกลุ่มมี mean ต่างกันได้แต่ variance คงที่ทุกกลุ่ม (constant variance/homoscedasticity) — เช็คด้วย residual plot, Levene's/Bartlett's test (variance), Shapiro-Wilk/Q-Q plot (normality)

4. Fit ใน R: aov() vs lm()

ContrastConstraintความหมาย (Intercept)ความหมายสัมประสิทธิ์
contr.treatment (default R)\(\tau_r=0\) (กลุ่มอ้างอิง=กลุ่มแรก)ค่าเฉลี่ยกลุ่มอ้างอิงตรง ๆผลต่างค่าเฉลี่ย (กลุ่มนี้ − กลุ่มอ้างอิง)
contr.sum\(\sum\tau_i=0\)Grand meanผลของกลุ่มนี้เทียบ grand mean (\(\hat{\tau}_i\))
aov(y~x, data=data) และ lm(y~x, data=data, contrasts=list(x=...)) ให้ F, p-value, \(R^2\) เหมือนกันทุกประการเสมอ — เพราะ aov เป็นแค่ wrapper ของ lm ที่เลือก contrast ให้อัตโนมัติ ต่างแค่ "ความหมายของ coefficient แต่ละตัว" เปลี่ยนตาม constraint 
options("contrasts")                      # เช็คว่าใช้ constraint แบบไหนอยู่ก่อนตีความเสมอ
aovmodel <- aov(y~x, data=data)
summary(aovmodel)                         # ANOVA table: Df, Sum Sq, Mean Sq, F value, Pr(>F)
model.tables(aovmodel, "means")           # ค่าเฉลี่ยแต่ละกลุ่ม + grand mean ตรง ๆ ไม่ต้องตีความ contrast
model.tables(aovmodel, "effect")          # tau_i-hat ของแต่ละกลุ่ม (ผลต่างจาก grand mean)

5. Template ประโยคแปลผล F-test

"จากข้อมูลนี้ ปฏิเสธ/ไม่ปฏิเสธ \(H_0\) ที่ระดับนัยสำคัญ \(\alpha\)=[ค่า] (\(F\)([r-1],[n_T-r])=[F], p=[p-value]) สรุปได้ว่า [มี/ไม่มี] อย่างน้อยหนึ่ง[กลุ่ม]ที่มี[ตัวแปรตอบสนอง]เฉลี่ยแตกต่างจากกลุ่มอื่นอย่างมีนัยสำคัญทางสถิติ"

ข้อควรระวัง: F-test บอกแค่ "มีอย่างน้อยหนึ่งกลุ่มต่างจากกลุ่มอื่น" เท่านั้น ไม่บอกว่าคู่ไหนต่างจากคู่ไหน — ต้องทำ post-hoc comparison ต่อ

6. ปัญหา Multiplicity และวิธีแก้ 4 แบบ

จำนวนคู่เปรียบเทียบทั้งหมด = \(r(r-1)/2\) — ยิ่งทดสอบหลายคู่พร้อมกัน ยิ่งมีโอกาสสูงที่อย่างน้อยหนึ่ง CI จะพลาดจากความบังเอิญ (overall confidence ต่ำกว่า \(1-\alpha\))

วิธีMultiplierลักษณะ
LSD (Least Significant Difference)\(t(1-\alpha/2; n_T-r)\)ไม่ปรับ multiplicity เลย — power สูงสุด, false positive สูงสุด
Bonferroni\(t(1-\alpha^*/2; n_T-r)\), \(\alpha^*=\alpha/[r(r-1)/2]\)ง่าย แต่ conservative เกินเมื่อคู่เยอะ
Tukey's HSD\(q(1-\alpha; r; n_T-r)\) (studentized range)ออกแบบมาสำหรับ pairwise ทุกคู่โดยเฉพาะ — คุม family-wise error พอดี
Scheffe's Method\(\sqrt{(r-1)F(1-\alpha; r; n_T-r)}\)คุม multiplicity ของ linear combination ทุกรูปแบบ — conservative ที่สุด

CI ของผลต่างสองกลุ่ม: \((\bar{Y}_{i\cdot}-\bar{Y}_{k\cdot}) \pm \text{multiplier} \times s\sqrt{1/n_i+1/n_k}\)

7. Post Hoc ใน R และ Template แปลผล

TukeyHSD(aovmodel)                                  # ตาราง diff, lwr, upr, p adj ต่อคู่
library(DescTools)
PostHocTest(aovmodel, method="lsd"/"bonferroni"/"hsd"/"scheffe")
plot(PostHocTest(aovmodel, method="hsd"))           # plot CI ทุกคู่ เทียบเส้นอ้างอิงที่ 0
Template แปลผล Pairwise Comparison

"[ตัวแปรตอบสนอง]เฉลี่ยของ[กลุ่ม A] [สูงกว่า/ต่ำกว่า][กลุ่ม B] อยู่ [|diff|] [หน่วย] อย่างมีนัยสำคัญทางสถิติที่ 95% family-wise confidence level (95% CI ของผลต่างคือ [lwr] ถึง [upr] ซึ่งไม่ครอบคลุม 0, p adj=[ค่า])"

องค์ประกอบที่ขาดไม่ได้: (1) ทิศทางของผลต่าง ไม่ใช่แค่ "ต่างกัน" (2) ขนาดผลต่างพร้อมหน่วย (3) อ้าง CI/p-value ที่ปรับ multiplicity แล้ว ไม่ใช่ p ดิบจาก t-test ทีละคู่ (4) CI ไม่ครอบคลุม 0 \(\Longleftrightarrow\) นัยสำคัญ (กฎเดียวกับ CI ของ \(\beta\) ใน Lesson 1)
