Lecture 9 — Binary Data

Logistic Regression: สมการ + Interpretation Template (Log-odds/Odds Ratio/Probability)

สรุปสมการ logistic regression และ template แปลผลสัมประสิทธิ์ — ทักษะที่ออกสอบหนักที่สุดในวิชานี้ทั้งเทอม ตาม MISSION.md — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. โมเดลและ Logit Link

\(Y_i \sim \text{Bernoulli}(\pi_i)\) ⟺ \(\text{Binomial}(1, \pi_i)\),  \(\text{Mean}[Y_i]=\pi_i\),  \(\text{Variance}[Y_i]=\pi_i(1-\pi_i)\)

เป็นกรณีพิเศษของ GLM: random component = Bernoulli, canonical link = logit

\[\text{logit}(\pi_i) = \log\left(\dfrac{\pi_i}{1-\pi_i}\right) = \beta_0 + \beta_1 X_{i1} + \cdots + \beta_p X_{ip}\] (= \(\eta_i\), linear predictor)

ฟังก์ชันผกผัน (logistic function): \(\pi_i = \dfrac{e^{\eta_i}}{1+e^{\eta_i}}\)

Odds: \(\omega = \dfrac{\pi}{1-\pi}\) — อัตราส่วน "เกิด : ไม่เกิด" (ขอบเขต [0,∞) ต่างจาก π ที่มีขอบเขต [0,1])  |  \(\text{logit}(\pi) = \log(\omega)\)

2. ★ ทักษะสำคัญที่สุด: Interpretation Template 3 ระดับ ★

แปลผล β̂_k ได้ 3 แบบ — ใช้ตอบข้อสอบเสมอ

(1) Log-odds: "เมื่อ [X_k] เพิ่มขึ้น 1 [หน่วย] โดยตัวแปรอื่นคงที่ log-odds ของ [outcome=1] เปลี่ยนไป [β̂_k] หน่วย (บวก=เพิ่ม, ลบ=ลด)"

(2) Odds ratio (ตอบสอบบ่อยที่สุด): "odds ของ [outcome=1] เปลี่ยนเป็น \(\exp(\hat{\beta}_k)\) เท่า ทุก 1 [หน่วย] ที่ [X_k] เพิ่มขึ้น โดยตัวแปรอื่นคงที่" — ถ้า \(\exp(\hat{\beta}_k) > 1\): "odds เพิ่มขึ้น [\((\exp(\hat{\beta}_k)-1)\times 100\)]%"; ถ้า \(\exp(\hat{\beta}_k) < 1\): "odds ลดลงเหลือ [\(\exp(\hat{\beta}_k)\times 100\)]% ของเดิม" หรือกลับเศษส่วน \(1/\exp(\hat{\beta}_k)\) พูดว่า "กลุ่มอ้างอิง odds สูงกว่า [\(1/\exp(\hat{\beta}_k)\)] เท่า"

(3) Probability ที่จุด X เฉพาะเจาะจง: predict(model, newdata, type="response") → π̂ ตรง ๆ แล้วพูดว่า "ที่ [X_k]=[ค่า] และตัวแปรอื่น=[ค่า] ความน่าจะเป็นของ [outcome=1] คือ [π̂]" — ต้องระบุจุด X เสมอ เพราะผลของ X ต่อ π ไม่คงที่ (ต่างจาก log-odds ที่คงที่เสมอ)

ห้ามใช้: "ทำให้"/"เป็นสาเหตุของ" กับข้อมูล observational — ใช้ "สัมพันธ์กับ" แทน เว้นแต่มาจาก randomized experiment

สูตร Odds Ratio ระหว่างสองจุด X=A vs X=B
\[\dfrac{\omega_A}{\omega_B} = \exp\{\beta_1(A-B)\}\] — A คือค่าที่อยู่ "เศษ" (กลุ่ม/ค่าที่ต้องการเทียบ), B คือค่าที่อยู่ "ส่วน" (กลุ่มอ้างอิง) — สลับ A,B แล้วจะได้ผลกลับเศษส่วน (1/เดิม) ซึ่งตอบคนละคำถาม

4. Goodness-of-Fit และ Hypothesis Testing

การทดสอบH₀ / สถิติกฎการตัดสินใจ
Hosmer-Lemeshowโมเดล fit ข้อมูล — χ²(g−2), g≈10 กลุ่มตาม π̂p สูง (>0.05) → ไม่ปฏิเสธ H₀ → โมเดลใช้ได้ (สลับทิศจาก test ปกติ)
Wald's Test (β_k เดี่ยว)\(z = \dfrac{\hat{\beta}_k - \beta_k}{SE} \sim N(0,1)\)ดูจากตาราง Coefficients ตรง ๆ
Likelihood Ratio Test (drop-in-deviance)\(D(\hat{\beta}_{reduced}) - D(\hat{\beta}_{full}) \sim \chi^2_{df}\)ใช้ทดสอบหลายตัวพร้อมกันได้ (LRT วิธีเดียวที่ใช้ได้จริงตรงนี้)
tmod1 <- update(fullmodel, .~.-varname)
pchisq(deviance(tmod1)-deviance(fullmodel), df=1, lower=F)   # LRT p-value ของตัวแปรเดียว

LRT <- deviance(redmodel)-deviance(fullmodel)
1-pchisq(LRT, df.residual(redmodel)-df.residual(fullmodel))  # LRT ของหลายตัวแปรพร้อมกัน

5. Prospective vs Retrospective (Case-Control)

ใน retrospective/case-control study: Intercept ไม่ใช่ค่าประมาณของ prospective intercept ที่แท้จริง (สัดส่วน case:control ถูกกำหนดโดยนักวิจัย ไม่ใช่สัดส่วนในประชากร) แต่ สัมประสิทธิ์ของตัวแปรอิสระยังคงประมาณได้ถูกต้อง และแปลผลได้แบบเดียวกับ prospective study ทุกประการ

6. Model Selection: AIC vs BIC

\(AIC = \text{Deviance} + 2(p+1)\),  \(BIC = \text{Deviance} + (p+1)\log(N)\)

BIC ลงโทษพารามิเตอร์แรงกว่า AIC เมื่อ N มาก (log(N)>2 เมื่อ N>e²≈7.4) → BIC มักเลือกโมเดลกระชับกว่า

step(fullmodel, trace=F)                 # AIC-based stepwise
step(fullmodel, k=log(N), trace=F)       # BIC-based stepwise
