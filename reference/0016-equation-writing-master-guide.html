รวมทุก Lecture — จาก R Output สู่สมการโมเดล

อ่าน R Output แล้วเขียนสมการโมเดล — Master Guide ทุกตระกูลในวิชานี้

ข้อสอบไม่ให้เขียนโค้ด R แต่ให้ summary()/glm() output มาแล้วให้เขียนสมการที่ fit ได้ — ทักษะนี้คือการจับคู่แถวในตาราง Coefficients เข้ากับพจน์ในสมการ แผ่นนี้รวมทุกตระกูลโมเดลในวิชา พร้อมตัวอย่างตัวเลขจริงจากสไลด์ของอาจารย์

ขั้นตอนสากล 3 ขั้น (ใช้กับทุกโมเดล)
  1. ระบุ family + link function จากฟังก์ชันที่เรียก — lm()=identity link (ตรงตัว), glm(family=binomial)=logit, glm(family=poisson)=log, lmer()=identity+random effect, multinom()/polr()=logit แบบพิเศษ
  2. อ่านคอลัมน์ Estimate ทีละแถว จับชื่อแถวกับตัวแปร — ระวัง 3 กับดัก: (a) พจน์ dummy จะถูกตั้งชื่อ ตัวแปรชื่อกลุ่ม เช่น InsulAfter ไม่ใช่ Insul เฉย ๆ — กลุ่มที่หายไปคือ reference level (b) พจน์ยกกำลัง I(x^2) คือพจน์แยกต่างหาก ไม่ใช่ตัวแปรใหม่ (c) พจน์ปฏิสัมพันธ์ x1:x2 คูณกันในสมการ
  3. ประกอบสมการให้ครบ ใส่ link function/back-transform ให้ถูก — GLM เขียนฝั่งซ้ายเป็น \(g(\mu)\) ไม่ใช่ \(\hat{Y}\) ตรง ๆ (เช่น logistic เขียน \(\text{logit}(\hat\pi)=\ldots\) ไม่ใช่ \(\hat\pi=\ldots\) ตรง ๆ)

1. Simple Linear Regression (Lecture 1)

Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept)   23.333      6.873   3.395  0.00943 **
x              3.394      1.108   3.064  0.01548 *

อ่านตรง ๆ: \(\hat\beta_0=23.333\), \(\hat\beta_1=3.394\) →

\[\hat{Y} = 23.333 + 3.394X\]

2. Multiple Linear Regression + Dummy + Interaction (Lecture 2, whiteside)

Coefficients:
               Estimate Std. Error t value Pr(>|t|)
(Intercept)     6.85383    0.13596  50.409  < 2e-16 ***
InsulAfter     -2.12998    0.18009 -11.827 2.32e-16 ***
Temp           -0.39324    0.02249 -17.487  < 2e-16 ***
InsulAfter:Temp 0.11530    0.03211   3.591 0.000731 ***

แถว InsulAfter ไม่ใช่ Insul เฉย ๆ — R เลือก "Before" เป็น reference level (เรียงตามตัวอักษร) สมการเต็ม:

\[\widehat{Gas} = 6.85383 - 2.12998\,\mathbb{1}[\text{After}] - 0.39324\,Temp + 0.11530\,\mathbb{1}[\text{After}]\times Temp\]

แยกตามกลุ่ม: Before (\(\mathbb{1}=0\)): \(\widehat{Gas}=6.85383-0.39324\,Temp\)   After (\(\mathbb{1}=1\)): \(\widehat{Gas}=(6.85383-2.12998)+(-0.39324+0.11530)Temp = 4.72385-0.27794\,Temp\) — สังเกตว่า slope เปลี่ยนด้วย (interaction) ไม่ใช่แค่ intercept เลื่อน

3. Polynomial Regression (Lecture 2/3, corn yield)

Coefficients:
              Estimate Std. Error t value Pr(>|t|)
(Intercept)   -5.01467   11.44158  -0.438  0.66387
RAINFALL       6.00428    2.03895   2.945  0.00571 **
I(RAINFALL^2) -0.22936    0.08864  -2.588  0.01397 *
\[\widehat{YIELD} = -5.01467 + 6.00428\,RAINFALL - 0.22936\,RAINFALL^2\]

กับดัก: ห้ามตัด intercept ทิ้งแม้ p=0.664 ไม่มีนัยสำคัญ — RAINFALL กับ RAINFALL² เป็นตัวแปรเดียวกัน ตัดพจน์ไหนออกจะบิดรูปทรงเส้นโค้งทั้งเส้น

4. Robust Regression — เปลี่ยน "Estimate" เป็น "Value" (Lecture 3/4)

Coefficients:
                Value    Std. Error t value
(Intercept)     -15.1294   1.8190    -8.3176
log(Area)         0.1417   0.0455     3.1118
log(Population)   1.2715   0.1214    10.4698

rlm() เปลี่ยนหัวคอลัมน์เป็น Value แทน Estimate แต่วิธีอ่านเหมือนเดิม — เขียนสมการเหมือน OLS ทุกประการ เพียงไม่มีคอลัมน์ p-value ให้ในตารางหลัก (ต้องเรียกฟังก์ชันแยกต่างหาก):

\[\widehat{\log(CO2)} = -15.1294 + 0.1417\log(Area) + 1.2715\log(Population) + \cdots\]

5. Model Selection — สมการสุดท้ายจาก Stepwise Output (Lecture 5, mtcars)

Stepwise/forward selection แสดงผลเป็น Parameter Estimates ของโมเดลที่เลือกได้ท้ายสุด: Intercept=39.686, wt=-3.191, cyl=-1.508

\[\widehat{mpg} = 39.686 - 3.191\,wt - 1.508\,cyl\]

ข้อควรระวัง: Forward/Backward/Stepwise อาจให้ชุดตัวแปรไม่เหมือนกัน (คนละเส้นทางค้นหา) — ต้องดูว่าโจทย์ให้ output ของวิธีไหนมา อย่าสมมติว่าทุกวิธีต้องได้สมการเดียวกัน

6. ANOVA: Cell-Means vs Factor-Effects Parameterization (Lecture 6)

ข้อมูลเดียวกัน (bakesale) fit ได้ 2 แบบ ให้สมการต่างกันแต่ทำนายค่าเดียวกัน — ต้องดูว่า R ใช้ contrast แบบไหน (options("contrasts")):

# contr.treatment (default)
Coefficients:
             Estimate Std. Error t value Pr(>|t|)
(Intercept)    55.800      1.013 55.071 < 2e-16 ***
heightmiddle   21.400      1.433 14.934 2.07e-10 ***
heighttop      -4.300      1.433 -3.001 0.00896 **
\(\hat{Y}_{bottom}=55.800\), \(\hat{Y}_{middle}=55.800+21.400=77.2\), \(\hat{Y}_{top}=55.800-4.300=51.5\) — Intercept คือค่าเฉลี่ยกลุ่มอ้างอิง (bottom) ตรง ๆ แต่ละ dummy คือผลต่างจาก reference
# contr.sum
Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) 61.5000      0.5850 105.13 < 2e-16 ***
height1       -5.7000    0.8273   -6.89 5.15e-06 ***
height2       15.7000    0.8273   18.98 6.74e-12 ***
Intercept=61.5000 คือgrand mean (ไม่ใช่กลุ่มอ้างอิง) — \(\tau_i\) คือผลต่างจาก grand mean, \(\tau_{top}=-(\tau_1+\tau_2)=-(−5.7+15.7)=-10\) (คำนวณจากพจน์ที่เหลือ เพราะ \(\sum\tau_i=0\))

7. Penalized Regression — Ridge/LASSO ไม่มี p-value (Lecture 7)

coef(glmnet(...)) ให้รูปแบบสมการเหมือน OLS ทุกประการ (\(\hat{Y}=\hat\beta_0+\hat\beta_1X_1+\cdots\)) แต่มี 2 ข้อต่างสำคัญที่ต้องพูดถึงเสมอเวลาเขียนคำตอบ:

(1) ไม่มี Std. Error/p-value/t-value ในตาราง — coef() ให้แค่ค่า Estimate หลัง shrinkage เท่านั้น ไม่มี inference แบบ OLS ให้ใช้
(2) สัมประสิทธิ์ผ่านการ standardize มาก่อน (X แต่ละตัวถูกปรับ mean=0, variance=1 ก่อนฟิต) — ตีความ "หน่วยจริง" ตรง ๆ แบบ OLS ไม่ได้ทันที ต้องแปลงกลับก่อน และเพราะเป็นค่าที่ shrink เข้าหา 0 โดยตั้งใจ (biased by design) การเทียบขนาดสัมประสิทธิ์ระหว่างตัวแปรทำได้ แต่การอ่าน "effect size ต่อหน่วยจริง" ต้องระวัง

8. GLM Framework — ตาราง Link Function อ้างอิง (Lecture 8)

DistributionCanonical Linkรูปสมการฝั่งซ้าย
Gaussian (Normal)Identity\(\hat{Y}=X\hat\beta\)
BinomialLogit\(\text{logit}(\hat\pi)=\ln\!\left(\dfrac{\hat\pi}{1-\hat\pi}\right)=X\hat\beta\)
PoissonLog\(\log(\hat\mu)=X\hat\beta\)
GammaInverse (\(1/\mu\))\(1/\hat\mu=X\hat\beta\) (แต่สไลด์มักใช้ log link แทนในทางปฏิบัติ)
Inverse Gaussian\(1/\mu^2\)\(1/\hat\mu^2=X\hat\beta\)

ทุกโมเดลด้านล่าง (หัวข้อ 9–13) คือการใช้ตารางนี้กับข้อมูลจริง

12. Multinomial (Baseline-Category Logit) และ Ordinal (Proportional Odds)

Multinomial — เขียนสมการแยกต่อคู่ (category j เทียบ baseline):

Coefficients:
          Value Std. Error t value
nincome 0.01312   0.001971   6.657
\[\log\left(\dfrac{\hat\pi_j}{\hat\pi_{\text{baseline}}}\right) = \hat\beta_{0j} + 0.01312\times nincome\] (เขียนแยกทุก j ที่ไม่ใช่ baseline)

Ordinal (polr) — cumulative logit, มี threshold \(\theta_j\) หลายตัวแต่ slope \(\beta\) ตัวเดียวใช้ร่วมทุก cutpoint:

Coefficients: nincome  0.01312
Intercepts:
  Democrat|Independent    0.2091
  Independent|Republican  1.2916
\[\text{logit}(\hat{P}(Y\leq j)) = \theta_j - \hat\beta X\]   ระวังเครื่องหมายลบ — polr() รายงาน \(\hat\beta\) โดยสมมติว่าลบออกจาก \(\theta_j\) ไม่ใช่บวกแบบ GLM ทั่วไป ผิดเครื่องหมายนี้ = คำนวณค่าทำนายผิดทิศทางทันที

13. Gamma / Inverse Gaussian GLM (Lecture 13)

glm(resist~.^2, family=Gamma(link=log))
Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) 5.31111     0.04762 111.525 4.67e-14 ***
x1+           0.20088   0.04762   4.218 0.00292 **
x3+           0.43718   0.06735   6.491 0.00019 ***
x1+:x3+     -0.15621    0.06735 -2.319 0.04896 *
\[\log(\hat\mu) = 5.31111 + 0.20088\,\mathbb{1}[x1{+}] + 0.43718\,\mathbb{1}[x3{+}] - 0.15621\,\mathbb{1}[x1{+}]\times\mathbb{1}[x3{+}] + \cdots\]

สังเกต: แม้ canonical link ของ Gamma คือ \(1/\mu\) (หัวข้อ 8) แต่สไลด์ระบุ link=log ชัดเจน — อ่าน argument family= ในโค้ดเสมอ อย่าเดาจาก distribution ว่าต้องใช้ canonical link เพราะ log link ตีความง่ายกว่า (multiplicative effect) และใช้บ่อยกว่าในทางปฏิบัติ

14. Linear Mixed-Effects Models (Lecture 14, pulp brightness)

Random effects:
 Groups   Name        Variance Std.Dev.
 operator (Intercept) 0.06808 0.2609
 Residual             0.10625 0.3260
Fixed effects:
            Estimate Std. Error t value
(Intercept) 60.4000      0.1494   404.2

เขียนสมการเต็ม 2 ระดับ — fixed part (จากตาราง Fixed effects) บวก random part (variance จากตาราง Random effects):

\[Y_{ij} = 60.4000 + b_{0i} + \varepsilon_{ij}\] โดย \(b_{0i} \sim \text{iid } N(0,\,0.06808)\), \(\varepsilon_{ij} \sim \text{iid } N(0,\,0.10625)\), เป็นอิสระต่อกัน

Marginal mean (ค่าเฉลี่ยประชากรรวม, ไม่ระบุ operator): \(E[Y]=60.4000\) ตรง ๆ — Conditional/BLUP prediction (operator ที่ระบุเจาะจง i): ต้องบวก \(\hat{b}_{0i}\) (ค่า BLUP เฉพาะกลุ่ม, ได้จาก ranef()) เข้าไปด้วย สองค่านี้ไม่เท่ากัน — โจทย์ที่ถามว่า "ทำนายค่าของ operator คนใดคนหนึ่ง" ต้องใช้ conditional เสมอ ไม่ใช่ marginal

สรุป: ตารางฟังก์ชัน R → ฝั่งซ้ายของสมการ

ฟังก์ชัน Rฝั่งซ้ายของสมการบทที่ใช้
lm(), rlm()\(\hat{Y}\)L1–L7
glm(family=binomial)\(\text{logit}(\hat\pi)\)L9–L10
glm(family=poisson)\(\log(\hat\mu)\)L11
glm(family=poisson) + offset()\(\log(\hat\mu)\) (offset ไม่มี β)L11
glm.nb() (Negative Binomial)\(\log(\hat\mu)\) เหมือน PoissonL11
multinom()\(\log(\hat\pi_j/\hat\pi_{\text{base}})\)L12
polr()\(\text{logit}(\hat{P}(Y\leq j)) = \theta_j - \hat\beta X\)L12
glm(family=Gamma(link=log))\(\log(\hat\mu)\)L13
lmer()\(\hat{Y}_{ij} = X\hat\beta + \hat{b}_i\) (2 ระดับ)L14
