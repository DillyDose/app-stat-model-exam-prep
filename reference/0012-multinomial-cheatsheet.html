Lecture 12 — Multinomial Data

Baseline-Category Logit + Proportional Odds — Formulas & Interpretation Cheat Sheet

สรุปสูตรทั้งสองโมเดล + template แปลผลที่ต้องระบุ baseline เสมอ + คู่มืออ่าน multinom()/polr() — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. เลือกโมเดลให้ถูกก่อนเขียนสมการ: Nominal vs Ordinal

ชนิด responseตัวอย่างโมเดลR function
Nominal (ไม่มีลำดับ)สีที่ชอบ, พรรคที่สังกัด, แผนกที่ติดต่อBaseline-category logistic modelmultinom() — package nnet
Ordinal (มีลำดับ)อายุกลุ่ม, Likert scale, ระดับความเสี่ยงProportional odds modelpolr() — package MASS
\(\pi_j = P(\text{Category } j) \geq 0\),  \(\sum \pi_j = 1\) (j=1..J) — รู้แค่ J−1 probability ก็พอ จึงเป็นที่มาว่าทุกโมเดลในบทนี้มีแค่ J−1 สมการ ไม่ใช่ J สมการ

2. Baseline-Category Logit Model — สมการ (J−1 สมการพร้อมกัน)

\[\log\left[\dfrac{\pi_j(x_i)}{\pi_1(x_i)}\right] = \beta_{0j} + \beta_{1j}\cdot x_{i1} + \cdots + \beta_{pj}\cdot x_{i,p}\],  สำหรับ j = 2, 3, …, J

อ่านให้ถูก: ไม่ใช่สมการเดียว — J category ⟹ J−1 สมการ แต่ละสมการมีชุด β เป็นของตัวเอง (subscript j ติดทุก β) เทียบกับ baseline (category 1) เสมอ — เปลี่ยน baseline แล้วค่า \(\hat{\beta}\) เปลี่ยน แต่ fitted probabilities \(\hat{\pi}_j(x)\) และ prediction ไม่เปลี่ยน (โมเดลเดียวกันเขียนคนละมุมมอง)

Logit ระหว่าง 2 category ที่ไม่ใช่ baseline: \(\log[\pi_j(x)/\pi_k(x)] = \log[\pi_j(x)/\pi_1(x)] - \log[\pi_k(x)/\pi_1(x)] = x(\beta_j-\beta_k)\) — เอาสัมประสิทธิ์ 2 สมการมาลบกันตรง ๆ

Softmax (ความน่าจะเป็นจาก log-odds):

\[\pi_1(x_i) = \dfrac{1}{1 + \sum_{k=2}^{J} \exp(x_i \beta_k)}\] (baseline)
\[\pi_j(x_i) = \dfrac{\exp(x_i \beta_j)}{1 + \sum_{k=2}^{J} \exp(x_i \beta_k)}\], j=2,…,J

3. Interpretation Template — ต้องระบุ Baseline เสมอ (ทักษะที่ออกสอบหนักที่สุด)

Template สำหรับสัมประสิทธิ์ \(\hat{\beta}_{pj}\) (ตัวแปร \(X_p\) ในสมการของ category j)

"\(\exp(\hat{\beta}_{pj})\) คือตัวคูณ (multiplicative factor) ของการเปลี่ยนแปลง odds ของ category j เทียบกับ baseline category เมื่อ \(X_p\) เพิ่มขึ้น 1 หน่วย โดยตัวแปรอื่นคงที่"

ต้องระบุชื่อ baseline category ทุกครั้งที่แปลผล — สัมประสิทธิ์ตัวเดียวกันความหมายเปลี่ยนไปทันทีถ้าเลือก baseline คนละตัว (nominal ที่ J>2 ไม่มี "the" reference โดยธรรมชาติแบบ binary logistic — ต้องประกาศเองเสมอ)

องค์ประกอบที่ขาดไม่ได้: (1) หน่วยของ X ที่เปลี่ยน (2) ชื่อ category ที่กำลังพูดถึง (3) ชื่อ baseline category ระบุชัดเจน (4) คำว่า "multiplicative"/"เท่าของเดิม" ไม่ใช่ "increase/decrease" ตรง ๆ

4. Proportional Odds Model — สมการ (\(\beta\) ชุดเดียว, \(\theta_j\) เปลี่ยนตาม level)

\(\gamma_j = P(Y \leq j) = \sum P(Y=k)\) สำหรับ k ≤ j  (cumulative probability)
\[\log\left[\dfrac{\gamma_j(x_i)}{1 - \gamma_j(x_i)}\right] = \theta_j - \beta\cdot x_i\],  สำหรับ j = 1, …, J−1

โครงสร้างประโยคแปลผล: ไม่ต้องระบุ baseline (ไม่มีแนวคิดนี้) แต่ต้องพูดถึงทิศทางของการเปรียบเทียบตามลำดับ ("moving from lower category to higher category") — ตัวอย่าง: "The odds of moving to a higher category decrease by a multiplicative factor of \(\exp(\hat{\beta})\) as X increases by one unit" — คำนวณ P(category กลาง) จากการลบ cumulative probability ที่ติดกัน: \(P(\text{category } j) = \hat{\gamma}_j - \hat{\gamma}_{j-1}\)

6. Brant Test — เช็ค Proportional Odds Assumption

\(H_0\): Proportional odds (parallel regression) assumption holds — สัมประสิทธิ์เท่ากันในทุก cumulative logit
\(H_1\): มีตัวแปรอย่างน้อยหนึ่งตัวละเมิด proportionality

อ่านผล: แถว Omnibus p<0.05 → ปฏิเสธ \(H_0\) (assumption ถูกละเมิด) → ดู p-value รายตัวแปรเพื่อหาตัวการ → ตัดตัวที่เป็นปัญหาออก → เช็คซ้ำ — ต้องชั่งน้ำหนัก: ตัดตัวแปรที่ทำนายดีที่สุดออกเพื่อให้ assumption ผ่าน อาจไม่คุ้มเสมอไป (อาจพิจารณา baseline-category logit แทน เพราะไม่มี assumption นี้ตั้งแต่แรก)

7. Inference: Wald Test vs LRT

Wald test (จาก Estimate/Std.Error ใน summary()) ทดสอบ β ทีละตัว — ไม่นิยมเพราะตัดตัวแปร x หนึ่งตัวกระทบสัมประสิทธิ์ทั้ง J−1 สมการพร้อมกัน
LRT เทียบ nested models — ทดสอบผลรวมของการตัดตัวแปรได้ในครั้งเดียว จึงเป็นตัวหลัก

pchisq(deviance(model2)-deviance(model), model$edf-model2$edf, lower=F)
# หรือ
anova(model2, model, test="Chisq")
