Lecture 7 — Penalized Regression

Ridge/LASSO/EN Formulas + glmnet Cheat Sheet

สรุปสูตร penalty ทั้งหมด + โค้ด glmnet ที่ต้องใช้ซ้ำทุกครั้งที่ fit penalized regression — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. โจทย์ตั้งต้น (OLS ที่เขียนใหม่)

\(\hat{\beta} = \underset{\beta}{\arg\min} \sum_i (Y_i - X_i\beta)^2\)  — สมมติ X standardized (mean 0, var 1) และ Y centered (mean 0) จึงไม่มีพจน์ intercept แยก

ปัญหาของ OLS: (1) prediction accuracy ต่ำ (low bias, high variance) (2) interpretability แย่เมื่อ p เยอะ (3) multicollinearity (4) ใช้ไม่ได้เมื่อ p > n (X'X ไม่ invertible)

2. สมการทั่วไปของ Penalized Regression

\[\hat{\beta} = \underset{\beta}{\arg\min} \sum_i (Y_i-X_i\beta)^2 + P_\lambda(\beta)\]

\(\lambda=0\) → เท่ากับ OLS พอดี  |  \(\lambda\to\infty\) → บีบทุกสัมประสิทธิ์เข้าใกล้ศูนย์

3. สูตร Penalty แต่ละแบบ (เทียบข้าง ๆ กัน)

วิธีPenalty term \(P_\lambda(\beta)\)NormExact zero ได้ไหม
Ridge\(\lambda\sum_j \beta_j^2\)\(\ell_2\)ไม่ได้ — หดเข้าใกล้ 0 เท่านั้น
LASSO\(\lambda\sum_j |\beta_j|\)\(\ell_1\)ได้ — cut variable ออกจากโมเดล
Elastic Net\(\lambda_1\sum_j |\beta_j| + \lambda_2\sum_j \beta_j^2\)\(\ell_1\)+\(\ell_2\)ได้บางส่วน (grouping effect)
L0 (best subset)\(\lambda\lVert \beta \rVert_0\)\(\ell_0\) (นับจำนวน)ได้ตรงตามนิยาม แต่คำนวณยาก (combinatorial)

Constrained form ↔ Penalized form: Ridge: \(\sum \beta_j^2\leq t\) ↔ \(+\lambda\sum \beta_j^2\); LASSO: \(\sum |\beta_j|\leq t\) ↔ \(+\lambda\sum |\beta_j|\) — สองรูปเทียบเท่ากันเสมอเมื่อ \(\lambda\) คู่กับ t ถูกต้อง

4. glmnet Reparameterization

\[P_\lambda(\beta) = \lambda\left[ \alpha \sum_j|\beta_j| + \dfrac{(1-\alpha)}{2} \sum_j\beta_j^2 \right]\]

alpha=0 → Ridge  |  alpha=1 → LASSO  |  0<alpha<1 → Elastic Net

5. เรขาคณิต: ทำไม L1 ได้ exact zero แต่ L2 ไม่ได้

คำตอบ = จุดแรกที่ contour วงรีของ RSS สัมผัส constraint region. L1-norm = diamond มีมุมแหลมบนแกน → สัมผัสที่มุมบ่อย → พิกัดหนึ่งเป็น 0 เป๊ะ ("sparsity inducing"). L2-norm = วงกลมไม่มีมุม → สัมผัสกระจายรอบขอบ → ได้แค่หด ไม่เท่ากับ 0 เป๊ะ ("weight sharing").

7. Template ประโยคที่ต้องระวัง (ใช้ตอบข้อสอบ)

ห้ามตีความ \(\hat{\beta}\) จาก Ridge/LASSO/EN แบบเดียวกับ lm() ตรง ๆ เพราะ: (1) \(\hat{\beta}\) อยู่บนสเกลของ X ที่ standardize แล้ว ไม่ใช่หน่วยดั้งเดิม (2) \(\hat{\beta}\) ถูก shrink เข้าหา 0 โดยตั้งใจ (biased by design) ไม่ใช่ unbiased estimate (3) สัมประสิทธิ์ = 0 จาก LASSO ไม่ใช่บทสรุปเชิงสถิติที่ยืนยันด้วย p-value — เป็นแค่ผลของ \(\lambda\) ที่เลือกโดย cross-validation รอบนั้น

Bias-variance tradeoff: "Penalized regression ยอมรับ bias ที่เพิ่มขึ้นเพื่อแลกกับ variance ที่ลดลงมากกว่า ทำให้ MSE รวม (\(\text{bias}^2+\text{variance}\)) ต่ำลง โดยเฉพาะเมื่อ p ใหญ่หรือมี multicollinearity"
