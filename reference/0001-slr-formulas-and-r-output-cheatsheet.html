Lecture 1 — Simple Linear Regression

SLR Formulas + Reading summary(lm(...)) — Cheat Sheet

สรุปสูตรและ template แปลผลที่ต้องใช้ซ้ำทุกครั้งที่ fit regression — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. โมเดลและ Assumption

\(Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i\),  \(\varepsilon_i \sim \text{iid } N(0,\sigma^2)\)

Assumption 4 ข้อของ ε: (1) mean zero (2) independent (3) constant variance (homoscedasticity) (4) normally distributed

2. OLS Estimators

\[\hat{\beta}_1 = \dfrac{\sum (X_i-\bar{X})(Y_i-\bar{Y})}{\sum (X_i-\bar{X})^2} = \dfrac{\text{COV}_{xy}}{S_x^2} = r_{xy} \times \dfrac{S_y}{S_x}\]
\[\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}\]
\(SSE = \sum (Y_i-\hat{Y}_i)^2\),  \(s^2 = MSE = \dfrac{SSE}{n-2}\),  \(s = \sqrt{MSE}\)

3. Hypothesis Test / CI สำหรับ β

\[t = \dfrac{\hat{\beta}-\beta}{SE[\hat{\beta}]} \sim t_{n-2}\]
\(SE[\hat{\beta}_1] = \sqrt{\dfrac{s^2}{\sum (X_i-\bar{X})^2}}\),  \(SE[\hat{\beta}_0] = \sqrt{s^2\left(\dfrac{1}{n} + \dfrac{\bar{X}^2}{\sum (X_i-\bar{X})^2}\right)}\)
\[(1-\alpha)\% \text{ CI: } \hat{\beta} \pm t_{(1-\alpha/2,\, n-2)} \times SE[\hat{\beta}]\]

กฎ: CI ไม่ครอบคลุม 0 ⟺ ปฏิเสธ H₀:β=0 ที่ระดับ α เดียวกัน (ให้ข้อสรุปตรงกับ p-value เสมอ)

4. R² และ ANOVA

\(SST = SSE + SSR\),  \(R^2 = \dfrac{SSR}{SST} = 1-\dfrac{SSE}{SST}\) (SLR: \(R^2 = r_{xy}^2\))
\(F = \dfrac{MSR}{MSE} \sim F_{(1,\,n-2)}\),  \(t_{n-2}^2 = F_{(1,\,n-2)}\) (SLR เท่านั้น)

3 ข้อควรระวังเรื่อง R²: สูงไม่ใช่ = ทำนายแม่น, สูงไม่ใช่ = ฟิตดีเสมอ, ต่ำไม่ใช่ = ไม่สัมพันธ์กันเลย (อาจสัมพันธ์แบบไม่เชิงเส้น)

5. Mean Response vs Prediction ที่ X=X₀

Mean response (CI)Prediction (PI)
ถามอะไรค่าเฉลี่ยทฤษฎีที่ X₀ค่าสังเกตใหม่ 1 ตัวที่ X₀
Point estimate\(\hat{Y} = \hat{\beta}_0+\hat{\beta}_1 X_0\) (เท่ากัน)
SE\(s\sqrt{\dfrac{1}{n} + \dfrac{(X_0-\bar{X})^2}{\sum (X_i-\bar{X})^2}}\)\(s\sqrt{1 + \dfrac{1}{n} + \dfrac{(X_0-\bar{X})^2}{\sum (X_i-\bar{X})^2}}\)
กว้างกว่ากันPrediction กว้างกว่าเสมอ (มีพจน์ "+1" เพิ่ม = ความแปรปรวนของค่าสังเกตใหม่)

6. อ่าน summary(lm(...)) — Field Glossary

Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept)   β̂₀       SE[β̂₀]   t stat   p-value ของ H0:β0=0
x             β̂₁       SE[β̂₁]   t stat   p-value ของ H0:β1=0

Residual standard error: s (= √MSE), df = n-2
Multiple R-squared: R² (SLR เท่านั้น: = r_xy²)
Adjusted R-squared: R² ปรับด้วยจำนวนตัวแปร (ใช้เทียบโมเดลที่มี p ต่างกัน)
F-statistic: F=MSR/MSE, df=(1,n-2), p-value (SLR: เท่ากับ p-value ของ x พอดี)

7. Template ประโยคแปลผล (ใช้ตอบข้อสอบ)

Slope (\(\hat{\beta}_1\)): "จากข้อมูลนี้ เมื่อ [ตัวแปร X] เพิ่มขึ้น 1 [หน่วยของ X] [ตัวแปร Y] คาดว่าจะเพิ่มขึ้น/ลดลงโดยเฉลี่ย [|\(\hat{\beta}_1\)|] [หน่วยของ Y] (อย่างมีนัยสำคัญทางสถิติที่ p=[p-value])"

Intercept (\(\hat{\beta}_0\)): "เมื่อ [X] = 0 [Y] ที่คาดไว้คือ [\(\hat{\beta}_0\)] [หน่วยของ Y]" — เช็คก่อนว่า X=0 อยู่ในช่วงข้อมูลจริงหรือไม่ ถ้าไม่อยู่ ระวัง extrapolation

ห้ามใช้: คำว่า "ทำให้" / "เป็นสาเหตุของ" กับข้อมูล observational — ใช้ "สัมพันธ์กับ" / "คาดว่าจะเพิ่มขึ้นโดยเฉลี่ย" แทนเสมอ เว้นแต่ข้อมูลมาจาก randomized experiment

Confidence interval ของ β: "มั่นใจ [1−α]% ว่าค่าจริงของ β อยู่ระหว่าง [lower] ถึง [upper]"
