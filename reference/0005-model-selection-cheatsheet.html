Lecture 5 — Model Selection

Model Selection: Criteria + R Syntax Cheat Sheet

สูตร Cp/AIC/BIC, ทิศทาง "ดีกว่า" ของแต่ละ criterion, และ R syntax ของทุกวิธี selection ที่ใช้ในบทเรียน — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. Stepwise 3 รูปแบบ

วิธีเริ่มจากทำอะไร
Forward SelectionConstant mean model (ไม่มีตัวแปรเลย)เพิ่มตัวแปรทีละตัว จนเพิ่มต่อไม่คุ้ม
Backward EliminationFull model (ทุกตัวแปร)ลบตัวแปรทีละตัว จนลบต่อไม่คุ้ม
Stepwise (both)Constant mean modelเพิ่ม/ลบสลับกันทุกขั้น จนไม่มีตัวไหนเพิ่ม/ลบได้อีก

ทั้งสามวิธีไม่รับประกันว่าจะได้โมเดลเดียวกัน — เดินเส้นทางค้นหาคนละแบบ อาจติด local optimum คนละจุด (forward กับ stepwise มักลงรอยกันมากกว่า backward)

2. สูตร Selection Criteria — ทิศทาง "ดีกว่า"

Criterionสูตรทิศทางที่ดีกว่า
Adjusted R²\( 1 - \dfrac{SSE/(n-p-1)}{SST/(n-1)} \)ยิ่งมากยิ่งดี
Mallow's Cp\( C_p = (n-(p+1)) \times \dfrac{MSE}{MSE_{full}} + [2(p+1)-n] \)ยิ่งน้อยยิ่งดี — โมเดลดีควรมี Cp ≈ p+1
BIC\( n\log(MSE) + (p+1)\log(n) \)ยิ่งน้อยยิ่งดี
AIC\( n\log(MSE) + 2(p+1) \)ยิ่งน้อยยิ่งดี
จุดที่ข้อสอบชอบเช็ค: Cp/BIC/AIC "ยิ่งน้อยยิ่งดี" (minimize) — สลับทิศทางกับ Adjusted R² ที่ "ยิ่งมากยิ่งดี" (maximize) ห้ามจำสลับ

Cp เมื่อเทียบโมเดลกับตัวเอง (MSE/MSE_full=1) จะลดรูปเหลือ \(C_p = p+1\) เสมอ — ใช้เป็นจุดเช็คสูตรได้  |  Cp ขึ้นกับ full model ที่อ้างอิง — ห้ามเทียบ Cp ข้ามชุดคำนวณที่ใช้ full model คนละตัว

AIC vs BIC: penalty ของ BIC คือ \((p+1)\log(n)\) ส่วน AIC คือ \(2(p+1)\) — เมื่อ \(\log(n) > 2\) (คือ n>7) BIC ลงโทษความซับซ้อนแรงกว่าเสมอ → BIC มักเลือกโมเดลที่เล็กกว่าหรือเท่ากับที่ AIC เลือก

เกณฑ์ AIC ยอมรับตัวแปรที่ทำให้ AIC ลดลง แม้จะไม่ผ่าน p<0.05 — สองเงื่อนไขนี้ไม่เท่ากันเป๊ะ ดังนั้น AIC-based selection มักได้โมเดลที่มีตัวแปร ≥ p-value-based selection

4. R Syntax: Manual Selection ด้วยฟังก์ชันมาตรฐาน

งานโค้ด
ลองเพิ่มตัวแปรทีละตัว + F-testadd1(currentmodel, scope_formula, test="F")
ลองลบตัวแปรทีละตัว + F-testdrop1(currentmodel, test="F")
Stepwise อัตโนมัติ (default=AIC, k=2)step(startmodel, scope_formula, direction="forward"/"backward"/"both")
Stepwise ด้วย BIC แทน AICstep(model, ..., k=log(n))

add1(): เลือกตัวแปรที่ F สูงสุด/p-value ต่ำสุดเข้าก่อนในแต่ละรอบ  |  drop1(): ลบตัวแปรที่ p-value สูงสุดออกก่อนในแต่ละรอบ — ทำซ้ำจนไม่มีตัวไหนเข้า/ออกเกณฑ์ได้อีก

หลายวิธี/หลายเกณฑ์ที่เดินคนละเส้นทางแต่ลงเอยโมเดลเดียวกัน = สัญญาณว่าโมเดลนั้นเสถียร (robust) ไม่ได้ขึ้นกับวิธีเลือกที่ใช้ — ถ้าแต่ละวิธีให้ผลต่างกัน แปลว่าโมเดลไม่เสถียรเท่า ต้องระวังตอนสรุปผล

5. ข้อควรระวัง: Automatic Selection กับพจน์พิเศษ

สถานการณ์ความเสี่ยง

7. วัดความแม่นยำการพยากรณ์ (ยิ่งน้อยยิ่งดีทั้งหมด)

Metricสูตรลักษณะเด่น
RMSE\( \sqrt{\dfrac{\sum (Y_i-\hat{Y}_i)^2}{n_{test}}} \)ยกกำลังสอง — error ใหญ่มีผลกระทบรุนแรงกว่าสัดส่วน
MAE\( \dfrac{\sum |Y_i-\hat{Y}_i|}{n_{test}} \)หน่วยเดียวกับ Y, ไม่ถูก outlier ดึงแรงเท่า RMSE, ตีความง่าย
MAPE\( \dfrac{\sum \left|\dfrac{Y_i-\hat{Y}_i}{Y_i}\right|}{n_{test}} \)ไม่มีหน่วย (สัดส่วน/%) — เทียบข้ามตัวแปรคนละสเกลได้
predacc <- function(y, yhat){
  n <- length(y)
  RMSE <- sqrt(sum((y-yhat)^2)/n)
  MAE <- sum(abs(y-yhat))/n
  MAPE <- sum(abs((y-yhat)/y))/n
  data.frame(RMSE=RMSE, MAE=MAE, MAPE=MAPE)
}
