Lecture 2 — Multiple Linear Regression

MLR Formulas + Reading summary(lm(...)) — Cheat Sheet

สรุปสูตร, dummy/interaction, และ template แปลผลแบบ "holding other variables constant" ที่ต้องใช้ซ้ำทุกครั้งที่ fit MLR — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. โมเดลและจำนวนพารามิเตอร์

\(Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \cdots + \beta_p X_{ip} + \varepsilon_i\),  \(\varepsilon_i \sim \text{iid } N(0,\sigma^2)\)

มีตัวแปรอิสระ p ตัว → พารามิเตอร์ β ทั้งหมด p+1 ตัวเสมอ (นับ intercept รวมด้วย) — df ของการทดสอบ/CI จึงเป็น \(n-p-1\) (ไม่ใช่ \(n-2\) แบบ SLR)

2. Template แปลผลสัมประสิทธิ์ — "Holding Other Variables Constant"

ไม่มี interaction (เช่น Y~X1+X2): "เมื่อ [X_j] เพิ่มขึ้น 1 หน่วย โดยคุม [ตัวแปรอื่นทั้งหมด] ให้คงที่ [Y] คาดว่าจะเพิ่มขึ้น/ลดลงโดยเฉลี่ย [|β̂_j|] หน่วย" — ตัวเลขนี้ใช้ได้เหมือนกันทุกระดับของตัวแปรอื่น เพราะไม่มี interaction

มี interaction (เช่น Y~X1*X2, X2 เป็น dummy): slope ของ X1 ไม่คงที่ข้ามกลุ่มของ X2 อีกต่อไป — ต้องระบุกลุ่ม (baseline) กำกับเสมอ: "สำหรับกลุ่ม [baseline], เมื่อ X1 เพิ่มขึ้น 1 หน่วย Y คาดว่าจะเปลี่ยนโดยเฉลี่ย [β̂(X1)] หน่วย"

Interaction term เอง (β̂ ของ X1:X2): "ความชันของ X1 ที่มีต่อ Y ในกลุ่ม [ไม่ใช่ baseline] ต่างจากกลุ่ม [baseline] อยู่ [β̂(X1:X2)] หน่วย" — วัด "ความต่างของ slope" ไม่ใช่ effect ของตัวแปรใดตัวหนึ่งตรง ๆ

Intercept ของ dummy (β̂ ของ X2 เอง เมื่อไม่มี interaction): "ที่ระดับ X1 เดียวกัน กลุ่ม [ไม่ใช่ baseline] มี Y ต่ำ/สูงกว่ากลุ่ม [baseline] โดยเฉลี่ย [β̂(X2)] หน่วย — เท่ากันทุกระดับของ X1"

Intercept ของ dummy (เมื่อมี interaction): ความต่างนี้เป็นเฉพาะที่ X1=0 เท่านั้น ไม่ใช่ค่าเฉลี่ยตลอดช่วง เพราะช่องว่างระหว่างกลุ่มเปลี่ยนไปตาม X1

3. Dummy Variable vs Interaction — ผลต่อเส้นถดถอย

Marginality/hierarchy principle: ถ้ามีพจน์ interaction X1:X2 ต้องมีพจน์เดี่ยว X1 และ X2 อยู่ในโมเดลเสมอ แม้พจน์เดี่ยวจะไม่มีนัยสำคัญก็ตาม (เขียน X1*X2 ไม่ใช่ X1:X2 เฉย ๆ)

5. Polynomial Model

First-order: \(Y=\beta_0+\beta_1 x+\varepsilon\)  | Second-order: \(Y=\beta_0+\beta_1 x+\beta_2 x^2+\varepsilon\)  | Third-order: \(Y=\beta_0+\beta_1 x+\beta_2 x^2+\beta_3 x^3+\varepsilon\)

ยังนับเป็น "linear regression" เพราะเชิงเส้นในพารามิเตอร์ β ไม่ใช่เชิงเส้นในรูปกราฟ — x² คือตัวแปรอิสระอีกตัวที่ transform มา

เครื่องหมาย β₁,β₂ (second-order)รูปทรง
β₁<0, β₂>0ลดลงเร็วช่วงต้น แล้วแบนราบ (decreasing convex)
β₁>0, β₂>0เพิ่มขึ้นเร่งตัว (increasing convex)
β₁<0, β₂<0ลดลงเร่งตัว (decreasing concave)
β₁>0, β₂<0diminishing returns — เพิ่มเร็วตอนแรกแล้วชะลอ (increasing concave)

ห้ามตัด intercept หรือพจน์อันดับต่ำทิ้ง แม้ไม่มีนัยสำคัญ — X และ X² เป็นตัวแปรเดียวกัน ตัดพจน์ใดพจน์หนึ่งจะบิดรูปทรงเส้นโค้งทั้งเส้น

6. การทดสอบสัมประสิทธิ์รายตัว และ Extra-Sum-of-Squares F-test

\(t = \dfrac{\hat{\beta}_j-\beta_j}{SE[\hat{\beta}_j]} \sim t(n-p-1)\),  \(CI: \hat{\beta}_j \pm t(1-\alpha/2,n-p-1)\times SE[\hat{\beta}_j]\)

ทดสอบกลุ่มตัวแปรพร้อมกัน (full vs reduced model):

\[ESS = SSE_{reduced} - SSE_{full}\]
\(F = \dfrac{ESS/q}{SSE_{full}/(n-p_{full}-1)} \sim F(q, n-p_{full}-1)\), q = จำนวนสัมประสิทธิ์ที่ตัดออกพร้อมกัน
R: anova(reduced_model, full_model) — argument แรก="Model 1"(reduced), argument ที่สอง="Model 2"(full) ในตาราง ไม่ใช่ชื่อตัวแปร R

anova(model) ตัวเดียว (ไม่เทียบสองโมเดล) ให้ sequential/Type I SS — ตัวเลขแต่ละแถวขึ้นกับลำดับที่ตัวแปรถูกใส่เข้าไปใน formula (สลับลำดับ Sum Sq เปลี่ยน แต่ F ภาพรวม/R² ไม่เปลี่ยน)

7. R² และ Adjusted R²

\(SST=SSE+SSR\),  \(R^2=SSR/SST\)
\[\text{Adjusted } R^2 = 1 - \dfrac{SSE/(n-(p+1))}{SST/(n-1)}\]

R² เพิ่มขึ้นเสมอ (หรือเท่าเดิม) เมื่อใส่ตัวแปรเพิ่ม ไม่ว่าจะมีความหมายจริงหรือไม่ — Adjusted R² ลงโทษการเพิ่มตัวแปร ใช้เปรียบเทียบโมเดลที่มี p ต่างกันได้แฟร์กว่า แต่ไม่มีการตีความตรงไปตรงมาแบบ R² (ใช้เปรียบเทียบเท่านั้น)

9. Prediction และ Hidden Extrapolation (MLR เท่านั้น)

ค่า X₀=(X₀₁,…,X₀_p) อาจอยู่ในช่วงข้อมูลจริงของแต่ละตัวแปรแยกกัน แต่ยังเป็น extrapolation ได้ ถ้าไม่เคยมีข้อมูลจุดไหนที่ตัวแปรเหล่านั้นมีค่าคู่กันแบบนั้นมาก่อน — ต้องเช็คขอบเขตร่วม (joint scope) ของทุกตัวแปรพร้อมกัน ไม่ใช่แค่ทีละตัว
