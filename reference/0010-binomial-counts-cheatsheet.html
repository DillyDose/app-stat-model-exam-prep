Lecture 10 — Binomial Counts

Binomial Counts: cbind() Syntax + Overdispersion Cheat Sheet

สรุปความต่างระหว่าง binary (Lesson 9) กับ binomial-count logistic regression, syntax cbind(), และการเช็ค overdispersion — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. Binary vs Binomial Counts

\(Y \sim \text{Binomial}(n, \pi)\),  \(\text{Mean}[Y]=n\pi\),  \(\text{Var}[Y]=n\pi(1-\pi)\)

Binary (Lesson 9) = กรณีพิเศษเมื่อ \(n=1\) ทุกแถว  |  Binomial counts (บทนี้) = กรณีทั่วไปที่ n ต่างกันได้ในแต่ละแถว (แต่ละแถวคือ "จำนวนสำเร็จจาก n ครั้งลอง" ไม่ใช่คนคนเดียว)

2. สิ่งที่เหมือน vs สิ่งที่ต่างจาก Binary Logistic (Lesson 9)

เหมือนเดิมทั้งหมด: ความหมายของสัมประสิทธิ์ β ยังคือ log-odds ของ π ที่เปลี่ยนไปต่อ 1 หน่วย X (ไม่ว่าจะมาจากข้อมูล n=1 หรือ n>1) — ทฤษฎีเบื้องหลังและวิธีตีความไม่เปลี่ยนเลย

สิ่งที่เปลี่ยนจริง ๆ มีแค่ 2 อย่าง: (1) รูปแบบข้อมูล — ต้องมีทั้งจำนวนสำเร็จและจำนวนครั้งลองต่อแถว ไม่ใช่แค่ 0/1 ต่อแถว (2) syntax ใน R — ต้องระบุ response เป็นคู่ (สำเร็จ, ไม่สำเร็จ) แทนที่จะเป็น Y ตัวเดียว

3. Syntax: cbind() แทน Y เดียว

Binary (n_i=1, Lesson 9)Binomial Counts (n_i>1, บทนี้)
Response ใน formula\(Y\) ตรง ๆcbind(Y, n−Y) คือคู่ (สำเร็จ, ไม่สำเร็จ)
ตัวอย่างโค้ดglm(Survived~Age+Sex, family=binomial)glm(cbind(damage,6-damage)~temp, family=binomial)
ทางเลือกเทียบเท่า—glm(Y/n ~ x, weights=n, family=binomial) ให้ β̂, SE เหมือนกันเป๊ะ

ทั้ง family=binomial และ default link=logit เหมือนเดิมทุกประการ — เปลี่ยนแค่การระบุ response

4. Interpretation Template (เหมือน Lesson 9 ทุกประการ)

1. Log-odds: "เมื่อ X เพิ่มขึ้น 1 หน่วย log-odds ของความสำเร็จเปลี่ยนไป β̂ หน่วย (คุมตัวแปรอื่นคงที่)"

2. Odds ratio: "odds คูณด้วย \(e^{\hat{\beta}}\) ทุก 1 หน่วยที่ X เพิ่มขึ้น"

3. Probability: \(\hat{\pi} = e^{\hat{\eta}}/(1+e^{\hat{\eta}})\) ที่จุด X เฉพาะเจาะจง

กฎพิเศษ: เมื่อตัวแปรอิสระเป็น log(X) — "k-fold rule"
\(\log(\omega) = \beta_0 + \beta_1 \log(X)\) ⟹ ถ้า X เพิ่มขึ้นเป็น k เท่า (kX) odds จะเปลี่ยนไปด้วยตัวคูณ \(k^{\beta_1}\) (ไม่ใช่ e^β₁ ต่อหน่วยแบบปกติ เพราะ X ไม่ได้เพิ่มทีละ 1 หน่วยแต่เพิ่มเป็นสัดส่วน)

5. CI ของ Prediction — ทำบน Link Scale ก่อนเสมอ

\(\hat{\eta}(x) \pm z_{(1-\alpha/2)}\times SE[\hat{\eta}]\) → แปลงกลับ → \(\hat{\pi}(x)=e^{\hat{\eta}}/(1+e^{\hat{\eta}})\), ขอบเขต \((\hat{\pi}_l,\hat{\pi}_u)=(e^{\hat{\eta}_l}/(1+e^{\hat{\eta}_l}), e^{\hat{\eta}_u}/(1+e^{\hat{\eta}_u}))\)

ห้ามสร้าง CI ของ π ตรง ๆ ด้วยสูตร normal — π ถูกจำกัดใน (0,1) การแจกแจงไม่สมมาตร ต้องสร้าง CI บน η (ที่ β̂ เป็น normal โดยประมาณ) แล้วค่อยแปลงกลับ

plink <- predict(model, newdata=data.frame(x=x0), se.fit=T, type="link")
CIeta <- c(plink$fit-1.96*plink$se.fit, plink$fit+1.96*plink$se.fit)
CIprob <- exp(CIeta)/(1+exp(CIeta))

6. Goodness-of-Fit และ Nested Model Tests

pchisq(deviance(model), df.residual(model), lower=FALSE) ~ \(\chi^2(n-(p+1))\) เมื่อ n_i≥5 ทุกแถว — p สูง (>0.05) → ไม่ปฏิเสธว่าโมเดล fit เพียงพอ (แต่ไม่ได้พิสูจน์ว่าถูกต้องหรือดีที่สุด)
วิธีสูตรเมื่อไรใช้
Wald's Test\(z=\hat{\beta}_k/SE \sim N(0,1)\)ทดสอบ β_k เดี่ยว — ง่าย ใน summary() อยู่แล้ว
LRT / drop-in-deviance\(D(\hat{\beta}_0)-D(\hat{\beta}) \sim \chi^2_{df}\)ทดสอบเดี่ยวหรือหลายตัวพร้อมกัน — วิธีเดียวที่ใช้ได้จริงเมื่อทดสอบหลายตัว
anova(reducedmodel, model, test="LRT")   # LRT / drop-in-deviance test พร้อม p-value

7. ★ Overdispersion — เช็ค Assumption สำคัญที่สุดของบทนี้ ★

\(\text{Overdispersion: } \text{Var}[Y_i] > n_i\pi_i(1-\pi_i)\)  |  \(\text{Underdispersion: } \text{Var}[Y_i] < n_i\pi_i(1-\pi_i)\)

ผลกระทบ: β̂ ไม่เอนเอียงมากนัก แต่ SE[β̂] จากโมเดล binomial มาตรฐานจะเล็กกว่าความเป็นจริง → p-value เตี้ยเกินไป (ดูมีนัยสำคัญเกินจริง)

\(\hat{\phi} = X^2/(n-(p+1))\) (Pearson's X² หารด้วย residual df) — φ>1.5 บ่งชี้ overdispersion, φ≫2 บ่งชี้รุนแรง 
est.phi <- function(glmobj) sum(residuals(glmobj, type="pearson")^2)/df.residual(glmobj)
est.phi(model)

วิธีแก้: quasi-likelihood — \(\text{Var}[Y_i]=\phi \cdot n_i\pi_i(1-\pi_i)\), เปลี่ยน family=binomial → family=quasibinomial

สิ่งที่เปลี่ยน: SE[β̂] ขยายขึ้นด้วยตัวคูณ \(\sqrt{\hat{\phi}}\), สถิติทดสอบเปลี่ยนจาก z เป็น \(t=\hat{\beta}/SE \sim t_{(n-(p+1))}\), p-value สูงขึ้น

สิ่งที่ไม่เปลี่ยน: β̂ เหมือนเดิมทุกประการ (φ ไม่กระทบ E[Y_i])

Nested model test ภายใต้ overdispersion — ใช้ F-test แทน χ²:

\(F = \dfrac{(\text{Deviance}_{reduced}-\text{Deviance}_{full})/(df_{reduced}-df_{full})}{\hat{\phi}_{full}} \sim F(df_{reduced}-df_{full},\, df_{full})\) 
qmodel <- glm(cbind(y,n-y)~x, family=quasibinomial, data=data)
anova(redqmodel, qmodel, test="F")
