Lecture 4 — Regression Diagnostics (Part II)

Outlier / Leverage / Influence — สูตร + Threshold ทั้งหมด

สามคำที่ข้อสอบชอบสับสน + ตารางสูตร/threshold ของทุก influence measure — ใช้ n, p ของโมเดลตัวเองแทนในสูตรได้ทันที (p = จำนวนตัวแปรอิสระ ไม่รวม intercept, p+1 = จำนวนพารามิเตอร์ทั้งหมด)

1. นิยาม 3 คำที่ต้องแยกให้ออก

Outlier — เบี่ยงเบนใน Y (แนวตั้ง, ให้ X คงที่) — วัดด้วย residual/studentized residual

Leverage point — เบี่ยงเบนใน X (แนวนอน) — วัดด้วย hat value hii

Influential point — ไม่ใช่การวัดแบบใหม่ แต่เป็นผลลัพธ์ร่วมของ leverage + residual — วัดด้วย DFFITS/Cook's D/DFBETAS

กฎสำคัญ: Leverage สูงไม่ได้แปลว่า influence สูงเสมอไป — ถ้า Y ของจุดนั้นยังสอดคล้องกับแนวโน้ม (residual ปกติ) มันจะไม่ดึงเส้นถดถอยมาก แต่ leverage ที่สูงมาก (hii→1) ก็ทำให้ influential ได้เองผ่านพจน์ \( (1-h_{ii})^2 \) ในสูตร Cook's D แม้ residual จะปกติ — จุดที่เบี่ยงเบนทั้ง X และ Y พร้อมกันจะ influential รุนแรงที่สุด

2. ตารางสูตร + Threshold ทั้งหมด

ตัวชี้วัดวัดอะไรสูตรRule of thumb
Hat value hiiLeverage (outlying X)\( 0 \leq h_{ii} \leq 1 \), \( \sum h_{ii} = p+1 \)\( h_{ii} > 2(p+1)/n \)
Internally studentized residual r_iOutlier ใน Y\( r_i = e_i/\sqrt{MSE(1-h_{ii})} \)\( r_i > 2 \)
Studentized deleted residual t_i
(= Externally studentized / RStudent)		Outlier ใน Y (ไม่มี masking)\( t_i = e_i\sqrt{(n-p-2)/(SSE(1-h_{ii})-e_i^2)} \sim t(n-p-2) \)\( t_i > t(1-\alpha/2n; n-p-2) \) (Bonferroni) หรือ \( t_i > 3 \) (กฎง่าย)
DFFITSInfluence บนค่า fit ที่ i\( (DFFITS)_i = t_i\sqrt{h_{ii}/(1-h_{ii})} \)\( |DFFITS|>1 \) (เล็ก-กลาง) หรือ \( >2\sqrt{(p+1)/n} \) (ชุดใหญ่)
Cook's Distance D_iInfluence รวมบนค่า fit ทั้ง n ค่า\( D_i = e_i^2h_{ii} / [(p+1)MSE(1-h_{ii})^2] \)\( D_i > 4/n \) (นิยม) หรือเทียบ percentile ของ F(p+1,n−p−1)
DFBETASkInfluence บนสัมประสิทธิ์ β_k ตัวเดียว\( (DFBETAS)_{k(i)} = (\hat{\beta}_k-\hat{\beta}_{k(i)})/\sqrt{MSE_{(i)}c_{kk}} \)\( |DFBETAS|>1 \) (เล็ก-กลาง) หรือ \( >2/\sqrt{n} \) (ชุดใหญ่)
COV RATIOผลต่อความแม่นยำ (precision) ของสัมประสิทธิ์\( [1/(1-h_{ii})] \times [MSE_{(i)}/MSE]^{p+1} \)\( |COV\ RATIO-1| \geq 3(p+1)/n \)

COV RATIO < 1 = ตัดเคสนี้ออกแล้ว CI ของสัมประสิทธิ์แคบลง (เคสนี้เคยเพิ่มความไม่แน่นอน)  |  COV RATIO > 1 = ตัดออกแล้ว CI กว้างขึ้น (เคสนี้เคยช่วยให้แม่นยำขึ้น มักเป็น leverage point ที่ไม่ใช่ outlier)

3. Masking Effect — ทำไมต้องมี t_i แยกจาก r_i

r_i คำนวณจาก MSE ที่รวม residual ของเคสนั้นเองด้วย — ถ้าเคสนั้นเป็น outlier รุนแรง residual ใหญ่ของมันจะดัน MSE ให้สูงขึ้น ทำให้ r_i ของตัวมันเองถูก "เจือจาง" จนดูไม่ผิดปกติ (masking) — t_i แก้ด้วยการคำนวณ MSE(i) โดยไม่รวมเคส i จึงจับ outlier รุนแรงได้แม่นกว่าเสมอ

4. อ่านผลจาก R

e <- resid(model)                    # residual ดิบ
h <- hatvalues(model)                # leverage h_ii
rstandard(model)                     # internally studentized (r_i)
rstudent(model)                      # studentized deleted (t_i / RStudent)
influence.measures(model)            # ตารางรวม DFBETAS, dffit, cov.r, cook.d, hat (มี * กำกับเคสที่ flag)
plot(model, 4)                       # Cook's distance plot
library(olsrr) — ชุดพล็อตสำเร็จรูป: ols_plot_resid_stand() (internally studentized), ols_plot_resid_stud() (studentized deleted), ols_plot_resid_lev() (RStudent vs Leverage — แยก 3 กลุ่มสี: outlier/leverage/ปกติ), ols_plot_cooksd_bar()/chart(), ols_plot_dfbetas() — threshold ที่ olsrr พิมพ์กำกับใช้สูตร large-sample เสมอ (\( 2\sqrt{(p+1)/n} \), \( 2/\sqrt{n} \))

5. ตรรกะการอ่านกราฟ RStudent vs Leverage (3 กลุ่ม)

6. Remedies สำหรับ Influential Point

ทางเลือกใช้เมื่อไร
ตัดทิ้ง (Remove)มั่นใจว่าเป็นข้อผิดพลาดจากการเก็บ/บันทึกข้อมูล หรือไม่ควรอยู่ใน population ที่ศึกษา
Robust regression — LMS (Least Median of Squares)ข้อมูลจริงถูกต้อง, minimize median ของ residual² แทน sum — ทนต่อ outlier มาก แต่ไม่มี SE/p-value ให้ในตัว
Robust regression — IRLS / M-estimator (Huber, Bisquare)ข้อมูลจริงถูกต้อง, ถ่วงน้ำหนัก w_i ลดลงตาม residual แล้ว iterate — ให้ SE/t-value แต่ต้องใช้ f.robftest() แยกหา p-value
Huber weight: \( w_i=1 \) ถ้า \( |e_i|\leq 1.345 \), มิฉะนั้น \( w_i=1.345/|e_i| \) (ลดน้ำหนักค่อยเป็นค่อยไป ไม่มีวันเป็น 0)
Bisquare weight: \( w_i=[1-(e_i/4.685)^2]^2 \) ถ้า \( |e_i|\leq 4.685 \), มิฉะนั้น \( w_i=0 \) (ตัดทิ้งเต็ม ๆ เมื่อ residual รุนแรงมาก — ดุกว่า Huber) 
library(MASS)
lmsreg(y~x1+x2, data=d)                                    # LMS — coef() เท่านั้น ไม่มี SE
rlm(y~x1+x2, data=d, method="M", psi=psi.huber)             # IRLS-Huber
rlm(y~x1+x2, data=d, method="M", psi=psi.bisquare, maxit=50) # IRLS-Bisquare
library(sfsmisc); f.robftest(model, var="x1")                # p-value ของ rlm()

Action เมื่อเจอเคสที่ถูก flag: ตรวจว่าข้อมูลถูกต้องหรือไม่ก่อนเสมอ → ถ้าถูกต้องจริง ให้ fit ทั้งโมเดลเต็มและ robust regression คู่กัน แล้วรายงานทั้งสองผลเปรียบเทียบว่าข้อสรุปเปลี่ยนไปมากแค่ไหน
