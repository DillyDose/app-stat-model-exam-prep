Lecture 14 — Linear Mixed-Effects Models

Fixed vs Random Effects + lmer() Output Cheat Sheet

สรุปสมการ LMM, checklist ตัดสินใจว่าต้องใช้ mixed model เมื่อไร, และคู่มืออ่าน summary(lmer(...)) ทีละบล็อก — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. Fixed Effect vs Random Effect — นิยาม

Fixed effect — ค่าคงที่ที่ไม่รู้ค่า (unknown constant) ที่พยายามประมาณจากข้อมูล — lm()/GLM ธรรมดาจัดการแค่ fixed effect เท่านั้น

Random effect — ตัวแปรสุ่ม (random variable) ที่พยายามประมาณพารามิเตอร์ของการแจกแจงของมัน ไม่ใช่ค่าตัวมันเองตรง ๆ — ต้องเป็น grouping factor เสมอ (เช่น operator, subject, school ไม่ใช่ตัวแปรต่อเนื่องอย่าง age)

Mixed model = ผสม fixed effect + random effect ในสมการเดียว

Fixed effect = จุดสนใจหลัก ตีความเหมือนตัวแปรใน regression ทั่วไป — Random effect = ไม่ใช่จุดสนใจหลัก แต่ "จับ" ความสัมพันธ์ระหว่าง observation ในกลุ่มเดียวกันไว้ และแตกความแปรปรวนรวมของ Y ออกเป็นระดับต่าง ๆ

2. สมการโมเดล

Matrix form: \[\mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\boldsymbol{\gamma} + \boldsymbol{\varepsilon}\]   (Fixed: \(\mathbf{X}\boldsymbol{\beta}\), Random: \(\mathbf{Z}\boldsymbol{\gamma}\))

\(\boldsymbol{\gamma} \sim N(0, \sigma^2\mathbf{D})\),  \(\boldsymbol{\varepsilon} \sim N(0, \sigma^2\mathbf{R})\),  \(\boldsymbol{\gamma}\) และ \(\boldsymbol{\varepsilon}\) อิสระต่อกัน
⟹ \(\mathbf{Y} \sim N(\mathbf{X}\boldsymbol{\beta}, \sigma^2(\mathbf{R} + \mathbf{Z}\mathbf{D}\mathbf{Z}^T))\) — พจน์ \(\mathbf{Z}\mathbf{D}\mathbf{Z}^T\) คือแหล่งที่มาของความสัมพันธ์ระหว่าง observation ในกลุ่มเดียวกันที่ lm() ไม่มีทางจับได้

Scalar form (random intercept, ใช้ตอบข้อสอบ):

\[Y_{ij} = \beta_0 + \beta_1 X_{ij} + b_{0i} + \varepsilon_{ij}\]
\(b_{0i} \sim \text{iid } N(0, \sigma^2_b)\) (random intercept เฉพาะกลุ่ม i),  \(\varepsilon_{ij} \sim \text{iid } N(0, \sigma^2)\),  อิสระต่อกัน

\(\beta_0, \beta_1\) = fixed effect (ค่าคงที่ประชากร) — \(b_{0i}\) = ค่าเบี่ยงเบนของ intercept เฉพาะกลุ่ม i จาก \(\beta_0\) — ถ้า \(\sigma^2_b=0\) โมเดลยุบกลับเป็น lm() ธรรมดาทันที (LMM คือ generalization ของ regression ปกติ ไม่ใช่เทคนิคคนละสาย)

3. Checklist: เมื่อไรต้องใช้ Mixed Model

  1. ข้อมูลเป็น Clustered (หน่วยวัดครั้งเดียว แต่ nested ในกลุ่ม เช่น นักเรียนในโรงเรียน), Longitudinal (วัดซ้ำหน่วยเดิมข้ามเวลา), Clustered-Longitudinal (ทั้งสองแบบผสม), หรือ Repeated Measures (วัดซ้ำข้ามมิติใดก็ได้) ใช่หรือไม่?
  2. ตัวแปรระดับสูง (เช่น ประเภทโรงเรียน) คงที่ซ้ำกันสำหรับหลาย observation ในกลุ่มเดียวกันหรือไม่? (ถ้าใช่ → error terms สัมพันธ์กันเอง)
  3. ถ้าฟิต lm()/GLM ตรง ๆ จะละเมิด assumption ข้อ 2: error independent จาก Lesson 1 หรือไม่?

ถ้าตอบ "ใช่" ข้อใดข้อหนึ่ง → ต้องใช้ mixed model ไม่ใช่ lm()/GLM ธรรมดา ไม่งั้นจะเจอ 3 ปัญหา: (1) Unit of analysis problem (2) Aggregation bias (ecological fallacy) (3) SE ผิด (ต่ำเกินจริง → p-value ต่ำเกินจริง → false positive)

Syntaxความหมาย

Random effects block = variance component — แตกความแปรปรวนรวมของ Y ออกเป็น "ต่างกันเพราะกลุ่ม" (แถว grouping factor) กับ "ต่างกันเพราะเหตุสุ่มภายในกลุ่ม" (แถว Residual) — ยิ่งมี random slope เพิ่ม จะเห็นบรรทัดเพิ่มพร้อมคอลัมน์ Corr

Fixed effects block = ตีความเหมือน lm() ทุกประการ (ค่าเฉลี่ยของประชากร/population-average) — ไม่มี p-value ให้อัตโนมัติเพราะ df ของ fixed effect ใน mixed model ไม่ชัดเจน (ต้องเลือกวิธีประมาณ p-value เอง — หัวข้อ 8)

7. Intraclass Correlation Coefficient (ICC)

\[\text{ICC} = \dfrac{\sigma^2_{group}}{\sigma^2_{group} + \sigma^2_{residual}}\]

Template แปลผล: "[ICC×100]% ของความแปรปรวนทั้งหมดใน [Y] มาจากความแตกต่างระหว่าง [grouping factor] ส่วนที่เหลืออีก [(1−ICC)×100]% มาจากความแตกต่างภายในกลุ่มเดียวกัน" — ICC ใกล้ 0 → โครงสร้างกลุ่มแทบไม่มีผล (lm() ธรรมดาอาจให้ผลใกล้เคียง mixed model)

9. \(R^2\) สำหรับ Mixed Model

Marginal \(R^2\) — สัดส่วน variance ที่อธิบายจาก fixed effects เท่านั้น
Conditional \(R^2\) — สัดส่วน variance ที่อธิบายจาก fixed + random effects รวมกัน

ช่องว่าง Conditional − Marginal ที่กว้าง = ความแตกต่างระหว่างกลุ่ม/บุคคล (individual heterogeneity) เป็นแหล่งความแปรปรวนสำคัญที่ lm() ธรรมดาจะทิ้งไว้ใน unexplained error ทั้งหมด
