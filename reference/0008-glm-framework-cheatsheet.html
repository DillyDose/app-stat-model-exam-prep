Lecture 8 — Exponential Family and Generalized Linear Models

Exponential Family + GLM Framework Cheat Sheet

สรุปกรอบทฤษฎีที่ Lecture 9–14 ทั้งหมดตั้งอยู่บน — รูปทั่วไปของ exponential family, 3 องค์ประกอบของ GLM, ตาราง canonical link, และวิธี inference — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. Exponential Family Distribution — รูปทั่วไป

\(f(y; \theta, \phi) = \exp\left\{ \frac{y\theta - b(\theta)}{a(\phi)} + c(y,\phi) \right\}\)

\(\theta\) = canonical parameter (location, ผูกกับ mean)  |  \(\phi\) = dispersion parameter (scale)  |  \(a(\cdot), b(\cdot), c(\cdot)\) = ฟังก์ชันที่รู้รูปแบบแน่นอนแล้ว (ไม่ใช่พารามิเตอร์ที่ต้องประมาณ)  |  มักเขียน \(a(\phi)=\phi/w\)

\(\mu \equiv E[Y] = b'(\theta)\),  \(\text{Var}[Y] = b''(\theta)\cdot a(\phi)\),  variance function \(V(\mu) \equiv b''(\theta)\) ⟹ \(\text{Var}[Y] = a(\phi)\cdot V(\mu)\)

ใช้ 2 สูตรนี้ตรวจว่าจัดรูป EFD ถูกหรือไม่ได้เสมอ (ไม่ต้องหา E[Y] จาก definition ตรง ๆ)

2. 3 องค์ประกอบของ GLM (ท่องให้ขึ้นใจ)

1) Random component: \(y_i \mid x_{i1},\ldots,x_{ip} \sim \text{ind. EFD}(\theta_i, \phi)\) — response แจกแจงแบบใดแบบหนึ่งใน exponential family, แต่ละ observation อิสระต่อกัน

2) Systematic component: \(\eta_i = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_p x_{ip} = x_i\beta\) — linear predictor เหมือน classical linear model ทุกประการ

3) Link function: \(g(\mu_i) = \eta_i\) — เชื่อม mean ของ response (μ_i) เข้ากับ linear predictor (η_i)

Canonical link: link function g(·) ที่ทำให้ \(\eta_i = g(\mu_i) = \theta_i\) พอดี — คือฟังก์ชันผกผันของ b'(·) — R ใช้เป็น default เสมอถ้าไม่ระบุ link เอง (ไม่ใช่ทางเลือกเดียวที่ใช้ได้ แต่สวยที่สุดทางคณิตศาสตร์)

3. Template: เขียนสมการ GLM ให้ครบ (ต้องมี 3 บรรทัด)

1) \(y_i \mid x_{i1},\ldots,x_{ip} \sim \text{ind.}\) [distribution](พารามิเตอร์) — เลือกจาก range ของ y (ดูตารางข้อ 4)

2) \(\eta_i = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_p x_{ip}\) — เหมือนเดิมทุกครั้งไม่ว่า distribution ใด

3) \(g(\mu_i) = \eta_i\) พร้อมระบุรูปของ g(·) ชัดเจน (เช่น log(μ_i)=η_i, logit(μ_i)=η_i) — ไม่ระบุ link = สมการยังไม่สมบูรณ์

5. OLS คือ GLM แบบพิเศษ

OLS/classical linear regression = GLM ที่เลือก random component = Normal และ link function = identity (canonical link ของ Normal) — เมื่อ \(g(\mu_i)=\mu_i=\eta_i\) แทนกลับได้ \(E[y_i]=\beta_0+\beta_1 x_{i1}+\cdots\) ซึ่งคือ linearity assumption ของ Lecture 1 ทุกตัวอักษร ไม่ใช่โมเดลคนละตระกูล

6. Fitting: MLE, Newton-Raphson ≡ IRWLS

β ประมาณด้วย maximum likelihood — Gaussian GLM (=OLS) มี closed-form; distribution อื่นทั้งหมดต้องใช้ numerical optimization

\(x^{(t+1)} = x^{(t)} - [g''(x^{(t)})]^{-1}g'(x^{(t)})\) (Newton-Raphson)  ≡  Fisher scoring บน log-likelihood ของ GLM ≡ IRWLS:

\(Z^{(k)} = \hat{\eta}^k + (Y-\hat{\mu}^{(k)})\left(\dfrac{d\eta}{d\mu}\right)_{(k)}\) (working response),  \(W^k = \text{diag}\left\{\text{Var}^{-1}[Y_i]\left(\dfrac{d\mu}{d\eta}\right)^2_{(k)}\right\}\) (weight)

\(\hat{\beta}^{(k+1)} = (X^TW^{(k)}X)^{-1}X^TW^{(k)}Z^{(k)}\) — เหมือน weighted least squares แต่ Z, W คำนวณใหม่ทุกรอบ (นี่คือที่มาของ "iteratively")

7. Deviance และ Goodness-of-Fit

\(D(\hat{\beta}) = 2\phi(l_F - l(\hat{\beta}))\),  scaled deviance \(D(\hat{\beta})/\phi = 2(l_F - l(\hat{\beta})) \sim \text{exact } \chi^2\)

\(l_F\) = log-likelihood ของ saturated model (μ̃_i=y_i ทำนายเป๊ะทุกจุด, uninformative แต่เป็น baseline), \(l(\hat{\beta})\) = log-likelihood ของโมเดลที่สนใจ

เส้นจำนวน likelihood: Worst fit (intercept only, l(β̂₀)) → Model analysed (l(β̂)) → Perfect fit (l_s, saturated) — ระยะจาก model ไป perfect fit = \(D\) (deviance); ระยะจาก worst fit ไป perfect fit ทั้งหมด = \(D_0\) (null deviance)

\(H_0: g(\theta)=X\beta\) (โมเดลฟิตดี) vs \(H_1: g(\theta)\neq X\beta\)  |  test stat = deviance \(\sim \chi^2_{(n-p-1)}\)  |  ปฏิเสธ H₀ เมื่อ deviance สูง (ตรงข้าม R² — deviance ยิ่งสูงยิ่งแย่ อย่าจำสลับ)

8. ทดสอบ H₀: β_j=0 — Wald's Test vs LRT

วิธีสูตรลักษณะ
Wald's Test\(z = \hat{\beta}_j/SE[\hat{\beta}_j] \sim \text{asymp. } N(0,1)\)ง่าย, R ให้อัตโนมัติในตาราง Coefficients — แต่ประมาณความโค้งที่จุดเดียว
Likelihood Ratio Test (LRT)\(2(l_1-l_0) \sim \text{asymp. } \chi^2_1\)ต้องรัน glm() สองครั้ง (full vs reduced) — แม่นยำกว่าโดยทั่วไป

9. Comparing Nested Models — Drop-in-Deviance Test

\(H_0: \beta_1=\cdots=\beta_k=0\)  ⟹  \(D_0 - D_1 \sim \text{asymp. } \chi^2_k\)  (D₀=deviance โมเดลเล็ก, D₁=deviance โมเดลใหญ่, k=จำนวนพารามิเตอร์ที่ตัดออก) 
anova(model_reduced, model_full, test="Chisq")   # คำนวณ D0-D1 พร้อม p-value อัตโนมัติ

10. Diagnostics for GLM

Hat matrix (ขยายจาก OLS ด้วย weight W): \(H = W^{1/2}X(X^TWX)^{-1}X^TW^{1/2}\) — h_ii สูง = ศักยภาพสูงที่จะดึงผลฟิต (ไม่ใช่ influential point เสมอไป) — ดึงด้วย influence(model)$hat

Influential points ใช้เครื่องมือชุดเดียวกับ linear model: cooks.distance(), dffits(), dfbetas(), covratio(), influence.measures()

เช็ค model adequacy: plot \(g(\hat{\mu})\) เทียบกับ \(\hat{\eta}\) — ควรเป็นเส้นตรง ถ้าโค้ง = link function หรือรูปแบบ linear predictor ไม่เหมาะสม
