Lecture 3 — Regression Diagnostics and Remedies

Diagnostics Cheat Sheet: Assumption → Plot/Test → Pass/Fail → Remedy

ตารางหลักของบทเรียนที่สอบหนักที่สุดรองจากการแปลผล — ใช้ตารางข้อ 1 เป็นแผนที่หลัก แล้วไล่ดูสูตร/threshold/remedy รายละเอียดในหัวข้อถัดไป

1. ตารางหลัก: 4 Assumption ↔ Diagnostic ↔ Pass/Fail ↔ Remedy

AssumptionGraphical checkFormal test (H₀=assumption จริง)ลักษณะ "ผ่าน"ลักษณะ "พัง"Remedy
1. LinearityResiduals vs Fitted—เส้น smoother ราบใกล้ 0 ตลอดช่วง ไม่มีรูปทรงเส้นโค้งเป็นระบบ (U/parabola)Transform X, เพิ่ม X², Box-Cox

3. Constant varianceResiduals vs Fitted (มองความกว้างแถบ)Breusch-Pagan (bptest)แถบกว้างคงที่ตลอดช่วง, p>αแถบบานเป็นกรวย (megaphone), p<αWeighted regression (ถ้าเส้นค่าเฉลี่ยตรงอยู่แล้ว), Transform Y

ข้อควรจำ: Residuals-vs-Fitted ใช้เช็คทั้ง linearity (มอง "แนวโน้ม/โค้ง") และ constant variance (มอง "ความกว้างแถบ") พร้อมกัน — ต้องแยกสองมิตินี้ให้ออกเวลาอ่านกราฟเดียวกัน

ทิศทางการอ่าน formal test ทุกตัวในบทนี้เหมือนกันหมด: H₀ = "assumption เป็นจริง" → ต้องการ p-value สูง (ไม่ปฏิเสธ H₀) ถึงจะ "ผ่าน" — ตรงข้ามกับการทดสอบ \(H_0:\beta=0\) ที่อยากปฏิเสธ

Mean-zero ไม่มี diagnostic แยก เพราะ \(\bar{e}=\sum e_i/n=0\) เสมอโดยพีชคณิตของ OLS — การพังของ mean-zero ที่แท้จริงออกอาการเป็น pattern ในกราฟ residuals-vs-fitted (คือ linearity check)

3. QQ Plot 4 รูปแบบ (Ramsey & Schafer)

แบบรูปทรงความหมาย
A. Normalเส้นตรงสม่ำเสมอผ่าน — มาตรฐานเทียบ
B. Long-tailedรูปตัว S: กลางแบน หางทั้งสองชันแรงKurtosis สูง หางหนาสองด้าน (สมมาตร)
C. Skewed (+)ส่วนโค้งเว้าด้านเดียวตลอดเส้นSkewness — เบ้ต่อเนื่องทางเดียว
D. Outlierส่วนใหญ่เกาะเส้นดี มีจุดเดียวหลุดไกลObservation ผิดปกติจุดเดียว ไม่ใช่ปัญหารูปร่างการแจกแจง

4. Residuals-vs-time 4 รูปแบบ (Independence)

แบบรูปทรงRemedy
A. Normal noiseกระจายสุ่มรอบ 0 ไม่มี patternผ่าน — ไม่ต้องแก้
B. Time trendไต่ระดับขึ้น/ลงตามเวลาต่อเนื่องเติม time เป็นตัวแปรอิสระ (deterministic trend)
C. Positive serial correlationแกว่งขึ้นลงเป็นช่วงยาวราบเรียบCochrane-Orcutt / time series techniques
D. Negative serial correlationสลับบวก-ลบถี่ ๆ เป็นซิกแซกCochrane-Orcutt / time series techniques

Durbin-Watson มีสเกล 0–4: DW≈2 = ไม่มี autocorrelation, DW→0 = positive serial correlation แรง, DW→4 = negative serial correlation แรง

6. Variable Transformation — สูตรและ Box-Cox

แปลงตัวไหนโมเดลสมการกลับ
Y = ln(Y)\(Y'=\beta_0+\beta_1 X\)\(\hat{Y}=e^{\beta_0} e^{\beta_1 X}\)
X = ln(X)\(Y=\beta_0+\beta_1\ln(X)\)—
ทั้งคู่ log\(\ln(Y)=\beta_0+\beta_1\ln(X)\)\(\hat{Y}=e^{\beta_0} X^{\beta_1}\)
Reciprocal ทั้งคู่—\(\hat{Y}=X/(\beta_0 X+\beta_1)\)
Box-Cox: \(Y' = Y^\lambda\) — กรณีพิเศษ: \(\lambda=2 \to Y^2\), \(\lambda=0.5 \to \sqrt{Y}\), \(\lambda=0 \to \log(Y)\), \(\lambda=-0.5 \to 1/\sqrt{Y}\), \(\lambda=-1 \to 1/Y\)
เลือก λ จากจุดสูงสุดของ log-likelihood plot (boxcox()) — แก้ nonlinearity, non-normality, non-constant variance พร้อมกันได้ด้วยการแปลง Y ตัวเดียว

7. Weighted Regression (สำหรับ non-constant variance ที่เส้นค่าเฉลี่ยตรง — แผง F)

\(w_i = 1/\hat{s}_i^2\) (จาก SD function, ทนต่อ outlier กว่า) หรือ \(w_i = 1/\hat{v}_i\) (จาก variance function) 
sdmodel <- lm(abs(resid(model))~X, data=d)
w <- 1/(fitted(sdmodel)^2)
wtmodel <- lm(Y~X, data=d, weight=w)

Observation ที่ variance สูง (residual กระจายมาก) ได้ weight น้อย → ดึงเส้นถดถอยน้อยลง

8. Cochrane-Orcutt Transformation (independence/autocorrelation)

โมเดล: \(Y_t=\beta_0+\beta_1 X_{1t}+\cdots+\varepsilon_t\), \(\varepsilon_t=\rho\varepsilon_{t-1}+u_t\)
ขั้นตอน: (1) fit ธรรมดา ได้ e_t (2) \(r=\dfrac{\sum e_t e_{t-1}}{\sum e_t^2}\) (3) \(Y^*_t=Y_t-rY_{t-1}\), \(X^*_t=X_t-rX_{t-1}\) (4) regress Y* on X* (5) ทำซ้ำจนกว่า DW test จะไม่พบ autocorrelation 
library(orcutt)
comodel <- cochrane.orcutt(model)
summary(comodel)   # แสดง DW ก่อน/หลัง + comodel$rho

SE ที่เพิ่มขึ้นหลังแก้ = สัญญาณว่า OLS เดิมประเมิน SE ต่ำเกินจริง (เพราะไม่นับ serial correlation)

9. Multicollinearity — สัญญาณ, VIF, Remedy

สัญญาณ: (1) correlation ระหว่างคู่ X สูง (2) สัมประสิทธิ์ไม่เสถียรเมื่อเปลี่ยนโมเดล (3) t-test รายตัวไม่นัยสำคัญ แต่ F-test ภาพรวมนัยสำคัญ (สัญญาณตรวจง่ายที่สุด)

\(\text{VIF}_j = 1/(1-R^2_j)\), R²_j จาก regress X_j กับ X ตัวอื่นที่เหลือ
\(\text{VIF}=1\) ไม่มี correlation | \(\text{VIF} > 4\) ปานกลาง | \(\text{VIF} > 10\) รุนแรง
RemedyแนวคิดTrade-off
Centeringลบ X ด้วยค่าเฉลี่ยก่อน fitช่วยเฉพาะ collinearity จาก interaction/polynomial
ตัดตัวแปรตัดตัวที่สัมพันธ์กันสูงออกบางตัวเสียข้อมูล/ตัวแปรที่อาจสำคัญทางทฤษฎี
Ridge Regression\(\hat{\beta}=\operatorname{argmin}[\sum (Y-X\beta)^2+\lambda\sum \beta_j^2]\), \(\hat{\beta}=(X'X+\lambda I)^{-1}X'Y\)ยอมรับ bias เพื่อลด variance/เสถียรภาพ — ตีความ β ตรงไปตรงมายังได้
PCAสร้างตัวแปรใหม่ (PC) orthogonal กัน จาก eigenvalue/eigenvector ของ covariance matrixกำจัด multicollinearity เต็มที่ + ลดมิติ แต่ตีความ PC ยาก (ต้องดู loading)

Ridge: \(\lambda=0\) → OLS พอดี; เลือก λ จาก ridge trace plot (จุดที่เส้นสัมประสิทธิ์เริ่มเสถียร) — R: lmridge(y~., data, K=\(\lambda\))

PCA: จำนวน PC ที่ใช้ ดูจาก scree plot หาจุด "elbow" — R: prcomp(X, center=TRUE, scale=TRUE), สัดส่วนอธิบาย = \(\lambda_k/\sum\lambda\)
