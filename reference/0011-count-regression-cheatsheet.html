Poisson / Negative Binomial Formulas + Rate Ratio Cheat Sheet

สรุปสมการ Poisson vs NB, กฎวินิจฉัย overdispersion, การใช้ offset, และ template แปลผลที่ต้องใช้ซ้ำทุกครั้งที่ fit count regression — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

ความสัมพันธ์: Poisson คือกรณีพิเศษของ NB เมื่อ \(\theta \to \infty\) (ไม่มี unobserved heterogeneity เหลืออยู่เลย) — \(\hat{\theta}\) ยิ่งเล็กยิ่งมี overdispersion มาก NB มองว่า \((y_i|x_i,\tau_i) \sim \text{Poisson}(\mu_i \tau_i)\) โดย \(\tau_i \sim \text{Gamma}(\theta,\theta)\) แล้วอินทิเกรต \(\tau_i\) ออก ("gamma mixture ของ Poisson")

2. Rate Ratio Interpretation Template — ทักษะที่ออกสอบหนักที่สุด

Template: การแปลผลสัมประสิทธิ์ Poisson/NB Regression (ใช้เหมือนกันทั้งคู่)

เพราะ link function เป็น log ต้อง exponentiate ก่อนเสมอ: \(\exp(\hat{\beta})\) คืออัตราส่วนอัตรา (rate ratio) ไม่ใช่ผลต่าง

"จากข้อมูลนี้ เมื่อ [ตัวแปร X] เพิ่มขึ้น 1 [หน่วยของ X] ค่าคาดหวังของจำนวนนับ (expected count/rate) ของ [Y] เปลี่ยนเป็น \(\exp(\hat{\beta})\) เท่า ของเดิม โดยตัวแปรอื่นคงที่ (holding other variables constant)"

ห้ามพูด "odds เพิ่มขึ้น" — Poisson/NB ไม่มีแนวคิด odds เลย มีแต่ expected count/rate (ต่างจาก odds ratio ใน Lecture 9)

กฎสเกล: ถ้า \(\hat{\beta}\) มีขนาดเล็กมาก (เช่น \(10^{-4}\)) ให้ลองคูณด้วยขนาดช่วงที่สมเหตุสมผลของ X ก่อนสรุปว่า "ไม่มีผล" — \(\exp(\hat{\beta} \times \Delta x)\) — สัมประสิทธิ์เล็กไม่ได้แปลว่าผลกระทบทางปฏิบัติเล็กเสมอไปถ้าหน่วยของ X มีสเกลใหญ่

3. กฎวินิจฉัย Overdispersion

เช็ค residual deviance / df (หรือ sum(residuals(model,type="pearson")^2)/df.residual):

  • ใกล้ 1 → assumption mean=variance ของ Poisson สมเหตุสมผล ไม่ต้องแก้
  • มากกว่า 1 ชัดเจน (โดยเฉพาะ >>1.5–2) → overdispersion ต้องแก้ด้วย quasi-Poisson หรือ Negative Binomial ไม่ใช่เชื่อ SE จาก Poisson ตรง ๆ

Goodness-of-fit test: pchisq(deviance(model), model$df.residual, lower=FALSE) — H₀: โมเดลฟิตข้อมูลได้ดี; p<0.05 → ปฏิเสธ H₀ (fit แย่)

ก่อนสรุปว่า overdispersion: เช็ค functional form ก่อน (plot X กับ log(Y) หรือ collapsed logplot) — ลองเพิ่มพจน์กำลังสองถ้าความสัมพันธ์โค้ง ถ้าเพิ่มแล้ว dispersion ยังสูงอยู่มาก แสดงว่าปัญหาไม่ใช่ functional form แต่คือ distribution assumption เอง

กฎเลือก: ถ้า overdispersion โตขึ้นเร็วกว่าเชิงเส้นเมื่อ mean สูง (variance ของกลุ่ม mean สูงเกินจริงเป็นพิเศษ) ให้ใช้ NB — ในทางปฏิบัติมักลองทั้งสองแล้วเทียบ AIC (มีแค่ NB ที่มี AIC ให้เทียบตรง ๆ)

5. เมื่อไรต้องใช้ offset()

ใช้เมื่อสนใจอัตรา (rate) ไม่ใช่จำนวนนับดิบ (จำนวนนับดิบเพิ่มตาม "ฐาน" ที่นับด้วยโดยธรรมชาติ เช่น เมืองใหญ่มีคดีมากกว่าเมืองเล็กเพราะประชากรเยอะ ไม่ใช่เพราะอันตรายกว่า)

\[\log \mu = \log N + \beta_0+\beta_1 x_1+\cdots+\beta_p x_p\] — พจน์ \(\log N\) ไม่มีสัมประสิทธิ์ (บังคับ = 1 เสมอ ไม่ใช่ให้ข้อมูลประมาณ)

กฎการใช้ offset: ถ้ามีเหตุผลทางทฤษฎีที่บอกว่าสัมประสิทธิ์ของตัวแปรหนึ่งต้องเท่ากับ 1 พอดี (เช่น "ฐาน" ของอัตรา — นับเซลล์เพิ่ม 2 เท่า ก็ควรเจอเหตุการณ์เพิ่ม 2 เท่าโดยธรรมชาติ) ให้ใช้ offset() แทนปล่อยให้โมเดลประมาณเอง

ผลของการใช้ offset ถูก: ไม่ต้องเสีย 1 df ไปกับการประมาณสัมประสิทธิ์ที่รู้คำตอบอยู่แล้ว → SE ของพารามิเตอร์ที่เหลือแม่นยำขึ้น (เล็กลง) + AIC ดีขึ้น

ตัวอย่าง R: glm(ca ~ offset(log(cells)) + log(doserate)*dosef, family=poisson, data=dicentric)
