Lecture 13 — Other GLMs

Gamma / Inverse Gaussian GLM Formulas + Link Selection Cheat Sheet

สรุปสูตร variance function ของแต่ละ family, ตารางเปรียบเทียบกลาง (centerpiece), และ template แปลผลแบบ multiplicative เหมือน Poisson — พิมพ์แผ่นนี้ติดโต๊ะได้เลย

1. เมื่อไรต้องใช้ Gamma / Inverse Gaussian แทน Normal

Binomial, Gaussian, Poisson ใช้บ่อยที่สุด — Gamma และ Inverse Gaussian ออกแบบมาสำหรับข้อมูลต่อเนื่อง เป็นบวกเสมอ และเบ้ขวา (เช่น เวลาถึงจุดเสียหาย, ค่าเคลมประกัน, resistivity) ที่ normal linear regression (error สมมาตร, variance คงที่) ไม่เหมาะ

ที่มาของ Gamma: ถ้า \(\text{Var}(Y_i) = \sigma^2\mu_i^2\) (variance โตแบบกำลังสองตามค่าเฉลี่ย) การ log-transform Y จะได้ \(\text{Var}(\log Y_i) \approx \sigma^2\) คงที่ ("variance stabilizing") — ทางเลือกที่ไม่ต้อง log (ทำงานบนสเกลเดิม) คือ gamma GLM ซึ่งมี variance function เป็น \(\mu^2\) อยู่แล้วในตัว

4. ตารางเปรียบเทียบกลาง: Family → ข้อมูล → Link → การแปลผล

Gammaต่อเนื่อง เป็นบวกเสมอ เบ้ขวา (เช่น ค่าใช้จ่ายเคลม, resistivity)\(\propto \mu^2\)log (multiplicative), canonical/inverse \((\eta=1/\mu)\), linear \((\eta=\mu\), สำหรับ \(\chi^2)\)\(\log(\mu_i)=X_i\beta\)\(\exp(\hat\beta)\) = ตัวคูณของค่าเฉลี่ยต่อการเพิ่ม X 1 หน่วย; % เปลี่ยนแปลง = \((\exp(\hat\beta)-1)\times100\%\)

วิธีเลือก: (1) response บวกเบ้ขวาปกติ → เริ่มจาก Gamma (2) มีค่าสุดโต่งมากกว่าปกติ (heavy tail ชัดเจน) → ลอง Inverse Gaussian เพิ่ม (3) เทียบ AIC/deviance ระหว่าง link ภายใน family เดียวกันได้ตรง ๆ — เทียบข้าม family/distribution ต้องระวัง (หัวข้อ 6)

5. Interpretation Template — เหมือน Poisson ทุกจุด (เมื่อใช้ log link)

เพราะ log link ทำให้ผลของ X เป็นตัวคูณ (multiplicative) จึงต้องยกกำลัง exp() ก่อนแปลผล เสมอ:

\(\hat\beta > 0 \implies \exp(\hat\beta) > 1 \implies\) ค่าเฉลี่ยเพิ่มขึ้น,  \(\hat\beta < 0 \implies \exp(\hat\beta) < 1 \implies\) ค่าเฉลี่ยลดลง — เปอร์เซ็นต์การเปลี่ยนแปลงคือ \((\exp(\hat\beta) - 1) \times 100\%\)

Template ประโยค: "จากข้อมูลนี้ เมื่อ [X] เพิ่มขึ้น 1 [หน่วย] ค่าเฉลี่ยของ [Y] คาดว่าจะเปลี่ยนเป็น \(\exp(\hat\beta)\) เท่าของเดิม (เพิ่ม/ลด \([(\exp(\hat\beta)-1)\times100]\%\)) โดยตัวแปรอื่นคงที่"

ถ้าใช้ offset(log(N)) (เช่นโมเดลค่าสินไหมต่อกรมธรรม์): \(\log(\mu_i)=\log(N_i)+X_i\beta \implies \dfrac{\mu_i}{N_i}=\exp(X_i\beta)\) — โมเดลทำนายค่าเฉลี่ยต่อหน่วยฐาน ไม่ใช่ยอดรวมดิบ — หลักการเดียวกับ offset ใน Poisson (Lecture 11)

6. เปรียบเทียบโมเดล — ข้อจำกัดสำคัญ

เทียบ link ภายใน family เดียวกัน: ใช้ AIC และ 1-pchisq(deviance,df) (goodness-of-fit) เทียบกันได้ตรง ๆ — เลือก link ที่ AIC ต่ำสุด + p-value goodness-of-fit สูง + coefficient significant + plot \(g(\mu)\) เทียบ x เป็นเส้นตรงที่สุด

เทียบข้าม distribution (เช่น Gamma vs log-normal): LRT ใช้ไม่ได้ เพราะไม่ nested กัน (distribution assumption คนละแบบ) และ AIC เทียบตรง ๆ ไม่ได้ตรงไปตรงมา — ถ้า null deviance ใกล้เคียงกัน ให้เทียบว่า residual deviance ของโมเดลไหนลดลงได้มากกว่าหลัง fit ตัวแปร (สัญญาณอ้อมว่าโมเดลไหนดีกว่า)

เช็ค: ถ้า \(\sqrt{\text{dispersion}}\) ของ gamma GLM ใกล้เคียงกับ Residual standard error ของ lm(log(y)~...) มาก แปลว่า \(\nu=1/\phi\) ใหญ่ → gamma distribution ถูกประมาณด้วย normal ได้ดี → สองโมเดลแทบแยกกันไม่ออก
